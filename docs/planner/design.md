# 调度（planner）

> 代码：[`packages/planner`](../../packages/planner) · 接口：[契约](../stage0/contracts.md) §5.1

调度负责"接下来做什么"：一门课的下一步、跨课程的今日待办、复习安排，以及隔几天回来时怎么接上。

## 现状

- **骨架：**
  - 按最小学习流程固定地走一遍，从各单元的状态读出下一步，并说明这一步是老师做还是等你做：商量目标 → 你确认目标 → 把教材加入本课 → 搭初版知识图 → 摸底 → 排路线 → 设计阶段 → 你确认设计书 → 每个课时（教材 → 阅读 → 小测 → 汇报和小结）。一个阶段的课时都完成后，停在"阶段测试和复盘"（还没实现）。
  - 每个课时先看教材状态：生成中 → 等你；失败第一次 → 主老师重试；连续失败两次 → 交还给你稍后重试。
  - 下一步放在每轮课程简报的开头给老师；首页（"继续学习"、课程卡片带进度）、课程进度页和状态栏显示给你。主界面左侧栏的课程列表也由它提供。
- **距考试还有多久（goal C，已技术验收，待你试用）：** 目标里有考试日期或最后期限时，下一步带一个倒计时：取较早的日期，写"距考试（2027-01-15）还有 14 周，路线 3 个阶段已完成 1 个"，不到两周按天说，过了写"已过"。进度页"下一步"、首页课程卡片和老师的简报都显示。
- **还没做：** 复习调度、跨课程的今日待办、"欢迎回来"、按最后期限判断能不能赶上（倒计时只说剩多少时间，不估算）。

## 复习与回归

- **复习融入日常。** 复习穿插在后续课时和阶段测试里，不单独做成"背单词"式的功能。复习量有上限，不会把你淹没。
- **隔几天再回来时：** 先欢迎回来，做一两道短检查，然后接着学。不会给你列一张"欠课清单"。
- **有期限时（比如期末考试）：** 只有一个最后期限，不排死每天的日程。系统只判断"照现在的节奏能不能赶上"，用区间表示，不报精确数字。赶不上时会直接说明，并给出选择：缩小范围、增加时间或调整里程碑。
- 结课以后，学到的节点也会偶尔安排复查。

**和课堂的关系很简单：** 不同步学校的课表。如果在确认目标时说明了有期限，只记一个最后期限。

## 关键决定

- **不同步课表：课程进度只显示学到哪了、接下来学什么**（10-03，你）。
- **有期限时只记一个最后期限，不排死日程**（10-03，你）。

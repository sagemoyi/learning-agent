# 调度（planner）

> 代码：[`packages/planner`](../../packages/planner) · 接口：[契约](../stage0/contracts.md) §5.1 · 调研：[调度做深调研](research.md)

调度负责"接下来做什么"：一门课的下一步、跨课程的今日待办、复习安排，以及隔几天回来时怎么接上。

## 现状

- **做深第一轮已技术验收，待你试用**（[验证记录](../stage0/compatibility.md#planner-abc下一步可信有上限的复查回来以后10-11claude)），分三批：
  - **A 下一步可信、可接续：** 每一步有稳定的标识（做什么、对哪个对象），写明是老师做、你做，还是现在谁都不用做（等后台生成、已结课、已归档、目标文件读不出来）；目标文件读不出来时说明原因，不再当成新课让老师重写目标；课程里没交的测试（"考我一下"、练习、模拟考等）列在"下一步"下面，随时能回去，计时中的测试直接成为下一步；撤回的小测、一道没答就结束的摸底不再当成做完了；你点"考我一下"的"不做了"会交回主老师一次。
  - **B 有上限的复查：** 按[掌握分析](../learner/design.md)给的"什么时候做一道新题才算数"，在课时之间建议做一道没做过的题；只看本课自己的作答，等得最久的先，全部课程每天合计默认 3 道（设置页可改，你自己点的"考我一下"也算）；可以"今天先不做"；没有没做过的练习题时请老师补题，不凭空出题。
  - **C 回来以后和能不能赶上：** 隔了 7 天以上再学，下一步先写上次学到哪、哪天，老师先欢迎回来、回顾一下再接着学，不列落下的内容；有考试日期或期限时，按已学完阶段的用时粗算剩下的要多久，说来得及、有点紧还是赶不上，赶不上时给出选择。首页"继续学习"先给计时中的测试，再给最近在学的课。
- **主线走法：** 按学习旅程固定地走：商量目标 → 你确认目标 → 把教材加入本课 → 搭初版知识图 → 摸底 → 排路线 → 设计阶段 → 你确认设计书 → 每个课时（教材 → 阅读 → 小测 → 汇报和小结）。从第 2 阶段起，你确认设计书后先做阶段前测。一个阶段的课时都完成后是阶段测试；交卷后老师写复盘，你在进度页决定补课还是进入下一阶段。有待确认的路线调整时，先请你看调整。所有阶段完成后：老师发布结课检验 → 你做结课检验 → 老师写课程报告 → 已结课；结课后加了阶段，学完要重新做结课检验。每个课时先看教材：生成中就等；失败第一次老师重试；连续失败两次交还给你稍后重试。
- **在哪里显示：** 每轮课程简报的开头给老师；首页（"继续学习"、课程卡片）、课程进度页、状态栏、主界面左侧的课程列表给你。
- **还没做：**
  - 复查只出一道单独的练习题；不会把复查需要放进课时小测，阶段测试里的旧题仍按 [assess](../assess/design.md) 的规则选。
  - 回来以后不单独出"回归检查"：到时间的复查照常建议；不会特意挑和当前课时相关的知识点。
  - "今天先不做"只能整门课推到明天，不能只推一个知识点；没有"今天主学哪门课"的选择。
  - 不记有效学习时长；"能不能赶上"只按阶段用时粗算，不看每周投入和日历上的先后约束，也没有用你的历史数据校准过。
  - 页面一直开着、跨过了检查时间时不会自己刷新，下一次有推送或重新打开页面时才出现建议。

## 怎么运作

### 下一步（A）

- **谁做：** 老师做（简报写"该你做"，你的操作交回时老师会被叫醒接着做）；你做（简报写"等学习者"，老师只提醒）；现在谁都不用做（教材在生成、已结课、已归档、目标文件读不出来；老师收到进度通知也不用回复）。
- **稳定的标识：** 每一步的标识由"做什么"和"对哪个对象"组成，例如"做这份小测"带着这份测试。老师的简报按标识判断下一步变了没有：撤回一份小测再发一份，标题一样也会告诉老师；只改了说明文字不算变化。
- **没做完的测试：** 除了下一步本身，课程里所有没交的测试都列在"下一步"下面（计时中的在前，其他按发布先后），点"继续"回到测试页，草稿和已存的答案都在。一份测试点了"开始"、正在计时，它就成为下一步，别的都排在后面。没交的"考我一下"不挡主线：老师照常往下讲，只是不讲那道题。
- **测试结束的几种情况：** 摸底只在还没有路线时起作用：一道没答就结束（你提前结束或老师撤回）时，老师先问你重新摸底还是直接排路线；排好路线后，摸底就不再拦着。小测被撤回就重新出，课时小结要一份交了卷的小测。阶段前测撤回或一道没答就结束，算跳过。阶段测试撤回后重新发布。
- **只读：** 看下一步不会出题、发任务、推进阶段或叫醒老师，重复读多少次数据都不变。
- **"不做了"交回：** 你在"考我一下"里点"不做了"，assess 交回主老师一次（"不算对也不算错，这道题以后不当新题出"）；老师自己撤回测试不交回。

### 复查（B）

- **什么时候做一道新题才算数**由 learner 按本课的作答给出（`checkFrom`）：已独立完成，最近一次接触这个知识点（作答或讲解）后 3 天，做对就是延迟验证；已延迟验证，最近一次独立答对后 14 天，看看还会不会；有帮助完成，最近一次帮助后 24 小时，不靠帮助独立做一道。最近 24 小时内讲过的，都往后推到讲解后 24 小时。还没答对、证据冲突的不安排复查：先教，或先核对做错的那道题。
- **挑哪个：** 时间已经到了的知识点里，等得最久的先（同时到的按固定顺序）。只看本课自己的作答：另一门课答对了，不算本课验证过。课程里还有没交的测试时不建议（那份先做，老师也不能讲）。每门课同时最多一道。
- **每天多少：** 全部课程合计，默认每天 3 道（设置页"资料服务"里的"复查提醒"，可选不建议、1、3、5 道）。当天开始过的都算：建议的、你自己点的"考我一下"、老师出的；点了"不做了"的也算，不会再腾出名额。同一个知识点今天在一门课查过，别的课今天不再问。
- **在哪里显示：** 课程进度页"下一步"下面一行"可以复查：知识点"和原因，"做一道"打开测试页，"今天先不做"让这门课到明天 0 点前不再建议（重启后也记得）。首页课程卡片上一行提示。老师的简报里也有：课时之间（你没在读教材、做测试时）问一句要不要先做一道，你同意就用 `start_check` 出题，不想做就接着学，不再提。
- **开始时再核对：** 点"做一道"时重新算一遍，已经不在建议里（今天的做够了、状态变了）就说明原因，不出题；两个页面同时点，只出一份。
- **没有新题：** 时间到了、但练习题池里没有你没做过的题时，简报列出这些知识点请老师补一两道；不借测试预留题，也不自动让模型出题。
- 复查交卷后照常交回主老师，结果只由判分和 learner 的规则决定；建议本身不写任何记录。

### 回来以后（C）

- **最近一次学习**取作答、你在对话里的提问和说法（课堂记录）、完成的任务中最晚的一次；后台生成教材、老师的进度通知、老师讲解（被通知叫醒的老师可能在没人时讲）、打开页面都不算。
- **隔了 7 天以上**（设置项 `returnAfter`，默认 7 天）：下一步多一行"隔了 N 天回来。上次（日期）做了什么"；老师的简报请老师先欢迎回来，用一两句话回顾上次学到哪里再接着做，不列落下的内容，也不因此重新摸底。一门课从来没学过、或者已经结课，不算"回来"。
- **继续学习：** 首页的"继续学习"先给计时中的测试，再给轮到你、最近学过的那门课。

### 能不能赶上（C）

- 有考试日期或期限时，倒计时照旧（取较早的日期，"距考试（2027-01-15）还有 14 周，路线 3 个阶段已完成 1 个"），后面加一句按节奏的估算。
- **一个阶段的用时**从上一个阶段结束（第一个阶段从你确认设计书）算到你看完复盘做出决定，包含其中的测试和复盘。
- **剩下多少：** 没开始设计的阶段算一个；进行中的阶段按课时完成的比例算，阶段测试和复盘算一个课时。
- **区间：** 只学完一个阶段时，按它用时的 0.75 到 1.5 倍；学完两个以上时，按最短到最长。
- **结论：** 剩下的上限不超过剩余天数，"照这个节奏来得及"；下限都超过，"照这个节奏赶不上"，并给出选择（每周多花些时间、缩小目标范围、调整后面的路线，跟主老师说）；其余"有点紧"。赶不上时简报请老师在合适的时候和你商量，改目标、改路线都要你确认，老师不能自己删内容或跳过验证。
- 学完第一个阶段之前、还没有路线时，明确说"估不了"。不报通过概率，不给完课日期；日期过了只说"已过"。

## 验收标准

做深第一轮按下面的标准技术验收（自动测试 `tests/planner-a.test.ts`、`planner-b.test.ts`、`planner-c.test.ts`，3182 合成数据实测）：

**A 下一步**
1. 同标题、不同对象的两步（撤回后重发的小测）标识不同，老师在同一轮里收到更新。
2. 课程里没交的"考我一下"列在下一步旁边、不挡主线；点了"开始"的计时测试成为下一步。
3. 你点"不做了"交回主老师一次，重复点不重复交回；老师撤回不交回。
4. 教材生成中、已归档、目标文件读不出来时谁都不用做，老师收到通知不被叫醒；目标读不出来不会变成"商量学习目标"。
5. 摸底撤回后先问重新摸底还是排路线，排好路线后不再拦着；撤回的小测重新出。
6. 读下一步和首页任意次，日志、测试、任务、模型调用、进度通知数都不变。
7. 同时点两次"考我一下"只出一份；测试建好、任务没发出的那份，再点时补发任务。

**B 复查**
1. 第一次独立答对后 3 天内不建议，到了时间建议延迟验证；另一门课没有自己的作答，不建议。
2. 中间讲解过，时间往后推；复查答对后状态变成已延迟验证，14 天后建议复查。
3. 全部课程每天合计不超过设置：等得最久的先；"不做了"也占名额，同一个知识点当天不再问；第二天重新计数。
4. 没有没做过的练习题时简报请老师补题，不出题。
5. "今天先不做"到第二天 0 点为止，重启后仍然有效；之后点"做一道"被拒绝并说明原因。
6. 两个页面同时开始不同课程的建议，只有还在建议里的那份开始；同一份点两次只出一份；老师用 `start_check` 出的题记为老师发布。

**C 回来和节奏**
1. 从没学过的课不算回来；后台生成、进度通知、老师自己的讲解不算学习；隔 7 天提示上次学了什么，再学一次就消失；你的提问、完成任务也算学习；结课后不提示。
2. 节奏：没有路线、没学完一个阶段时"估不了"；一个阶段按 0.75–1.5 倍，两个以上按最短到最长；进行中的阶段按课时比例；来得及、有点紧、赶不上三种结论；阶段都学完时只剩结课检验。

## 关键决定

- **不同步课表：课程进度只显示学到哪了、接下来学什么**（10-03，你）。
- **有期限时只记一个最后期限，不排死日程**（10-03，你）。
- **做深第一轮用可以说清楚的规则，不用记忆模型或排程服务**（10-11，Claude 按调研定）：下一步带稳定标识和"谁都不用做"的状态；复查只在 learner 说"现在做一道新题才算数"时建议，按本课作答、等得最久的先、全部课程每天共用上限，开始过的都算（包括"不做了"），点开始时再核对；没有新题请老师补，不让模型出题；"回来"按真正的学习记录算；"能不能赶上"按已学完阶段的用时给区间，学完一个阶段前不估。不采纳：FSRS 等记忆调度（输入是自评分的卡片，不能直接接六种证据状态）、按类型和课程轮转（先到先排已能保证不会一直排不上）、按工时和每周投入估算（没有可靠的耗时记录）、自动建复查测试（没交的测试会限制老师讲课）。

完整的决定和来源见[决策记录](../decisions.md)。

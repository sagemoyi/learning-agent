# 判分不把错的判成对

> 来源：11-02 的外部审查（[报告](../../history/2026-11-audit/report.pdf)，括号里是报告的编号）。修复顺序见 [现在](../../now.md#修复顺序)。原则：程序证明不了"对"的时候，宁可"待复核"，也不确定地判对。

## 问题

- **数值题只看开头的数字（L11）：** `splitQuantity` 取开头的数字，后面全当单位。参考答案没有单位，或单位程序不认识（`%`、`kg 水/kg 滤饼`）时只比数字，于是参考 `2`、答 `2+100` 或 `2 kg` 都判对；参考 `20%`、答 `20 kg` 也判对。"没单位""认不出的单位""无量纲"三种情况混在一起，都退回只比数字。
- **表达式题抽几个点就算等价（L05）：** 每个变量只在 0.5～2 之间随机取值，三到六次相近就判对。`sqrt(x^2)` 和 `x`、`abs(x)/x` 和 `1`、分段式和奇点附近的式子都能判对，而且是确定的"对"，直接进独立掌握证据。
- **摸底把"部分对"都当成会（L12）：** 两问答对一问也是"部分对"，摸底把它当"会"，跳过先修的探测；同一份作答在掌握分析里却是"还没答对"。设计里的约定是只有"对"或"只差单位"才算会。
- **没有判分的标准样例（M05）：** 判分规则和"判分"角色的模型都没有一组人核对过的题来衡量"错的判成对"有多少。

## 方案

1. **数值题完整读答案（L11）：**
   - 数字后面只允许单位或计数词（块、台……）；剩下有运算符（`+`、`*`、`/` 后跟数字）或认不出的内容，判"待复核"并说明，不再只比数字；
   - 区分三种参考单位：无量纲（空、`%`、`ppm`、"比例"）、程序认识的单位、程序不认识的单位（教材的复合单位）。无量纲参考遇到有量纲的答案判错；`%`、`ppm` 按比例换算（`20%` 等于 `0.2`）；不认识的单位要求答案写的单位文字一致，不一致的"待复核"；
   - 现有的单位换算、科学计数法、中文单位照常支持。
2. **表达式等价（L05）：** 先查调研再定做法，候选是 mathjs 的 `simplify`/`symbolicEqual` 加上题目声明的变量范围（题目可以写"x > 0"；判分实例里这些函数已关掉，要在程序里直接调，不经学生的式子）。数值抽样只用来找反例：找到不等的点就判错；没找到反例、又没有符号上的证明时，判"待复核"交给"判分"角色，不再直接判对。抽样覆盖负数、零、很大和很小的数，不只在 0.5～2。
3. **"部分对"带原因（L12）：** 判分结果给每一问的结果和"部分对"的原因（只差单位、某一问错、步骤不全）。摸底只把"对"和"只差单位"当作会；其他部分对按"不确定"继续往下探。
4. **判分样例集（M05）：** 先编一小组合成的化工题（量纲、百分数、科学计数法、有效数字、符号和定义域、多问、开放题评分要点），每题给标准答案和容易误判的近似错答案。规则判分每次跑测试都过一遍；"判分"角色的模型只在改提示词或换模型时、经你同意后跑（花钱）。报告分开写：对的判成错、错的判成对、转"待复核"的比例；"错的判成对"单列。

## 放弃的方案

- **表达式题全部交给模型判：** 模型对代数等价不可靠，费用也高；程序能证明的仍由程序判。
- **只是把抽样区间放大：** 换个区间仍是有限个点，分段和奇点照样漏，只是更难复现。
- **认不出单位时一律判错：** 教材里有大量程序不认识的复合单位，全判错会把会做的人判成不会；"待复核"让老师看一眼。

## 验收标准

1. `2+100` 不被当成 `2`；参考无量纲时 `2 kg` 判错；参考 `20%` 时 `0.2` 判对、`20 kg` 判错；现有单位换算的测试照常通过。
2. 变量范围未知时，`sqrt(x^2)` 和 `x` 不判对；题目写明 `x ≥ 0` 时判对。`abs(x)/x` 和 `1`、分段式、`0/1e-7` 这类边界不确定地判对。
3. 两问答对一问的摸底题，不让这个知识点算"会"，也不跳过它的先修。
4. 样例集进自动测试，规则判分没有"错的判成对"。
5. `pnpm typecheck`、`pnpm test`（含 `tests/flow.test.ts`）、`pnpm build` 通过。

## 风险

- 更严格会让更多作答进"待复核"，老师的待办变多；样例集里统计一下"待复核"的比例，太高再调规则。
- 旧作答不用新规则重判（11-02 你定），新规则只影响之后的判分：以前按宽松规则判对的作答仍算证据，觉得不对的可以申诉。
- 题目要能写变量范围，`add_problems` 的说明多一个参数（按 `learning-prompts-tools` 改）。

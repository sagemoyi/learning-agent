# 题库与测试（assess）

> 代码：[`packages/assess`](../../packages/assess) · 调研：[做深调研](research.md) · 接口：[契约](../stage0/contracts.md) §4.6、§5.1 · 验证：[验证记录](../stage0/compatibility.md) V9（拍照手写）、"骨架联调"

题库与测试负责题从哪来、怎么分池、怎么组卷、怎么判分。判分结果记进证据日志，掌握状态由 [learner](../learner/design.md) 据此推算。

## 现状

- **A 批题库可信已技术验收，待你试用**（细节见下文"A 批"）：教材习题按题号导入，题干、附图和书后答案取自原书；同一道题只入库一次、只在一个题池；改编题和老师自己出的数值题，答案由受限计算工具算出；数值题有单独的答案栏，单位换算后比较；你可以按题号标出作业做过的题；测试页显示题库概览和附图。
- **骨架沿用：**
  - 题库分两个题池：练习题池和测试预留题池。摸底、小测、练习只能用练习题，阶段测试和模拟考只能用测试预留题；指定的题目不在对应题池、或答案存疑暂停使用时直接报错。
  - 老师组卷发布、查看结果。测试种类有摸底、小测、练习、阶段测试、复查、模拟考。按节点组卷时先挑你没见过的题（没作答过、没标作业做过），也会选给后来被合并进这个节点的旧节点出的题（10-08，knowledge C）。
  - 测试页：左侧栏"测试"入口显示待作答数量；作答进度条、固定的交卷栏，交卷前不显示答案；交卷后显示得分卡；可以"就这题提问"。
  - 表达式和开放题由模型按评分标准判，带把握程度，把握低的标"待复核"。每次判分都记进证据日志。
  - 交卷后交回主老师（带判分结果），对应的测试任务自动完成。
  - 测试条件：老师不写开闭卷时，阶段测试和模拟考按目标说明里考试档案的条件（模拟考带考试时长），其他测试按目标里的默认条件；老师写了开闭卷就只覆盖这一项（10-08，goal A）。
- **做深：** 按 A 题库可信 → B 测试按规则组、作答时换题报错 → C 手写作答和模拟考分三批（10-08 确认，见[调研报告](research.md)）。
- **还没做：** 自适应摸底和"不会"按钮；阶段测试的组卷规则（新题比例、旧题回归、完整任务题）；换题与报错；"待复核"的改判和申诉；拍照手写作答；往年题和模拟考。

## A 批：题库可信

题目尽量直接取自教材习题，答案要有依据，同一道题只在一个题池，数值题比对单位，你能标出作业做过的题。已技术验收，待你试用。

### 怎么运作

- **按题号导入习题：**
  - 老师给出题号（如 `1-25`）、考查的知识节点，可选题池和题目大小。程序在本课的资料里找到这道习题，取出题干、附图和书后方括号里的答案。
  - 答案能解析成"数值 + 单位"的，按数值题判；分几问的，拆成几个小问各自判；解析不了的那一问（文字答案、"略"）按书后原文由模型判。
  - 导入结果逐题列出解析出的答案，老师核对后可以改。
- **一题一池：**
  - 同一份资料里的同一个题号只入库一次，再导入时返回已有的题。
  - 老师不指定题池时，程序按节点分：每个节点约三分之一进测试预留题池，至少一道；短题和作业做过的题只进练习题池。
  - 进测试预留题池的题，答案必须有依据（书后答案、权威来源或计算工具算出），老师自己解的答案不行。
- **受限计算工具：**
  - 老师用 `calculate` 写一段带单位的计算过程，程序逐行算出结果。它只能做数学计算，不能定义函数、不能建矩阵，算式长度有上限，碰不到文件和网络。
  - 用来验算书后答案：结果对不上时，这道题标"答案存疑"，暂停使用，等老师核对。
  - 改编题必须写明原题和计算过程，答案由程序算出；老师写的答案和算出的对不上时退回，并写明差多少。改编题在题目上标"改编"和原题号。
- **判分：**
  - 数值题有单独的"答案"栏（多问的题每问一栏），步骤写在下面的作答区。判分只看答案栏。
  - 单位换算后比较；没写单位但数值对，判"部分对"；单位的量纲不对，判错。
  - 表达式题代入几组随机数值比较，不交给模型。
- **作业做过：** 测试页里你按题号标记做过的作业题（如"1-1~1-10, 2-3"），可以撤销；你在对话里告诉老师，老师用 `mark_homework` 记下。这些题以后不算新题、不进测试预留题池；你标了已经在测试预留题池里的题，老师会收到提示。
- **题库概览：** 测试页按知识节点列出练习题、测试预留题各有几道，作业做过和答案存疑的有几道。测试预留题只显示数量，不显示题干。
- **附图：** 带附图的习题，测试页只显示原书上那张图的区域，不显示整页（整页上印着答案）。

### 验收标准

- 合成教材里导入"1-3、1-4"：题干、附图和方括号里的答案都对得上原文；分问的题拆成小问；再导入一次，不会多出新题。✓
- 同一个题号不会同时出现在两个题池；不指定题池时，每个节点至少有一道测试预留题；答案没有依据的题不能进测试预留题池。✓
- 改编题没有计算过程不能入库；老师写的答案和算出的对不上时退回，并写明差多少。✓
- 计算工具拒绝定义函数、`import` 这类调用和过长的算式；验算书后答案对不上时，这道题标"答案存疑"，组卷时不再选它。✓
- 答"1.44 kg/m³"判对，"1440 g/m³"换算后判对，"1.44"（没写单位）判部分对，"1.44 m"判错；作答区写满步骤时，只按答案栏判。✓
- 标记"1-1~1-10 作业做过"后，这些题不再当新题、不再分进测试预留题池；撤销后恢复。✓
- 测试页显示附图区域；测试预留题的题干不出现在题库概览里。✓
- 3180 上已有的重复题（同一出处存了两份）在升级时处理：保留有作答记录的那份，其余停用。✓
- 自动测试只用合成教材和假模型；真实模型只在 3182 的合成课程上走一遍"导入习题 → 小测 → 判分"。✓

验证结果见[验证记录](../stage0/compatibility.md#assess-a题库可信10-08claude)。

## 摸底：探知识边界

- **出题方式：** 只出少量、有区分度的题。从中等难度开始，沿着知识图往上探（会了就跳到更高层），或者往下探（不会就查它的先修）。这样十几道题就能大致定位你的边界。这是报告里提到的 ALEKS "知识空间"思路。
- **你说"这个我会"时：** 系统既不直接采信，也不逼你重学，而是出一两道短题快速验证。
- **心理预期：** 明确告诉你这只是摸底，不算成绩，答不出来很正常。
- **产出：** 在知识图上标出三类区域：已会 / 边界（正好可以开始学的部分）/ 未探测。

## 阶段测试

- **每个阶段结束都一定有阶段测试。** 必须独立完成，测试条件按目标说明里约定的工具条件执行（例如闭卷、可以查公式表等）。
- **测试组成：**
  - 本阶段核心节点的题目，其中一部分是**练习中没见过的新题**，用来防止背题、检验能否迁移到新情境。
  - 一道本阶段的"完整任务"题。
  - 少量**前面阶段的题**，用来检验隔一段时间后是否还会，也就是延迟验证。
- **开放题判分：** Agent 按评分标准初判，并标注自己的把握程度。把握低的标为"待复核"，不会直接判错。你也可以申诉。

阶段测试之后的复盘见 [curriculum](../curriculum/design.md)"阶段复盘"。

## 题目来源分级

你提出"尽量用权威题，不要让 Agent 自己编"，报告也支持这一点。下表在此基础上补充了权威题不够用时的办法。

| 级别 | 来源 | 可用于 |
|---|---|---|
| 1 | 你导入的资料里的习题/例题（教材课后题、讲义） | 所有场景，包括阶段测试 |
| 2 | 公认的权威来源（官方真题/样题、知名教材习题集、公开课作业） | 所有场景，包括阶段测试 |
| 3 | 改编题：在 1/2 级题目基础上改数字或情境，标注原题出处，答案用计算工具独立验算 | 所有场景，包括阶段测试；界面上明确标注"改编" |
| 4 | Agent 原创题，并明确标注 | 只用于练习和即时检查，不进入阶段测试 |

每道题都要记录：
- 出处（精确到页码/题号）
- 答案及答案来源（原书答案，或 Agent 解答但未经核对）
- 考查哪些知识节点
- 你是否见过这道题

化工原理的题目以计算为主：带单位的数值计算、查图表（摩擦系数图、物性表等）、图解法（如逐板计算的图解）。所以判分要支持"数值 + 允许误差 + 单位"，改编题要用计算工具独立验算，作答界面要能写解题步骤，第一版就支持拍照上传手写解答。验算用一个只能做数学计算、不能碰文件和网络的受限计算工具，不开放通用代码执行。

## 练习题和测试题分开

练习用的题和阶段测试里的新题要从不同的题池里出。同一道题练过之后再出现在测试里，只能算"复现"，不能算迁移。权威题的数量有限，所以在做阶段设计时，就要先为测试预留好题目。

## 测试类型与独立性

| 类型 | 何时进行 | 是否算独立证据 |
|---|---|---|
| 摸底 | 建课时 | 算，但只用于定位边界 |
| 小节小测 | 每学完一小节 | 算（闭卷作答的前提下） |
| 练习 | 课时中 | 用了提示就记为"有帮助" |
| 阶段测试 | 每个阶段末尾 | 算，而且是最重要的证据 |
| 复查 | 回来时，以及阶段测试里的旧题 | 算，用来确认"已延迟验证" |

**测试期间的侧边会话：** 只回答操作类问题，不讨论题目内容。如果你主动退出测试去提问，这道题记为"有帮助"。退出测试永远是允许的，不会被拦着。

**工具条件：** 每门课单独约定，写在目标说明里（有考试时以考试档案的条件为准）。老师可以为某次测试另选开卷或闭卷。

## 换题与报错

- **来源标签：** 每道题都显示来源：原题（附出处）、改编（附原题）或原创。
- **"这题有问题"按钮：** 作答界面上随时可以点，原因分五种：题目有错 / 条件不全 / 超出范围 / 答案存疑 / **这题我做过**（作业或课上做过）。
- **点了之后怎么处理：**
  - 这道题不计分，系统从同一知识节点、相近难度的题池里换一道。
  - 报"有错"的题进入待核查：老师回查原书或重新验算。
    - 确实有错 → 修正或下架，并告诉你结果。
    - 题目没错 → 向你解释清楚。
- **"这题我做过"：** 这道题会被标记为你见过，以后不再当"新题"用。你在上课做作业，所以这一点很关键。
- **换题规则：**
  - 换题不扣分。
  - 为了保证测试仍然有效，一次测试的换题次数有上限。报错不限次数；超过上限后，该题跳过，不判错。
  - 看过的题即使被换掉，也记为"见过"。

## 判分

- **客观题**（数值、选择）：按规则判分。数值题判断"数值 + 允许误差 + 单位"。
- **开放题**：由 LLM 按评分标准判分，附上理由和把握程度；把握低的标为"待复核"。
- **拍照手写作答：**
  1. 你拍照上传解答。
  2. 看图模型把照片转写成文字和公式。
  3. **你先确认转写结果。** 有识别错的地方可以直接改，避免因为识别错误被判错。
  4. 按上面的规则判分：结果按数值规则判，解题步骤按评分标准判。
- **掌握状态的计算：** 由规则根据累积的证据算出，不采用 LLM 自己报的"掌握度"。

阶段 0 用 `deepseek-flash` 试过手写识别：公式和计算过程识别得很好，但有两类错误，需要三道保险，其中一道就是你先确认转写结果（[验证记录](../stage0/compatibility.md) V9）。图片要放在用户消息里发给模型，当前中转会把工具结果里的图片转成文本。

判分的模型是设置页里的"判分"角色，输出额度留 4000（思考也算在内）。

## 关键决定

- **题目优先使用权威来源，并分级使用；练习题池与测试题池分开**（10-03，你 + 报告）。
- **改编题可以进入阶段测试，但必须标注、独立验算；作答时可以报错或换题（含"这题我做过"）**（10-03，你；换题机制由 Claude 补充）。
- **测试的工具条件按课程单独约定，由老师为每次测试选择开卷或闭卷**（10-03，你）。
- **第一版就支持拍照手写作答；判分前先由你确认识别结果**（10-03，你；确认这一步由 Claude 补充）。
- **拍照手写识别用 `deepseek-flash`**（10-03，阶段 0 调研）：DSH 默认目录里唯一能看图的 DeepSeek 模型。
- **看图一律放在用户消息里发给模型**（10-03，阶段 0 验证 V0）：中转会把工具结果里的图片转成文本。
- **练习题和测试预留题严格分开，由代码拒绝混用**（10-04，Claude 验收时发现小测可以用测试预留题）。
- **按 A 题库可信、B 测试按规则组和作答时换题报错、C 手写作答和模拟考分批做深；数值对了但没写单位判"部分对"，量纲不对判错；阶段测试不设总分过关线，按核心知识点逐个判断；建课时只做约 10 题的短摸底，每个阶段开头再做三五道前测**（10-08，你选调研的推荐项）。
- **A 批的细节**（10-08，Claude 按调研定）：
  - 教材习题由程序按题号从资料库取，不让老师转抄；同一份资料的同一个题号只入库一次，以前存了两份的，保留有作答记录的那份。
  - 不指定题池时每个节点约三分之一进测试预留题池、至少一道；测试预留题的答案必须有依据（书后、权威或计算工具算出）。
  - 受限计算工具只开放算术、单位和少数数学函数，在执行前检查整棵语法树；它算出的答案才算"已验算"。验算和书后答案不符时先暂停这道题，等老师核对，不自动改答案。
  - 数值题判分只看答案栏，解题过程只用来给老师看和给模型判开放题时参考。
  - 附图只裁出图本身显示，因为原书同一页印着答案。

完整的决定和来源见[决策记录](../decisions.md)。

## 待定问题

- **"部分对"算不算做对：** 掌握状态的规则目前只把"对"算作做对，所以没写单位的作答不会让节点变成"独立完成"。要不要把"只差单位"当作会了这个方法，留给 learner 做深时定。
- **老师每轮多看到的说明：** 题库的工具从约 2200 字符增加到约 4200 字符（新增导入习题、计算、记作业三个工具，加题工具多了改编和计算参数）。真实对话里老师用得对，暂不合并。
- **附图只在有坐标的 PDF 上显示：** 网页资料和没有坐标的解析结果只写"见原书第几页"。
- **3180 上已有的题没有题号：** 以前老师手工加的题，再用 `import_exercises` 导入同一道题时会补上题号，不会重复入库。

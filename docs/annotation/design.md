# 批注（annotation）

> 代码：还没有单独的包 · 接口：[契约](../stage0/contracts.md) §4.5（Block、Annotation）、§5.1（`learnAnnotation`）

批注负责你在教材和资料上的划线和批注：锚定位置、分类，并把它们转成学习信号、侧边会话或修改提案。

## 现状

- **还没开始。** 契约里已经定好了数据对象和服务接口；按开发顺序和 [sidechat](../sidechat/design.md) 一起做深。

## 设计

- **批注对象：** 可以在教材上划线、写批注，也可以在导入的资料上批注。批注锚定到段落块 ID，所以教材修订后批注不会丢。
- **四种类型：** 疑问 / 我的理解 / 重点 / 报错（教材或题目有误）。
- **不同类型的后续处理：**
  - 疑问 → 可以一键转成侧边会话。
  - 报错 → 自动变成修改提案（走[统一的修改流程](../journey.md#所有修改都走同一条路)）。
  - 我的理解 → 当作自我解释来评估，可能借此发现误解。
- 批注只是信号，不会直接提升掌握状态。在批注里反复问到的节点会标"有疑点"（见 [learner](../learner/design.md)）。
- 老师什么时候请你写批注，见 [journey.md](../journey.md#一个课时怎么走) 里"自我解释要有选择地用"。

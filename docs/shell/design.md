# 外壳（shell）

> 代码：[`packages/shell`](../../packages/shell)（样式 `shell.css`，标签规则 `client/tabs.ts`）、共享控件在 [`packages/kit/src/client`](../../packages/kit/src/client) · 接口：[契约](../stage0/contracts.md) §6.3 和 §11"外壳" · 做法：[界面审美复核技能](../../.agents/skills/learning-ui-review/SKILL.md) · 验证：[验证记录](../stage0/compatibility.md)"前端重构""外壳：标签页导航和侧栏"等节 · 调研：[做深调研](research.md)

外壳是整个界面的框架：主界面和课程界面的切换、图标栏和侧栏、标签页和每个标签的历史、右侧栏、状态栏、深浅色，以及各单元往里放页面、侧栏面板和区块的插槽。各单元的页面由单元自己做，外壳只负责布局和共享的设计控件。

## 两级：主界面 / 课程界面

和 VSCode 里"工作区 → 项目"的关系一样：主界面管理全局，打开一门课就进入课程界面。两个界面各有自己的标签、侧栏和最近打开的页面。

| 页面 | 主界面 | 课程界面 | 负责的单元 |
|---|---|---|---|
| 首页 | 课程列表 + 今日待办（跨课程的复习） | — | [planner](../planner/design.md) |
| 知识模型 | 全部节点 | 本课节点 + 相关节点 | [knowledge](../knowledge/design.md) |
| 资料库 | 资料仓库：全部资料，每份写用在哪几门课 | 本课资料（侧栏）：按角色分组、书的章节目录、引用它的课时 | [library](../library/design.md) |
| 课程进度 | — | 目标说明、课程路线、阶段 → 小节时间线（每个小节附小测结果和小结）、当前任务、阶段测试结果 | [curriculum](../curriculum/design.md) |
| 课程教材 | — | 当前及历史阶段的教材（阅读 + 批注）；侧栏是阶段 → 课时目录 | [textbook](../textbook/design.md)、目录由 [curriculum](../curriculum/design.md) 提供 |
| 主老师对话 | — | 本课的主会话 | [tutor](../tutor/design.md) |
| 测试 | — | 摸底、课后小测、阶段测试；侧栏是待作答和做过的测试 | [assess](../assess/design.md) |
| 批注 | — | 本课的批注；侧栏按所在课时列出 | [annotation](../annotation/design.md) |
| 侧边提问 | ✓ | ✓ | [sidechat](../sidechat/design.md) |
| 设置 | ✓ | ✓ | [settings](../settings/design.md) |

**通用组件只做一次，两处共用。** 知识图、资料库、侧边会话各自是同一个插件，只是"范围"参数不同（全局 / 本课）。

- **图标栏**（最左，48 像素，常驻）：最上面是课程/主界面切换（课程首字，主界面是房子图标；点开列出主界面、各门课和新建课程）；下面每个功能一个图标，悬停显示名称，有待办时带数字（测试待作答数、位置待确认的批注数）；外观和设置在底部。图标有两种状态：侧栏正显示它的内容（底色加深），当前标签的页面属于它（图标变成强调色）。
- **侧栏**（图标栏右边）：侧栏开着时，点有侧栏内容的图标，侧栏换成它；再点一次收起，图标不动。顶部是功能名称和"收起"按钮，可以拖宽（200–420 像素，双击右边缘恢复 264）。每个界面记住开着哪个、是不是收起了；第一次进课程时开着"课程教材"目录。
  - 你收起侧栏以后，点图标只在主区打开这个功能的页面，侧栏保持收起；再点当前页面所属功能的图标（悬停提示"展开侧栏"），或者点标签栏最左边的"展开侧栏"按钮，侧栏才展开，显示当前页面所属功能的内容（这个功能没有侧栏内容时，显示上次那一栏）。命令面板里也有"展开侧栏/收起侧栏"。
  - 有侧栏内容的：课程教材（阶段 → 课时目录，正在读的课时高亮）、测试（待作答的在前，做过的带分数）、批注（按所在课时列出，已解决的疑问不列）、本课资料（按角色分组，书的章节目录，见 [library](../library/design.md)）、知识模型（跟着当前标签的局部图，见 [knowledge](../knowledge/design.md)）。侧栏底部有"全部"链接打开整页。
  - 点了直接在当前标签打开页面的：课程进度、主老师、主界面的首页、资料库和知识模型、设置。
  - 窗口窄于 1180 像素，或者侧栏会把分屏挤到每栏不足 360 像素时，侧栏浮在页面上：点图标或"展开侧栏"按钮弹出，点了里面的一项、点别处或按 Esc 就收起（侧栏里的菜单开着时，Esc 先关菜单）。
- **标签栏**（最上面一行）：标签、紧跟着的"+"，右边是搜索（Ctrl K 命令面板）和"提问"。分屏时，搜索和"提问"在右上角那一栏。
  - 标签显示页面图标和标题，页面把标题改成具体内容（如"1.2 静止流体的压强"）。中键关闭；再点一次当前标签，页面回到顶部。
  - 右键标签：固定或取消固定、在右侧分屏打开、关闭、关闭其他标签（固定的留下）。固定的标签显示图钉，中键关不掉。
  - 关掉最后一个标签时，留下一个新标签页。
- **标签里的页面**顶部一行：后退、前进（没有可退的时候变灰），位置路径（课程 › 功能 › 页面），右边是刷新、在右侧分屏打开、"只看这一栏"（有分屏时）。页面内容在下面，读教材用窄栏，网格用宽栏。
- **在哪打开：** 普通点击在当前标签打开，进这个标签的历史；要打开的正是当前页面就不动。当前标签固定时，或者 Ctrl+点击、中键点击，在新标签打开（就在当前标签右边）。命令面板里 Ctrl+Enter 在新标签打开。出处默认在右侧栏打开。拖动标签可以分屏。
- **后退和前进：** 页面顶部的按钮、Alt+←/→、鼠标侧键（Chrome、Edge；Firefox 不把侧键交给网页）。每个标签记最近 50 步。
- **记住位置：** 切走的标签不卸载，滚动位置、展开的内容、输入框里的字都在。当前页前两页、后一页也留着，后退前进原样还在；更早的页面记下滚动位置，回来时等内容出来再滚过去（最多等 4 秒，先动了滚轮就不再滚）。最近用过的 8 个标签不卸载，更早的只记位置；刷新浏览器后恢复的标签，第一次切过去才加载。不在前台的页面收到推送不刷新，切回来时有变化再刷新一次。
- **新标签页**（"+"）：继续学习（课程里是这门课的下一步，主界面是各门课的下一步，由 planner 提供）、最近打开的 12 个页面、本界面的页面入口。
- **右侧栏**分"提问"和"出处"两个视图，顶部切换：
  - 提问：侧边提问，在任何页面都能打开（主界面上先选问哪门课）；选中教材段落、资料原文、知识节点或题目后点"就这段/题提问"会直接打开。
  - 出处：点出处标签打开资料原文（Ctrl+点击则在新标签打开），可以"在标签页打开"或关掉。
  - 两个视图各记各的宽度（提问默认 380，出处默认 520 像素），拖左边缘调整、双击恢复。窗口窄于 1000 像素，或者会把分屏挤窄时，浮在页面上。
- **状态栏：** 各单元放进来的简短状态（阶段进度、待作答测试、下一步），点了直接去对应页面。
- **深浅色：** 跟随 DSH 的外观设置，图标栏底部"外观"可以切换。
- **界面偏好**（侧栏开哪个和宽度、右侧栏开关和宽度、每个界面的标签和历史、滚动位置、最近打开、上次所在课程）记在浏览器本地；学习数据只在文件和数据库里。
- **测试进行中（未实现）：** 主区锁定为测试页。教材和侧边会话按目标说明里约定的工具条件受限（见 [assess](../assess/design.md)"测试类型与独立性"）。

**10-12 改版的验收标准：**
1. 默认一个标签；点侧栏、页面里的按钮、命令面板，都在当前标签打开，标签数不变。
2. 每个标签的后退、前进互不影响；按钮、Alt+←/→、鼠标侧键（Chrome、Edge）都能用，没有可退的时候按钮变灰。
3. "+"、Ctrl+点击、中键点击打开新标签；固定的标签不会被别的页面替换；右键菜单的几项都能用。
4. 切换标签回来，滚动位置、展开的内容、输入框里的字都还在；后退、前进回到离开时的位置；再点一次当前标签回到顶部。
5. 图标栏：最上面切换课程和主界面，"学习工作台"那块没有了；点有侧栏内容的图标展开侧栏，再点收起，图标位置不变；点其他图标直接打开页面。
6. 教材、测试、批注的侧栏能用，点一项在主区打开；"课程目录"不再单独出现。
7. 出处在右侧栏打开，Ctrl+点击在新标签打开；拖动标签分屏照常可用。
8. 后台标签收到推送不刷新，切回来时刷新；刷新浏览器后标签和各自的历史都恢复。
9. 1440、1024、760 宽度和深浅两色截图核对；窄窗口下侧栏和右侧栏浮在页面上，没有横向滚动。
10. 标签历史的规则有单元测试；类型检查、全部测试、构建通过；最小学习流程照常通过。

## 前端原则：做我们自己的产品，不在 DSH 界面上小修小补

- **为什么不改 DSH 的界面：** DSH 是一个成熟的编程 Agent 产品，界面是围绕"对话 + 写代码"设计的。我们的核心是"课程 + 教材 + 知识图"，目标不一样。所以前端的外壳、信息架构和交互都由我们自己设计。
- **方案（阶段 0 调研结论，详见 [stage0/research.md](../stage0/research.md)）：**
  - **后端：** 使用 DSH `web-app` 组合里的服务端部分（HTTP 服务、认证、会话接口），负责模型、会话、工具和 Agent 循环。
  - **前端：** 跑在 DSH 的客户端内核上（启动加载、连接认证、会话流、热重载），**整个页面由我们接管**。DSH 的渲染器只渲染一个 `root` 插槽，谁占了它谁就拥有整页布局；DSH 自己的界面插件除了提供设置表单服务的 `ui-settings` 都不装。我们的外壳和各个页面都是我们自己的前端插件，所以前端同样是插件化的。
  - **前端零件：** 停靠布局用 dockview，知识图谱用 sigma.js，原文 PDF 用 pdf.js。React 版本跟随 DSH（目前是 18）。
  - **备选：** 如果实测发现内核方案处处受限，就改成独立的 Vite 应用，直接调用 DSH 的 HTTP 和 WebSocket 接口。
  - **桌面版：** 先做 Web。之后用 Electron 包一层就是桌面版，DSH 自己的桌面版也是这么做的。
- **第一原则：DSH 的设计不能拖累我们的功能。** 只复用不限制我们的 DSH 内核零件；只要某个零件会限制我们的功能，就自己写。
- **视觉风格向 DSH 看齐。** DSH 的简约风格很好，我们参考它，必要时直接复用它的设计变量（颜色、字体、间距）。DSH 是 MIT 协议，允许这样用。

## 视觉规范

具体规则写在 AGENTS.md"前端"一节和[界面审美复核技能](../../.agents/skills/learning-ui-review/SKILL.md)里，这里只列结论：

- 颜色和字号只用 `shell.css` 的 `--la-*` 变量；浅色、深色各一套。字号 9 档（11、12、13、14、15、16、18、24、30），字重只用 400、500、600。
- 图标用 Lucide 线条图标，不用 emoji；图标栏只有图标，悬停显示 2–4 字的名称。
- 全部交互控件用共享设计控件，不显示浏览器默认控件。难撤销的操作用 `ConfirmButton` 原地二次确认，不用弹窗或折叠区。
- 列表行的操作区按固定位置排列，缺了的按钮也留出位置。
- 审美方向目前由 Claude 决定；GPT/Codex 设计或调整的界面，在 [PLAN](../PLAN.md)"当前进度"里留审美复核点。

# 外壳（shell）

> 代码：[`packages/shell`](../../packages/shell)（样式 `shell.css`，标签规则 `client/tabs.ts`）、共享控件在 [`packages/kit/src/client`](../../packages/kit/src/client) · 调研：[research.md](research.md) · 契约：[contracts.md](../contracts.md)（§7.3 插槽、§7.4 `learnShell`） · 做法：`learning-ui-review` 技能

## 概要

外壳是整个界面的框架：主界面和课程界面的切换、图标栏和侧栏、标签页和每个标签的历史、右侧栏、状态栏、深浅色，以及各单元往里放页面、侧栏面板和区块的插槽。各单元的页面由单元自己做，外壳只负责布局和共享的设计控件。布局参考 Obsidian：默认一个标签，点什么都在当前标签打开，每个标签有后退前进；整页由我们的前端接管，DSH 只提供运行时和客户端内核。

## 两级：主界面和课程界面

和 VSCode 里"工作区 → 项目"一样：主界面管理全局，打开一门课就进入课程界面。两个界面各有自己的标签、侧栏和最近打开的页面。

| 页面 | 主界面 | 课程界面 | 负责的单元 |
|---|---|---|---|
| 首页 | 课程列表 + 今日待办（跨课程的复习） | — | [planner](../planner/design.md) |
| 知识模型 | 全部节点 | 本课节点 + 相关节点；侧栏是局部图 | [knowledge](../knowledge/design.md) |
| 资料库 | 资料仓库：全部资料，每份写用在哪几门课 | 本课资料（侧栏）：按角色分组、书的章节目录、引用它的课时 | [library](../library/design.md) |
| 课程进度 | — | 目标说明、课程路线、阶段 → 小节时间线、当前任务、测试结果 | [curriculum](../curriculum/design.md) |
| 课程讲义 | — | 当前及历史阶段的讲义（阅读 + 批注）；侧栏是阶段 → 课时目录 | [textbook](../textbook/design.md)，目录由 curriculum 提供 |
| 主老师对话 | — | 本课的主会话 | [tutor](../tutor/design.md) |
| 测试 | — | 摸底、小测、阶段测试；侧栏是待作答和做过的测试 | [assess](../assess/design.md) |
| 批注 | — | 本课的批注；侧栏按所在课时列出 | [annotation](../annotation/design.md) |
| 侧边提问 | ✓ | ✓ | [sidechat](../sidechat/design.md) |
| 设置 | ✓ | ✓ | [settings](../settings/design.md) |

通用组件只做一次，两处共用：知识图、资料库、侧边会话各自是同一个插件，只是范围参数不同（全局或本课）。

（示意图里的字代表图标，界面上全部是 Lucide 线条图标，没有文字。）

- **图标栏**（最左，48 像素，常驻）：最上面是课程和主界面的切换（课程首字，主界面是房子图标；点开列出主界面、各门课和新建课程）；下面每个功能一个图标，悬停显示名称，有待办时带数字（测试待作答数、位置待确认的批注数）；外观和设置在底部。图标有两种状态：侧栏正显示它的内容（底色加深）、当前标签的页面属于它（强调色）。功能图标放不下时只有这一列滚动，切换课程和外观的菜单完整显示在页面上。
- **侧栏**（图标栏右边）：侧栏开着时，点有侧栏内容的图标，侧栏换成它；再点一次收起，图标不动。顶部是功能名称和"收起"按钮，可以拖宽（200–420 像素，双击右边缘恢复 264）。每个界面记住开着哪个、是不是收起了；第一次进课程时开着"课程讲义"目录。
  - 收起侧栏以后，点图标只在主区打开这个功能的页面，侧栏保持收起；再点当前页面所属功能的图标（悬停提示"展开侧栏"），或点标签栏最左边的"展开侧栏"按钮，侧栏才展开，显示当前页面所属功能的内容（这个功能没有侧栏内容时显示上次那一栏）。命令面板里也有"展开侧栏/收起侧栏"。
  - 有侧栏内容的：课程讲义、测试、批注、本课资料、知识模型（局部图）。侧栏底部有"全部"链接打开整页。点了直接在当前标签打开页面的：课程进度、主老师、主界面的首页、资料库和知识模型、设置。
  - 窗口窄于 1180 像素，或侧栏会把分屏挤到每栏不足 360 像素时，侧栏浮在页面上：点图标或"展开侧栏"弹出，点了里面的一项、点别处或按 Esc 收起（侧栏里的菜单开着时，Esc 先关菜单）。
- **标签栏**（最上面一行）：标签、紧跟着的"+"，右边是搜索（Ctrl K 命令面板）和"提问"；分屏时这两个在右上角那一栏。标签显示页面图标和标题，页面把标题改成具体内容（如"1.2 静止流体的压强"）；只改标题，不切换标签，也不动最近打开和前进后退。中键关闭；再点一次当前标签，页面回到顶部。右键：固定或取消固定、在右侧分屏打开、关闭、关闭其他标签（固定的留下）；固定的显示图钉，中键关不掉。关掉最后一个标签时留下一个新标签页。
- **标签里的页面** 顶部一行：后退、前进（没有可退的时候变灰）、位置路径（课程 › 功能 › 页面），右边是刷新、在右侧分屏打开、"只看这一栏"（有分屏时）。读讲义用窄栏，网格用宽栏。
- **在哪打开：** 普通点击在当前标签打开，进这个标签的历史；要打开的正是当前页面就不动。当前标签固定时，或 Ctrl+点击、中键点击，在新标签打开（就在当前标签右边）；命令面板里 Ctrl+Enter 在新标签打开。出处默认在右侧栏打开。拖动标签可以分屏。
- **后退和前进：** 页面顶部的按钮、Alt+←/→、鼠标侧键（Chrome、Edge；Firefox 不把侧键交给网页）。每个标签记最近 50 步。
- **记住位置：** 切走的标签不卸载，滚动位置、展开的内容、输入框里的字都在。当前页前两页、后一页也留着；更早的记下滚动位置，回来时等内容出来再滚过去（最多等 4 秒，先动了滚轮就不再滚）。最近用过的 8 个标签不卸载，更早的只记位置；刷新浏览器后恢复的标签，第一次切过去才加载。不在前台的页面收到推送不刷新，切回来时有变化再刷新一次。
- **新标签页**（"+"）：继续学习（由 planner 提供）、最近打开的 12 个页面、本界面的页面入口。
- **右侧栏** 分"提问"和"出处"两个视图，顶部切换。提问是侧边提问，任何页面都能打开（主界面上先选问哪门课），选中内容后点"提问"（讲义的浮条）或"就此提问""就这题提问"直接打开；出处是资料原文（Ctrl+点击出处标签则在新标签打开），可以"在标签页打开"或关掉。两个视图各记各的宽度（提问默认 380、出处默认 520 像素），拖左边缘调整、双击恢复；窗口窄于 1000 像素或会把分屏挤窄时，浮在页面上。
- **状态栏：** 各单元放进来的简短状态（阶段进度、待作答测试、下一步），点了去对应页面。
- **深浅色** 跟随 DSH 的外观设置，图标栏底部"外观"可以切换。
- **界面偏好**（侧栏开哪个、是否收起和宽度、右侧栏、每个界面的标签和历史、滚动位置、最近打开、上次所在课程）记在浏览器本地；学习数据只在文件和数据库里。

### 手机（窗口窄于 600 像素）

窄于 600 像素时外壳换成手机布局，600 像素以上不变。页面内容按所在栏的宽度排（`@container`），不另做手机版。

```
┌──────────────────────────────┐
│ ←  →  静水压强        搜 问 [1] │  每个标签页面顶部的一行；[1] 是标签数
├──────────────────────────────┤
│                              │
│  页面内容                      │
│                              │
├──────────────────────────────┤
│ 流   进度  讲义  测试  批注  ⋯  │  底部导航栏，图标下写名称
│ 课程                     更多  │
└──────────────────────────────┘
```

- **底部导航栏代替图标栏：** 课程切换、放得下的功能（每个按钮约 60 像素宽，390 像素放 4 个），最后是"更多"：放不下的功能、底部那几个工具入口（设置）和外观。每个按钮在图标下面写名称（手机没有悬停）；角标照常显示，"更多"里有待办时"更多"带一个点。点功能图标的规则和侧栏浮起时一样：有侧栏内容的弹出侧栏，没有的直接打开页面。
- **顶部一行：** 不显示标签栏。每个标签页面顶部那一行是后退、前进、当前页面的名称，右边是搜索、提问和标签数。点标签数列出所有标签（点了切换），下面是新标签页、刷新、固定、关闭、关闭其他，有分屏时还有"只看这一栏"。手机上不提供分屏和拖动标签。
- **侧栏** 从左边浮出，最宽 360 像素，右边留一条，点了收起；**右侧栏**（提问、出处）盖满底部导航栏以上的整块。在底部导航栏点功能、或在标签里打开一页时，右侧栏收起；打开提问时，浮着的侧栏收起。
- **状态栏** 不显示（阶段进度、待作答、下一步看课程进度页和角标），只有推送断开时显示一行"正在重连"。
- **手指操作：** 按钮 40 像素高，小按钮、图标按钮、列表行和菜单项至少 36 像素；输入框用 16 像素字（iOS Safari 遇到更小的字会在聚焦时放大页面）；触屏上不显示键盘快捷键提示。
- **触屏选中文字：** 手指长按、拖动选区都不产生 `mouseup`，所以在粗指针（`pointer: coarse`）上，共享的 Markdown 在选区停下约 0.4 秒后报告选区；讲义的"提问 / 批注"浮条放在选区下方，让开系统的复制菜单。

## 前端方案

- 用 DSH `web-app` 组合的服务端（HTTP 服务、认证、会话接口）负责模型、会话、工具和 Agent 循环；前端跑在 DSH 的客户端内核上（启动加载、连接认证、会话流、热重载）。DSH 的渲染器只渲染一个 `root` 插槽，外壳占了它就拥有整页；组合包关掉 DSH 自己的界面插件，只留提供设置表单服务的 `ui-settings`。外壳和各单元的页面都是我们自己的前端插件。
- 前端零件：停靠布局用 dockview，知识图谱用 sigma.js（布局 d3-force），原文 PDF 用 pdf.js。React 版本跟随 DSH（18）。dockview 的容器有 `contain: layout`，里面的 `position: fixed` 会相对它定位，所以弹出的菜单不能靠 fixed 跳出停靠区。
- 页面用共享的页面骨架（`Page`、`PageHeader`、`Section`），控件用 `kit/client` 的共享设计控件。
- **页面数据跟着它的身份走：** `useLoad` 的依赖项说明这是哪一份数据。同一份数据刷新时旧内容留着，失败也留着；依赖项一变，旧内容从那一次渲染起就没了。
- **断线后整体重读：** 推送不回放。恢复后（连上半秒才算，快速断开恢复只算一次）外壳发 `learning/feed-resumed`：看得见的页面立即重读，看不见的回到前台时重读。
- **聊天用 DSH 的会话流（`SessionEventStream`）：** 它负责重连，每次恢复后给一份完整的窗口，页面整份替换，不重复也不缺。显示的内容和"老师在不在回答"都从事件算出来，不会一直停在"正在思考"；连接断了在输入框旁写"正在重连"，两者分开。顶部的"加载更早的消息"按 DSH 的分页往前翻，读的位置不动。
- **外来内容不执行、不自动联网：** 共享 Markdown（`client/html.ts`）渲染的讲义、资料预览、模型回复和网页正文最后都经 DOMPurify 净化：去掉脚本、事件属性、框架、表单、样式标签和图片；链接只放行 `http`、`https`、`mailto`，其他只留文字，外部链接新窗口打开、不带来源；外部图片显示成"图：…"链接，点了才打开；内联样式里带 `url()` 的去掉。公式（KaTeX 的 MathML 源码和 SVG）、出处标签、表格、折叠引文和裁出的图照常显示。外壳另给页面加一条内容安全策略（CSP）：不执行内联脚本和 `javascript:` 链接，不加载插件对象，图片只从本机加载。

## 键盘和读屏

只修了审查实测到的几处，用脚本核对过，没有用读屏软件听过。

- **菜单：** 焦点进第一项，方向键、Home、End 和首字母移动真实焦点；Esc 关闭并把焦点还回去。右键菜单一样。
- **命令面板（Ctrl K）：** 真的模态：面板外 `inert`，焦点一直在搜索框，Tab 不离开，任何位置按 Esc 都关闭，焦点回到打开前的地方。搜索框是 `combobox`，用 `aria-activedescendant` 指向当前选项。
- **侧栏分隔条：** 可以聚焦，左右方向键一步 16 像素（Shift 48），Home、End 到最窄和最宽。

## 视觉规范

规则在 [packages/AGENTS.md](../../packages/AGENTS.md)"前端"和 `learning-ui-review` 技能里，这里只列结论：颜色和字号只用 `shell.css` 的 `--la-*` 变量，浅色、深色各一套；页面的窄屏样式用 `@container` 按所在栏的宽度写（分屏的一栏、右侧栏和手机共用），固定宽度的控件不会超出所在的栏，提示框（`Callout`）的按钮在 560 像素以下的栏里放到文字下面；手机布局由外壳在 `.la-app` 上标 `data-layout='phone'`，只有外壳的样式用它；字号 9 档（11、12、13、14、15、16、18、24、30），字重只用 400、500、600；Lucide 线条图标，不用 emoji；全部控件用共享设计，难撤销的操作用 `ConfirmButton` 原地二次确认；列表行的操作区按固定位置排列，缺了的按钮也留出位置。

## 数据与接口

- **前端服务** `learnShell`（契约 §7.4）：登记图标栏按钮和角标、打开页面（`OpenOptions`：`title`、`newTab`、`split`、`side`）、`usePage()`、当前页面和界面、进出课程、选中内容、推送连接、`call`、`Markdown`、`Figure`。
- **插槽：** 外壳声明 `learning.page`、`learning.panel`、`learning.new-tab`、`learning.status`、`learning.side-chat`、`learning.figure`。
- **共享控件**（`kit/client`）：页面骨架、按钮（`opens` 让中键也能新标签打开）、`ConfirmButton`、`ContextMenu`、`Slider`、`Tag`、`PickButton`、`FileDrop` 等；`useLoad` 按 `usePage()` 的 `visible` 决定要不要随推送刷新。
- **界面偏好的键：** `shell:tabs:<界面>`（标签和历史）、`shell:panel:<界面>`、`shell:folded:<界面>`，以及滚动位置、最近打开、右侧栏的视图和宽度。
- **选区**（`client/selection.ts`）：页面上选中的文字按服务端读 Markdown 的方式还原（公式取 `$…$` 源码，出处标签不算），批注和侧边提问共用。

## 关键决定

- **两级界面：主界面（多门课程）和课程界面；布局参考 VSCode 和 Obsidian**（10-03，你）。
- **前端是我们自己的产品，不在 DSH 的界面上小修小补，DSH 只当运行时**（10-03，你）：DSH 的界面围绕"对话 + 写代码"设计，我们的核心是"课程 + 教材 + 知识图"。视觉参考 DSH 的简约风格，可以复用它的设计变量（MIT）。只复用不限制我们功能的内核零件。
- **先做 Web 版，之后用 Electron 包装成桌面版**（10-03，你）：DSH 自己的桌面版也是这么做的。
- **用 DSH 的客户端内核，前端插件占 `root` 插槽接管整页**（10-03，阶段 0 调研和实测）。放弃了独立的 Vite 应用（直接调 DSH 的 HTTP 和 WebSocket 接口），留作内核处处受限时的备选。
- **图标用 Lucide 线条图标；全部交互控件用共享设计；难撤销的操作原地二次确认**（10-04，你的试用反馈和 Claude 审美复核）。
- **字号统一为 9 档，字重只用 400、500、600**（10-05，Claude）：没有照搬 DSH 的"字重不超过 500"，中文在 Windows 上只有常规和粗体两种显示，500 看起来和常规一样。审美方向由 Claude 决定（10-05，你："审美取向暂时你来决定就行"）。
- **窄窗口按每栏至少 360 像素安排**（10-05，你："都按你方案修"）。
- **图标栏 + 可展开的侧栏；标签栏在最上面，位置路径和后退前进在每个标签的页面顶部；默认在当前标签打开，每个标签有历史；后台标签和前后几页不卸载；出处在右侧栏看**（10-12 你的试用反馈，10-15 定方向，10-16 Claude 按调研细化）。放弃了 VS Code 的预览标签、用浏览器历史做后退、Logseq 式右侧栏叠放。
- **图标栏只有图标；主界面的"首页"图标直接打开首页，不做课程列表侧栏**（10-16，你："正常只有图标"）：课程切换已经在图标栏最上面。
- **收起侧栏后，点图标直接打开页面，不再展开侧栏**（10-16，你的建议）：收起是你的选择，要单独记下来；再点当前页面的图标或"展开侧栏"才展开。
- **窗口窄于 600 像素换成手机布局：底部导航栏、标签数按钮、盖住页面的两侧栏**（11-01，你要求做移动端适配；Claude 按调研定细节，见 [research.md §5](research.md#5-手机上的布局11-01)）：600 像素是安卓"紧凑窗口"的界线，底部导航栏是这个宽度的通行做法，标签数按钮照 Obsidian 手机版。底部按钮写名称，和"图标栏只有图标"不同，因为手指不能悬停看名称（11-01，你："名称保留"）。放弃了底部栏横向滚动放全部图标（滚出去的看不到）、汉堡菜单（多点一次）、手机上保留标签栏（一个标签不到 100 像素）、单独做手机版。
- **渲染出口统一用 DOMPurify 净化，链接协议另加白名单；CSP 用 meta 标签加**（11-02 审查 SEC-01）：Marked 不负责净化；正则挡不全编码和换行的变体；资料解析结果里有合法的表格 HTML，不能关掉 Marked 的 HTML；模型回复和 PDF 解析同样可能带 HTML，只净化网页来源不够。DOMPurify 的地址检查放行相对路径，所以链接另判协议。DSH 的页面响应不带 CSP，设置表单用 `new Function` 生成，所以策略由外壳以 meta 标签加，允许 eval。
- **图标栏只让功能图标那一列滚动**（10-16，Claude）：整个图标栏可以滚动时，从里面弹出的菜单被裁成图标栏那么宽的一条；dockview 的 `contain: layout` 又让 fixed 定位跳不出停靠区。

## 已知限制与以后再做

- 消息刚发出去 DSH 就被结束：页面可能写"发送失败"并把字放回输入框，而消息其实已经到了 DSH，重启后会被回答；这时再发一次会和它一起回答。
- 手机布局只在 headless Chromium 的触屏模拟里看过，还没在真手机上看过：地址栏伸缩、软键盘盖住输入框、iPhone 底部横条的留白。
- DSH 只监听本机（127.0.0.1），手机要访问得把 DSH 开到局域网上，超出"只在本机用"的范围，没有做；现在用电脑浏览器的手机模拟或把窗口拉窄来用。
- 平板竖屏（600–1180 像素）沿用桌面布局，侧栏浮起，但按钮没有放大。
- 内容安全策略允许 eval（DSH 的设置表单要用），也不限制网络连接和框架；页面开头 DSH 自己的启动脚本在策略加上之前已经运行。

- 测试进行中锁定主区还没做：设计是主区锁定为测试页，讲义和侧边会话按目标说明里的工具条件受限（现在只有侧边会话按测试限制，见 [sidechat](../sidechat/design.md)）。

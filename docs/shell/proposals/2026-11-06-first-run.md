# 首次启动引导

## 问题

11-06 你试装知微后说：引导太硬，是原生窗口；也没引导配置密钥，打开后其实没法直接用。

现在的第一次启动：外壳先弹系统对话框问学习库放哪里，按钮是"使用这个位置 / 选择其他文件夹 / 退出"，说明文字挤在对话框里；然后直接进主界面。没有模型密钥时，新建课程、和主老师说话都会失败，学习者要自己找到设置页、在一长串设置里找到 DeepSeek 卡片。

## 方案

引导放进知微自己的界面里，分三步，和工作台同一套视觉：

1. **欢迎和学习库。** 一句话说明知微做什么；学习库位置默认 `文档\学习库`，旁边"换个位置"打开文件夹选择框。说明学习库是普通文件夹，可以用 Obsidian 打开、自己备份，卸载不删。
2. **连接模型。** 只放 DeepSeek 一张卡片：密钥输入框、"获取密钥"链接（DeepSeek 开放平台）、"测试连接"。测试通过才能"下一步"；其他厂商和中转站留一句"用别的模型服务，去设置页添加"。复用设置页的密钥保存和测试连接。
3. **可选服务。** MinerU 密钥（导入 PDF 时用，会上传 PDF 原件，可以跳过，以后导入时再提示）；完成后回到主界面，"新建第一门课"高亮。

谁来显示：

- **桌面版：** 外壳不再弹原生对话框。第一次启动先用默认学习库启动 DSH，引导在窗口里显示；在第 1 步换了位置，外壳记下新位置、用它重启 DSH 再回到引导第 2 步。页面通过 Electron 的 preload 调用外壳的两件事：打开文件夹选择框、换学习库。
- **网页（开发和验收）：** 没有外壳，第 1 步只显示当前学习库位置，不能换。
- **什么时候显示：** 没有任何能用的模型服务（DeepSeek 没有密钥，也没有添加别的厂商）时，打开知微就进引导；配好以后不再出现。中途关掉的，主界面顶部留一条"还没连接模型，去连接"。不另存"已完成引导"的标记，按有没有密钥判断，删了密钥会再看到。

自动更新同时补上看得见的反馈：发现新版本就在窗口底部提示"正在下载 0.1.x"和进度，下载失败说明原因并能重试；设置页"关于"里显示当前版本和"检查更新"。

## 放弃的方案

- **保留原生对话框，只把文字改好：** 系统对话框改不了样式和布局，也放不下密钥输入和测试连接。
- **外壳自己画一个引导页（DSH 启动前）：** 要在外壳里重做一套表单和样式，密钥也得在 DSH 起来之前另存一份；放在工作台里能直接用设置页现成的保存和测试。
- **引导里列出所有模型厂商：** 第一次只要能用起来，选择太多反而卡住；DeepSeek 是默认模型，其他厂商在设置页。

## 验收标准

1. 全新安装后打开知微，不弹系统对话框，窗口里显示引导第 1 步；默认学习库位置正确，"换个位置"能选文件夹，选完后学习库确实换了（新文件夹里出现 `.learning`）。
2. 第 2 步填错密钥，测试连接说明失败原因；填对后能下一步。
3. 跳过 MinerU 能完成；完成后主界面能新建课程、主老师能回复。
4. 中途关掉再打开，还从引导开始；配好后再打开直接进主界面。
5. 网页版（3182）没有密钥时也显示引导，第 1 步不能换位置。
6. 装着旧版本时，新版本开始下载就有提示和进度；断网时提示下载失败、能重试。
7. `pnpm e2e` 覆盖：没有密钥进引导、填密钥后进主界面。

## 风险

- **换学习库要重启 DSH：** 重启期间页面断开几秒，引导要能接上；已经在旧位置建了课的学习者不会进第 1 步（有密钥就不显示引导），换位置走设置页，这次不做。
- **测试连接走真实 DeepSeek：** 自动测试不能调用付费服务，e2e 用假模型服务的地址和密钥。
- **国内下载 GitHub Releases 可能很慢：** 246 MB 的更新包可能下很久或失败，这次先把进度和失败显示出来，要不要加国内镜像以后再定。

# 页面跟上当前课程和最新数据：切课、重连、长会话

> 来源：11-02 的外部审查（[报告](../../history/2026-11-audit/report.pdf)，括号里是报告的编号）。涉及外壳、`kit` 的共用前端代码、侧边会话和资料库的前端。`useLoad` 空数组订阅了所有事件（FE-05）已经修好。修复顺序见 [现在](../../now.md#修复顺序)。

## 问题

- **切到 B 课，右侧还是 A 课的侧边会话，还能发消息（FE-02）：** `CourseSideChat` 没按课程加 `key`，右侧栏的插槽只换参数、不重建；`useLoad` 换依赖重新加载时保留旧数据，加载失败也保留，而且侧边会话不显示加载错误。于是在 B 课能把问题发进 A 课的会话、结束 A 课的会话并写 A 课的总结；B 课加载失败时 A 课的会话一直留着。
- **后台页面补标题时抢走当前标签（FE-03）：** 资料和讲义在后台标签里读到标题后调用 `frame.setTitle`，外壳的 `retitle` 走 `setTab`，`setTab` 会激活那个标签。你正在作答，后台的书名一回来就跳走。
- **推送断线重连后，断线期间的变化不补（FE-04）：** 推送通道重连后只把状态灯改回"已连接"；服务端的事件没有序号，新连接只发一个 `ready`。断线期间导入完成、交卷判分、批注改了，页面一直显示旧状态。
- **聊天流断了不重新订阅（FE-06）：** 主老师和侧边会话的聊天组件只调一次 `remote.session.follow`，流断了只设错误；再发一条消息会清掉错误、进入"等待回复"，但收不到回复。在回复中途断开时"等待回复"不复位。DSH 自己的会话流组件处理了重连，我们的组件没有用。
- **聊天只显示最近 50 条（FE-07）：** DSH 默认只返回最近 50 条消息，我们的组件不读"还有更早的"标记，也没有"加载更早"的入口。磁盘上的记录没丢，但目标协商这类早期对话在页面上看不到了。
- **讲义和题目里的插图一直占着 PDF（FE-08）：** 插图组件用模块级的缓存保存打开的 PDF，只在失败时删除，关掉页面也不释放；资料阅读器已经有按引用计数借用、30 秒不用就释放的共享实现，插图没用它。

## 方案

1. **课程是数据身份的一部分（FE-02）：** 侧边会话按课程加 `key`，草稿、总结、未发送的输入都按课程分开；`useLoad` 区分"同一份数据刷新"（保留旧数据）和"换了一份数据"（先清空，旧数据不能再用于写操作）；侧边会话显示加载错误和重试；发消息、结束会话前核对会话属于当前课程。
2. **改标题不切换标签（FE-03）：** 外壳把"改标题和参数"和"导航"分开：`retitle` 只改标题，不激活、不写最近访问、不动前进后退的历史。
3. **重连后整体重读（FE-04）：** 每次收到 `ready`（包括重连），外壳发一个"全部过期"的通知：看得见的页面立即重读，看不见的标为过期、回来时重读；加一点去抖，快速断开恢复不引起刷新风暴。暂不做事件序号和回放。
4. **聊天流能重连（FE-06）：** 换用 DSH 的会话流组件（`SessionEventStream` 或同类），或者在载体恢复后按序号重新订阅、补齐消息。"连接状态"和"老师在不在回答"分开显示；断开时输入框旁提示"正在重连"，发送成功不掩盖仍断开的订阅。
5. **加载更早的消息（FE-07）：** 用 DSH 协议的分页字段（`hasMore` 和序号游标），在会话顶部显示"加载更早"，加载后保持滚动位置；处理重开时已经生成到一半的回复。
6. **插图借用共享的 PDF（FE-08）：** 插图改用资料阅读器的 `borrowDocument`，卸载时归还；同一本 PDF 阅读器和插图只打开一次；并发绘制设上限。

## 放弃的方案

- **切课时整页刷新：** 打断其他标签页的阅读和作答。
- **给推送事件加序号和回放：** 单用户本机，重连后整体重读足够，做回放要维护事件存储。
- **聊天一次读出全部历史：** 长会话一次读完会慢，分页更稳。

## 验收标准

1. A、B 两课快速切换，B 课加载延迟或失败：B 课页面不显示也发不进 A 课的会话；两课的草稿和上次总结不串；回到 A 课能恢复 A 课的会话。
2. 后台标签补标题、历史页面补标题，都不改变当前标签和焦点。
3. 断开推送，期间用另一个连接完成导入、交卷、改批注，恢复后不用任何操作页面就一致；快速断开恢复不会成倍订阅或连续刷新。
4. 老师回复中途断网、恢复后新旧消息补齐、不重复；DSH 重启后不关页面也能收到下一次回复；不会一直停在"等待回复"。
5. 120 条消息的会话能一页页加载到第一条，刷新后照样能翻，加载上一页时滚动位置不跳，失败能重试。
6. 打开、关闭多本书的插图后，超过释放时间 PDF 文档数回落；同一本书在阅读器和插图里只打开一次。
7. 这些场景写进浏览器自动测试（见 [CI 和依赖](../../core/proposals/2026-11-02-ci-and-dependencies.md)）；`pnpm typecheck`、`pnpm test`、`pnpm build` 通过，按 `learning-ui-review` 截图核对改过的界面。

## 风险

- DSH 的会话流组件是它的客户端内核的一部分，换用时要按本机 `0.2.0-rc.2` 的真实接口来，不凭文档印象。
- "全部过期"会让一次重连触发所有可见页面重读；页面多时测一下请求数。

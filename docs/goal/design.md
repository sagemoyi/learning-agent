# 目标（goal）

> 代码：[`packages/goal`](../../packages/goal) · 接口：[契约](../stage0/contracts.md) §4.3、§5.1 · 做深调研：[research.md](research.md)

目标负责和你商量"学来做什么、要做到什么程度、怎么验证"，写成一份目标说明，并管理它的版本。后面的路线、测试和教材都以它为准。

## 目标确认（Agent 同时在调研）

**协商方式：**
- 你先说一个模糊的愿望。
- Agent 不发长问卷，而是**先给出几个候选终点**，例如"科普级理解 / 能做题 / 能用于工程"，每个都配上"学成后你能做什么"的样例，由你挑选或修改。
- Agent 只追问会改变路线的问题（比如"想做应用还是做研究"），不问"你是视觉型还是听觉型"这类问题。

**产出目标说明（六要素）：**
- 目的
- 使用场景
- 学成后能做什么
- 要做到什么程度
- 怎么验证
- 边界：不学什么、测试时允许用什么工具、打算投入多少时间
- 可选：最后期限、考试档案（见下文）

你确认后目标说明生效。之后要修改就走[修改流程](../journey.md#所有修改都走同一条路)，并保留版本。

**同时进行的调研：** Agent 先查资料库，不够时再按"来源清单"联网找权威资料（做法见 [library](../library/design.md)"联网找权威资料"），然后搭出**初版知识模型**，并收集**题源**（教材习题、往年题、公开课作业）。这门课的权威来源清单也在这一步确定，由你确认。

## 有考试的课程：考试档案

报告里的"考试类目标"并不是另一个产品版本，而是给目标额外加的几条要求。所以我们只有一套流程。确认目标时，如果发现有考试，就给目标挂上**考试档案**，流程中相关的环节会自动多做一些事；没有考试，这些都不出现。

**考试档案的内容：**
- 考试范围（文字，加骨架教材的小节号）
- 题型和分值
- 成绩构成（例如平时 30%、期末 70%）
- 考试日期
- 考试条件：开卷还是闭卷、能不能用计算器和公式表、考试时长
- 往年题
- 你的侧重：只求通过、兼顾分数和理解，还是以理解为主

一切以官方原文为准，比如学校的教学大纲和老师公布的考试范围。考试日期写在考试档案里；"最后期限"是你自己另定的完成日期，可以不设。

**挂上考试档案后，各环节多做的事：**

| 环节 | 多做什么 |
|---|---|
| 目标确认 | 问你的侧重：只求通过、兼顾理解，还是以理解为主。报告提醒过，考试范围和真正有用的能力不完全重合，不能让"考试"悄悄替代你真正的目的 |
| 知识模型 | 节点上标出"考试范围内/外"；有些节点不在考试范围里，但对理解有帮助，会单独标出来，学不学由你决定 |
| 题库 | 往年题列为一级题源；阶段测试的题型向真题靠拢 |
| 临近期限 | 加做模拟考：限时、整卷，格式与真题一致 |
| 复盘 | 按考试的板块报告准备情况，比如"传热部分的计算题还不稳" |
| 排期 | 只按最后期限判断能不能赶上（见 [planner](../planner/design.md)） |

化工原理就属于这种情况：目标是"期末考试 + 真正理解"，学校的往年题是最好的题源。

- **有期限时只记一个最后期限，不排死日程**（10-03，你）。

- **B、C 一起做**（10-08，你）。细节由 Claude 按调研定：候选终点不另存数据，选择就是一条消息；资料清单写在目标说明里，增减不让已确认的目标回到草稿；考试范围加"范围外但有助理解"一档，按小节标时保留它；阶段对应目标条目按键记在阶段上；倒计时只说剩多少时间和阶段进度，两个日期取较早的。

## A 批：可信、可改，接到测试条件

依据[调研](research.md)第 6、7 节。

### 目标说明里多了什么

- **"能做"条目：** 每条有一个短键（`c1`、`c2`……），老师在简报里看得到，你看不到。改写文字时键不变；删掉的条目，它的键不会再分配给新条目。以后的阶段设计书和结课检验按键引用（C 批）。每条还可以单独写"怎么验证"。
- **每周投入：** 文字之外记一个小时数区间。老师写"每周 4–6 小时"这样的文字时，程序自动读出区间。
- **事实的来源：** 测试条件、每周投入、最后期限，以及考试档案的日期、范围、题型和分值、成绩构成、考试条件，各记一个来源：
  - 官方：从本课资料里读到的，必须附资料片段，页面上显示"依据《书名》"和页码；
  - 你：你说的，或者你在页面上确认、修改过的；
  - 推测：老师没有依据时写下的，页面标"待确认"。没写来源的事实都算推测。
- **版本号：** 每写一次加一。旧的 `goal.md`（"能做"是纯文字、没有版本号）照常读出：条目按顺序编键，版本号按已有的写入次数算，下次写入时补齐。

### 老师怎么写

- `save_goal_draft` 写整份目标，可以带考试档案和事实来源；同样的"能做"文字保留原来的键。
- `revise_goal` 带版本号，只改传入的字段：
  - "能做"传完整列表，带键的是改写，不带键的是新条目，没列出的删除；
  - 考试档案按项合并，还没有档案时要写全范围、考试条件和侧重；`removeExam` 去掉档案。
- **什么时候回到草稿：** 已确认的目标改了目的、场景、能做、程度、验证方式、不学、考试侧重或说明正文，回到草稿等你重新确认；只改事实（测试条件、时间、日期、考试档案的其他项），仍是已确认的。内容和当前版本相同时不写新版本。
- **程序检查**（只检查老师的写入）：
  - 退回：没有"能做"；某条以"理解、了解、熟悉、掌握、知道"这类词开头；没写验证方式；学习者能读到的文字里有内部编号；标为官方的事实没有附片段，或片段不在本课资料里；每周投入的最少小时数大于最多小时数。
  - 提醒但照常保存：提到了考试却没有考试档案；验证方式里的百分比门槛没写依据；给没有值的事实写了来源。

### 页面

- **草稿：** 全部展开。待确认的事实旁有"待确认"标记、"对"和"改"。确认框里写明哪几项是老师的推测，以及（改过的目标）和你上次确认相比改了什么、会影响哪些环节。
- **已确认：** 折叠成目的和几个标签（测试条件、考试日期、期限、"N 项待确认"、"老师改过 N 处"）。老师在你确认后只改了事实时，展开能看到改了什么，点"知道了"。
- **你直接改事实：** 测试条件、考试条件（含考试时长）、每周投入、最后期限、考试日期可以直接改；日期接受 2027-01-10、2027/1/10、2027年1月10日。改完记为你的，不需要再确认目标，交回主老师。考试范围、题型这些只能确认，要改请告诉老师。
- **版本记录：** 每一版是谁、什么时候、为什么改的。

### 测试条件

`start_test` 不写开闭卷时：阶段测试和模拟考按考试档案的考试条件（模拟考带考试时长），其他测试按目标里的默认条件；老师写了开闭卷，只覆盖这一项。没有目标说明时用闭卷、可用计算器、不带公式表。

- "能做"写成"理解静水压强"会被退回，并说明怎么改。✓
- 老师只改期限，其他字段和"能做"的键都不变；改写"能做"时键不变，新条目不复用删掉的键。✓

- 你在页面上改考试日期，这条事实变成"你确认的"，目标仍是已确认的，主老师收到一句进度通知。✓

## B 批：候选终点卡片和资料清单

本节是 B 批的设计和验收标准（10-08，Claude 按[调研](research.md)第 4、7 节和已确认方向细化），实现前写定。

### 候选终点卡片

- 老师用 `offer_goal_options` 给出 2–4 个候选终点，每个写：名称、学成后能做的 1–3 件事、可选的一道样题（从本课资料里取，带出处，写明选这个终点时这道题能做到哪一步）、时间上的取舍、学成后的感觉（只帮你想象，不算证明）。可以标一个推荐项。
- 程序检查：个数、每项至少一件能做的事、样题的片段属于本课资料、文字里没有内部编号。不合格的调用不显示卡片。
- 卡片显示在主老师对话里这次工具调用的位置。每张卡片有"选这个"（直接发"我选「……」。"）和"改一改"（把这句话放进输入框，你补充后再发）。你回复以后，卡片标出你选的那个，按钮不再可用。
- 卡片不另存数据：选择就是一条普通消息，老师按它起草目标说明，并把候选终点和你的选择写进说明正文。

### 资料清单

- 目标说明里增加"资料清单"：老师列出这门课还需要的资料，每份写是什么、为什么要、在资料库里算哪一类（骨架教材、参考、往年题），以及由谁来找（你提供，或老师联网找）。本课已有的资料自动列出，不用写。
- 每份资料的状态：已有（对应到本课资料库里的一份）、等你提供、老师会联网找、你说没有。
- 你在进度页上：去资料库加入资料，然后在清单里选"就是这份"；或者点"没有这份"。改动记为你的，不需要再确认目标，并交回主老师。往年题对应上资料后，自动记入考试档案的往年题。
- 老师修订清单时，同名的条目保留已对应的资料和"没有"的标记。清单的增减不让已确认的目标回到草稿。
- 简报里列出清单和每份的状态。确认目标时，还有资料没到也可以确认，确认框里写明还差几份。

### 从大纲里取考试档案

- 老师在目标确认这一步先看资料库里有没有教学大纲、考试通知；没有就列进资料清单请你提供。拿到以后读原文，把考试档案的事实改成官方并附片段（A 批已支持）。
- 你把一份资料对应到清单里的"教学大纲"后，老师收到通知；下一次对话时据此更新考试档案。

### B 批验收标准

- 合成课程里，老师的候选终点以卡片显示，样题能打开原文；片段不在本课资料里的调用被退回，不显示卡片。✓
- 点"选这个"后，老师在下一轮按选择起草目标，不重复提问；卡片标出所选项。✓
- 老师列出"教学大纲（你提供）""往年题（你提供）"；你加入一份合成大纲并选"就是这份"后，清单显示已有，老师收到通知；"往年题"点"没有这份"后显示"你说没有"。✓
- 老师修订清单时，已对应的资料不丢。✓
- 自动测试只用假模型；真实模型只在 3182 的合成课程上走一遍。✓

## C 批：考试档案接到知识图、阶段和进度

本节是 C 批的设计和验收标准（10-08，Claude），实现前写定。往年题当题源、模拟考、按考试板块复盘留给 assess 和 curriculum 做深。

### 知识图上的考试范围

- 课程里的每个节点可以标：考试范围内、范围外但有助理解、考试范围外，或者不标。
- 老师用 `mark_exam_scope` 按小节标：节点在骨架教材里的出处落在这些小节的，标为范围内；有骨架教材出处但都在这些小节外的，标为范围外；没有骨架教材出处的不动，返回给老师逐个判断。按小节标不会改掉已标为"有助理解"的节点。老师也可以逐个指定。整批是知识模型的一组修改，可以在变更记录里整组撤销。
- 你在节点详情里可以改标记。"范围外但有助理解"的节点写明"学不学由你决定"：不学就用已有的"移出本课"。
- 课程知识图加"考试范围"筛选：只突出范围内，或只突出范围外，其余变淡（不重排）。节点的说明里写出它的标记。
- 简报里写各类各有几个、还有几个没标。

### 阶段对应目标条目

- 课程路线的每个阶段记下它支撑目标里的哪几条"能做"（按条目键）。老师在 `save_roadmap` 或 `save_stage_design` 里写；不存在的键被退回，并列出现有的键。
- 进度页目标区的每条"能做"后面写"第 1 阶段"这样的对应；排了路线却没有阶段对应的条目标出来。
- 简报的课程路线部分写出每个阶段支撑哪几条，以及目标里还没有阶段对应的条目。

### 距考试还有多久

- 有考试日期或最后期限时，调度在简报和进度页"下一步"里写"距考试（2027-01-15）还有 14 周，路线 3 个阶段已完成 1 个"。两者都有时看较早的那个；不到两周时按天说。日期已过就写"已过"。
- 只说剩多少时间和完成了几个阶段，不估算能不能赶上（等路线有了时间估计后由 planner 做深）。

### C 批验收标准

- 按小节标考试范围：出处在范围内小节的节点标为范围内，出处都在范围外的标为范围外，没有出处的列给老师；"有助理解"的标记保留；整组可以撤销。✓
- 你在节点详情里改标记，图上的考试范围筛选随之变化。✓
- 路线写了不存在的条目键会被退回；进度页每条"能做"后显示对应的阶段，没有对应的标出来。✓
- 有考试日期时，进度页和简报写出剩余周数和阶段进度；考试日期和期限都有时用较早的。✓

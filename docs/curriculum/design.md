# 课程设计（curriculum）

> 代码：[`packages/curriculum`](../../packages/curriculum) · 接口：[契约](../stage0/contracts.md) §4.3、§5.1 和 §11 · 调研：[research.md](research.md)

课程设计负责把目标变成可以学的路线：阶段、阶段设计书、课时和任务，以及阶段结束后的复盘、补课和结课。"课程进度"页是它的页面。

## 现状

- **骨架：**
  - 老师用工具保存课程路线（阶段标题 + 阶段目标）、阶段设计书、发布任务。
  - 阶段的状态依次是：计划中 → 设计中（设计书已保存）→ 设计已确认（开始生成教材）→ 待学习（第一个课时的教材就绪）→ 学习中（发布了第一个任务）→ 测试中（发布了阶段测试）→ 复盘中（阶段测试判完分）→ 已完成。
  - 一个课时对应教材的一个小节。你在进度页确认设计书后，按课时顺序自动生成本阶段教材；第一个课时就绪就可以开始学，后面的边学边生成。
  - 课程进度页：下一步、目标（确认后折叠）、任务、阶段时间线、测试。左侧栏的"课程目录"（阶段 → 课时，点课时打开教材）、状态栏的阶段进度也由它提供。
  - 你确认设计书、点"完成"任务时交回主老师。
- **阶段对应目标条目（goal C，已技术验收，待你试用）：** 每个阶段记下它支撑目标里的哪几条"能做"（条目键），老师在 `save_roadmap` 或 `save_stage_design` 里写，目标里没有的键会被退回。路线文件里写成目标条目的内容；进度页的目标区在每条"能做"后面写对应的阶段；简报写出每个阶段支撑哪几条，以及还没有阶段对应的条目。
- **阶段的核心知识点（assess B，已技术验收，待你试用）：** 老师在 `save_stage_design` 里写下本阶段的核心知识点，阶段测试按它们组卷，阶段前测也探这些。
- **A 批复盘决定下一步已技术验收，待你试用**（细节见下文"阶段复盘"和"调整路线"）：阶段测试判完分后，程序按核心知识点汇总复盘事实并给默认建议，老师写复盘，你在进度页决定先补课还是进入下一阶段；选补课时插入补课阶段；往前走时，没过的知识点记为风险、有对有错的记为待验证，带进下一阶段。路线开始后的调整要你确认。设计书和路线不能写总分过关线。
- **B 批补课单元已技术验收，待你试用**（细节见下文"补课单元"）：设计补课阶段时老师的简报带上上一阶段的复盘；补课课时的教材只讲没过的地方、换一种讲法；重测只考补课的知识点，上一阶段完整任务题没过时还要有一道新的完整任务题；补课后又没过时，复盘事实列出先修知识点的状态，由老师和你商量。
- **C 批结课已技术验收，待你试用**（细节见下文"结课"）：所有阶段完成后，程序按目标的每条"能做"出结课检验；老师按条目写课程报告（结果、依据、还缺的证据），课程标为"已结课"；进度页顶部显示课程报告。结课后加新的阶段，课程回到进行中。
- **还没做：** 路线上不给每个阶段排时间区间：[planner](../planner/design.md) 只按已学完阶段的用时估整体能不能赶上；结课后的复查由 planner 的复查建议照常安排（已结课的课程也建议）。

## 课程路线（粗略）

- 把目标切成若干**阶段**，每个阶段围绕一个"完整任务"来组织。这是报告里的 4C/ID 思路：学完一个阶段，你能完成一件完整的事，而不只是背下几个知识点。
- 路线只写到"阶段标题 + 阶段目标"这一层，**只有当前阶段会做详细设计**。后面的阶段会根据实际学习情况调整。
- 路线不写时间；能不能按期赶上（用区间表示）由 [planner](../planner/design.md) 估计。
- 阶段目标写要做到的事，不写"习题做对 80% 以上"这类总分过关线，程序会拒绝（阶段测试按核心知识点逐个看，见 [assess](../assess/design.md)）。
- 化工原理的阶段大致按教材章节划分（流体流动、流体输送机械、传热、蒸馏、吸收……以你的教材为准），教材是骨架。

### 调整路线

- **只改后面的：** `save_roadmap` 只写计划中的普通阶段。已经开始或完成的阶段、已经排定的补课阶段保持原样排在前面；老师又写了它们的标题时，程序退回并说明。
- **路线开始后要你确认：** 第一个阶段的设计书确认之前，路线还在成形，老师保存即生效。之后的调整要写理由，先存为"待确认的路线调整"：进度页的课程路线上方列出改前、改后和理由，你点"按新路线"才生效，点"保持原来的"就放弃。待确认时，"下一步"先请你看这份调整。
- **不能悄悄缩小范围：** 改完后，原来有阶段对应的目标条目必须仍有阶段对应；要去掉某一条，先和你修订目标（目标改动要你确认，见 [goal](../goal/design.md)）。
- **改名不丢对应：** 老师调整顺序时没写某个阶段支撑哪几条目标，就沿用同名阶段原来的；没有同名的，沿用它替换的那个阶段的。
- 计划中的阶段还没有文件，调整后它们的文件夹按新的序号和标题命名。

## 阶段设计（每个阶段一份，认真设计）

顺序很重要，这是逆向设计：
1. **先定阶段验收。** 学完这一阶段能做到什么，再加上阶段测试蓝图：考哪些节点、用什么题型、在什么条件下考、哪些是新题。
2. **再定内容。**
   - 列出要覆盖的知识节点。
   - 已经有独立证据的节点，压缩成回顾。
   - 之前暴露出来的薄弱点，重点展开：以前复盘带过来的风险和待验证知识点列在老师的简报里，设计书要写明怎么处理（放进哪个课时复习、前测探一下）。
   - 穿插前面阶段内容的复习。
3. **听取你的要求。** 比如"按我导入的那本教材的顺序和讲法来""多给例题""先做个小项目"。
4. **产出阶段设计书。** 一页纸，包括目标、节点清单、课时安排、测试蓝图和要用到的资料。你确认后，再生成本阶段的教材。

**测试蓝图只写考什么、怎么考：** 考哪些知识点、题型、条件和新题比例，不写具体题目、题号和答案，也不写总分过关线（程序会拒绝）。设计书是给你看的，不出现内部编号。题目在做阶段设计时就要为测试预留好（见 [assess](../assess/design.md)"练习题和测试题分开"）。

## 课时

一个阶段按小节推进，一个小节就是一个课时；具体怎么切分，在阶段设计时决定。一个课时怎么走见 [journey.md](../journey.md#一个课时怎么走)。课程进度页只回答两件事：学到哪了、接下来学什么；不同步学校的课表。

## 阶段复盘 → 决定下一阶段

- **程序先把事实摆好：** 阶段测试判完分、阶段进入"复盘中"后，老师的简报按核心知识点列出：
  - 测试结果（过了、没过、待验证）和题号；
  - 掌握状态和理由、有没有疑点；
  - 本阶段设计确认以来得到过几次帮助、侧边会话里问过几次、记下的误解；
  - 后面有几个知识点以它为先修；
  - 完整任务题和前面阶段的题的结果，以前复盘带过来的知识点这次对不对。
- **怎么算过没过：**
  - 某个知识点的新题都对，算"过了"；都没对（部分对也算没对），算"没过"；有对有错、或没答到新题，算"待验证"。完整任务题做错或部分对，也算没过。
  - 被停用的题不算证据，它考的知识点算"待验证"。
  - 有题等复核、有没处理的申诉、有题在核查中时，先处理，处理完才能保存复盘。
- **默认建议：** 有知识点没过、或完整任务题没过时，默认先补课（补没过的知识点；只有完整任务题没过时，补它涉及的知识点）；否则进入下一阶段，待验证的带进下一阶段。补课阶段里同一个知识点又没过时没有默认建议，由老师和你商量。
- **老师写复盘：** 老师先在对话里和你过一遍结果和依据，就没过的地方问一句当时怎么想的（不填表）；再用 `save_stage_review` 保存。复盘存在 `stages/<阶段>/review.md`，开头是程序写的结果表，后面是老师写给你的复盘：做得好的、要修的、为什么这样建议。建议和默认不同（或没有默认）时要写理由；建议补课时写补课阶段的标题和目标。
- **你来决定：** 进度页的这个阶段下面出现复盘卡片：哪些过了、没过、待验证，老师的建议和理由，可以展开全文。
  - 建议补课时，主按钮是"先补课"；也可以选"不补课，进入下一阶段"，二次确认时写明哪些知识点会记为风险。
  - 建议往前走时，主按钮是"进入下一阶段"；有没过或待验证的知识点时，也可以选"我想先补课"。
  - 你决定后阶段标为"已完成"，复盘末尾记下你的决定，老师收到通知继续。时间线上这个阶段下面写一行复盘后怎么走，旁边的"复盘"按钮可以再看全文。
- **带进下一阶段：** 你选择往前走时，没过的知识点记为"风险"，待验证的记为"待验证"；完整任务题没过时，待验证的也记为风险。下一阶段设计时简报列出它们，阶段测试里"前面阶段的题"先出它们。后面某次复盘里它作为核心知识点过了，或者这次复盘之后你独立做对、它的掌握状态变成"已独立完成"，就不再列出。
- **通过标准不是一个固定的数字。** 关键的先修知识点需要更多独立证据，复盘事实里标出了每个知识点后面有多少知识点以它为先修，老师据此提建议。

## 补课单元

- **它是一个阶段：** 你选"先补课"后，在刚复盘的阶段后面插入一个"补课"阶段，后面的阶段顺延一个序号，路线文件同步。补课阶段走普通阶段的流程：设计书 → 你确认 → 教材 → 课时 → 重测 → 复盘。时间线和路线文件里标"补课"。
- **范围窄：** 核心知识点就是要补的那几个，一般一两个课时，按它们所在的小节排。
- **不做前测：** 刚做完阶段测试，补课阶段直接开始。
- **设计：** 补课阶段在开场会话里设计，老师的简报列出要补的知识点、上一阶段的完整任务题有没有过、上一阶段复盘里老师写给你的那部分，以及设计要求：写清每个知识点错在哪、这次换什么讲法，不重讲整节，按要补的知识点所在的小节排一两个课时，重测要的题在你确认设计书前备好。
- **教材换讲法：** 补课课时的教材一次写完，不分部分：拿到的资料仍是这一小节的，另外加上上一阶段的复盘，要求只讲没过的地方——先点明错在哪、为什么容易错，再换一种讲法（拆开步骤、对照常见错误），用资料里的例题一步一步讲，已经会的一句带过。"读完就答"问这次补的地方。出处规则不变：资料里没有的操作建议标"待核实"。
- **重测：** 补课阶段的阶段测试只考补课的知识点，用没见过的测试预留题，不出前面阶段的题。上一阶段的完整任务题没过时，重测还要有一道没见过的完整任务题，备题不够时简报提示；完整任务题过了的，不要求。
- **第二次没过：** 补课阶段里同一个知识点又没过时，程序不给默认建议；复盘事实列出它的先修知识点和掌握状态，老师看先修是不是缺、题目有没有问题，和你商量：补先修、调整路线、修订目标，或者带着风险往前走（先做一两道短题验证也可以）。保存复盘时要写理由。

## 结课

- **什么时候：** 所有阶段（包括补课阶段）都完成后，"下一步"是"发布结课检验"。
- **结课检验：** 老师用 `start_test` 发布（种类 `final`），程序组卷：
  - 目标的每条"能做"至少一道没见过的测试预留题，考支撑这一条的阶段的核心知识点。完整任务题优先；已经选上的题覆盖了这一条，就不再加题。
  - 再加至多两道以前复盘带过来、还没独立做对的知识点（风险、待验证）。
  - 完整任务题排在最后。测试条件按目标（有考试档案时按考试条件），换题最多两次，只换没见过的题。
  - 没有对应阶段、或没有新题的条目测不到，发布时告诉老师。所有阶段完成后，简报提示哪些条目备题不够，老师先补题再发布。
- **结果按目标条目：** 一条的题都对算"做到"；有错的（部分对也算）算"没做到"。以前带过来的知识点单独列出对错。测试页的结果和老师收到的进度通知都按条目写。
- **课程报告：** 结课检验判完分、等复核的题和申诉处理完之后，老师的简报按每条"能做"列出事实：结课检验的结果和题号、支撑它的阶段的核心知识点和掌握状态、以前带过来还没独立做对的知识点。每条的结果是四种之一：
  - **做到了：** 结课检验的题都对，相关知识点都已独立完成；
  - **做到了，还缺证据：** 题都对，但有知识点还没独立做对过（只在帮助下做对，或者没测到）；
  - **还没做到：** 题有错；
  - **没测到：** 没有题。

  老师用 `save_course_report` 写报告，程序把"能做 | 结果 | 依据 | 还缺"这张表放在 `report.md` 开头；老师的正文写给你：学会了什么（说依据）、还缺什么证据、要注意什么、以后怎么复查。保存后课程标为"已结课"。
- **页面：** 课程进度页顶部出现"课程报告"：每条"能做"一个结果标签，还缺的知识点写在后面，可以展开全文；"下一步"显示"已结课"。
- **之后：** 想接着学，请老师加新的阶段，课程回到进行中；报告卡片改为"上次结课时"，新阶段学完要重新做结课检验，再写报告。学到的知识点留在全局知识模型里，其他课程可以复用；复查调度在 planner 做深时做。

## 关键决定

- **教材按阶段生成，每个阶段一份；每个阶段都有阶段测试；由复盘决定下一阶段怎么写**（10-03，你）。
- **每个阶段先定测试蓝图，再写教材（逆向设计）**（10-03，报告）。
- **一个阶段内按小节推进：每学完一小节就做小测和汇报，并记入课程进度**（10-03，你）。
- **阶段测试没通过时，默认先补课**（10-03，你）。
- **不同步课表：课程进度只显示学到哪了、接下来学什么**（10-03，你）。
- **设计书的测试蓝图只写考什么、怎么考，不写具体题目；写给你看的文字不出现内部编号**（10-04，Claude 验收：设计书列出了小测题目，教材因此泄题）。
- **阶段在第一个课时的教材就绪后就可以开始，后面的课时边学边生成**（10-04，第一次试用后 Claude 设计）。只认第一个课时：第一节失败、后面成功时，仍留在设计阶段，先处理第一节的失败。
- **做深方向**（10-09，Claude 按调研的推荐项定，你说一轮做深完再统一试用）：复盘由程序汇总事实、老师建议、你决定；没过默认补课，题目有问题的先核对；有对有错、证据不够的带进下一阶段；坚持往前走的记为风险；补课是插在后面的阶段，只补没过的知识点；路线开始后的调整要你确认，不能让目标条目失去对应阶段；设计书和路线不写总分过关线。放弃的做法：把补课课时加回原阶段（原阶段的测试和复盘会被重新打开）；补课不占序号（每处显示序号都要另算）；有对有错也补课（时间成本高，研究支持只补缺口）；路线调整一律直接生效（学习流程里路线属于大改动）。
- **A 批的细节**（10-09，Claude）：
  - 完整任务题部分对也算没过：完整任务是往前走的关口。
  - 被停用的题不算证据：题目有问题时，它测出的对错都不可信。
  - 补课阶段是排定的，路线调整不会改它；它的标题不用再写"补课"（页面已经标出），程序去掉开头的"补课："。
  - 往前走时把"没过"记为风险（完整任务题没过时，待验证的也算，见 C 批的细节）；你选补课时，补课阶段负责没过的知识点，待验证的仍带进下一阶段。
- **B 批的细节**（10-09，Claude）：
  - 补课课时一次写完、不分部分：补课只讲没过的地方，篇幅短；分部分写会按小标题把整节又写一遍。
  - 补课重测只在上一阶段完整任务题没过时才要求完整任务题：只补某个知识点时，再加一道综合题会让重测变长，测不到更多东西。
  - 复盘事实给没过的知识点列出先修状态：第二次没过更可能是先修缺口或题目问题，补同一种课多半无效。
- **C 批的细节**（10-09，Claude）：
  - 结课检验是单独的一种测试，不拿模拟考代替：模拟考按考试的题型组卷，不保证每条"能做"都有题。有考试的课程仍可以另做模拟考，结课检验的条件按考试档案。
  - 每条"能做"有一道题就算测到，已选的题覆盖了就不再加：结课检验不再把所有阶段测一遍。只靠一道题不够说明的，用掌握状态补充：题对了但有知识点从没独立做对过，写"做到了，还缺证据"，不算"做到了"。
  - 完整任务题没过、你仍选往前走时，它涉及的待验证知识点也记为风险：完整任务是往前走的关口，没过说明这些知识点合起来还用不出来。联调中完整任务题没过、往前走后只留下"待验证"，结课检验也就不会优先考它们。
  - 结课检验记下发布时的阶段：结课后加了阶段，旧的结课检验不再算数，学完新阶段要重新做。

完整的决定和来源见[决策记录](../decisions.md)。

## 待定问题

- **真实考试的成绩记不记：** 有考试档案的课程，考完后要不要记下真实成绩、怎么用，还没定；课程报告目前只依据结课检验和掌握状态。
- **复盘事实还没包括批注：** 批注单元做深后，复盘里加上"在教材上写了哪些批注、哪些是疑问"。

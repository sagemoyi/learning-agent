# 课程设计（curriculum）

> 代码：[`packages/curriculum`](../../packages/curriculum) · 接口：[契约](../stage0/contracts.md) §4.3、§5.1 和 §11

课程设计负责把目标变成可以学的路线：阶段、阶段设计书、课时和任务，以及阶段结束后的复盘和结课。"课程进度"页是它的页面。

## 现状

- **骨架：**
  - 老师用工具保存课程路线（阶段标题 + 阶段目标）、阶段设计书、发布任务。
  - 阶段的状态依次是：计划中 → 设计中（设计书已保存）→ 设计已确认（开始生成教材）→ 待学习（第一个课时的教材就绪）→ 学习中（发布了第一个任务）→ 完成。
  - 一个课时对应教材的一个小节。你在进度页确认设计书后，按课时顺序自动生成本阶段教材；第一个课时就绪就可以开始学，后面的边学边生成。
  - 课程进度页：下一步、目标（确认后折叠）、任务、阶段时间线、测试。左侧栏的"课程目录"（阶段 → 课时，点课时打开教材）、状态栏的阶段进度也由它提供。
  - 你确认设计书、点"完成"任务时交回主老师。
- **还没做：** 阶段复盘、补课单元、调整后续路线、结课与课程报告；路线上的时间区间估计。

## 课程路线（粗略）

- 把目标切成若干**阶段**，每个阶段围绕一个"完整任务"来组织。这是报告里的 4C/ID 思路：学完一个阶段，你能完成一件完整的事，而不只是背下几个知识点。
- 路线只写到"阶段标题 + 阶段目标"这一层，**只有当前阶段会做详细设计**。后面的阶段会根据实际学习情况调整。
- 时间只给区间估计，不给精确的小时数。
- 化工原理的阶段大致按教材章节划分（流体流动、流体输送机械、传热、蒸馏、吸收……以你的教材为准），教材是骨架。

## 阶段设计（每个阶段一份，认真设计）

顺序很重要，这是逆向设计：
1. **先定阶段验收。** 学完这一阶段能做到什么，再加上阶段测试蓝图：考哪些节点、用什么题型、在什么条件下考、哪些是新题。
2. **再定内容。**
   - 列出要覆盖的知识节点。
   - 已经有独立证据的节点，压缩成回顾。
   - 之前暴露出来的薄弱点，重点展开。
   - 穿插前面阶段内容的复习。
3. **听取你的要求。** 比如"按我导入的那本教材的顺序和讲法来""多给例题""先做个小项目"。
4. **产出阶段设计书。** 一页纸，包括目标、节点清单、课时安排、测试蓝图和要用到的资料。你确认后，再生成本阶段的教材。

**测试蓝图只写考什么、怎么考：** 考哪些知识点、题型、条件和新题比例，不写具体题目、题号和答案。设计书是给你看的，不出现内部编号。题目在做阶段设计时就要为测试预留好（见 [assess](../assess/design.md)"练习题和测试题分开"）。

## 课时

一个阶段按小节推进，一个小节就是一个课时；具体怎么切分，在阶段设计时决定。一个课时怎么走见 [journey.md](../journey.md#一个课时怎么走)。课程进度页只回答两件事：学到哪了、接下来学什么；不同步学校的课表。

## 阶段复盘 → 决定下一阶段

- **综合两类信息：**
  - 这段时间的学习过程：练习表现、用了多少帮助、在侧边会话里问了什么、写了哪些批注。
  - 阶段测试的结果。
- **给出结论和建议：** 逐个节点说明状态变化和理由，然后在以下几种做法中提出建议：
  - 进入下一阶段
  - 先插一个补课单元：**阶段测试没通过时默认这样做**
  - 调整后续路线
  - 重新审视目标
- **衔接下一阶段：** 你同意后进入下一阶段的设计，这次复盘的结论会写进新的设计书。
- **通过标准不是一个固定的数字。** 关键的先修节点需要更多独立证据。如果你坚持往前走也可以，但系统会标明风险。

## 结课

- 用目标说明里约定的验证方式做最终检验，通常是一个完整任务。
- 生成课程报告：学会了什么（附证据），哪些还有待验证。
- 学到的节点留在全局知识模型里，之后其他课程可以复用；`planner` 也会偶尔安排复查。

## 关键决定

- **教材按阶段生成，每个阶段一份；每个阶段都有阶段测试；由复盘决定下一阶段怎么写**（10-03，你）。
- **每个阶段先定测试蓝图，再写教材（逆向设计）**（10-03，报告）。
- **一个阶段内按小节推进：每学完一小节就做小测和汇报，并记入课程进度**（10-03，你）。
- **阶段测试没通过时，默认先补课**（10-03，你）。
- **不同步课表：课程进度只显示学到哪了、接下来学什么**（10-03，你）。
- **设计书的测试蓝图只写考什么、怎么考，不写具体题目；写给你看的文字不出现内部编号**（10-04，Claude 验收：设计书列出了小测题目，教材因此泄题）。
- **阶段在第一个课时的教材就绪后就可以开始，后面的课时边学边生成**（10-04，第一次试用后 Claude 设计）。只认第一个课时：第一节失败、后面成功时，仍留在设计阶段，先处理第一节的失败。

完整的决定和来源见[决策记录](../decisions.md)。

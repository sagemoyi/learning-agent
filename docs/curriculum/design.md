# 课程设计（curriculum）

> 代码：[`packages/curriculum`](../../packages/curriculum) · 调研：[research.md](research.md) · 契约：[contracts.md](../contracts.md)

## 概要

课程设计把目标变成可以学的路线：阶段、阶段设计书、课时和任务，以及阶段结束后的复盘、补课和结课。每个阶段先定阶段验收和测试蓝图，再写讲义（逆向设计）；复盘由程序汇总事实、老师给建议、你决定。"课程进度"页和"课程讲义"侧栏是它的页面。进度页只回答学到哪了、接下来学什么，不同步学校的课表。

## 阶段和进度页

- 阶段的状态：计划中 → 设计中（设计书已保存）→ 设计已确认（开始生成讲义）→ 待学习（本阶段的讲义就绪）→ 学习中（发布了第一个任务）→ 测试中（发布了阶段测试）→ 复盘中（阶段测试判完分）→ 已完成。整份讲义发布后才进入待学习，生成期间可以先读草稿。
- 待学习、测试中、复盘中由讲义和测试的事件推动，任务也随测试结束完成。事件可能丢（提交后进程中断、监听出错），所以启动时等 assess 和 textbook 就位，再按讲义状态、阶段测试的任务和判分结果推一遍；只往前走，已经对上的不变。
- 一个阶段的课时共用一份讲义，一个课时对应其中一个小节（课时编号对应骨架教材的小节），怎么切分在阶段设计时定；一个课时怎么走见 [journey.md](../journey.md#一个课时怎么走)。
- 课程进度页由区块组成（插槽 `learning.course-section`）：下一步、目标（确认后折叠）、课程报告（结课后在最上面）、任务、阶段时间线（每个阶段的复盘卡片、复盘后怎么走）、测试。"课程讲义"图标的侧栏是阶段 → 课时目录（面板 `curriculum.outline`），点课时在当前标签打开讲义的那一节；状态栏显示阶段进度。
- 你确认设计书、点"完成"任务、决定复盘、确认或放弃路线调整时，交回主老师。

## 课程路线

- 把目标切成若干阶段，每个阶段围绕一个完整任务组织（报告里的 4C/ID 思路）：学完一个阶段能完成一件完整的事，而不只是背下几个知识点。化工原理大致按教材章节分（流体流动、流体输送机械、传热、蒸馏、吸收……以你的教材为准），教材是骨架。
- 路线只写到"阶段标题 + 阶段目标 + 支撑哪几条能做"，只有当前阶段做详细设计，后面的按实际学习情况调整。路线不写时间；能不能赶上由 [planner](../planner/design.md) 估。
- 阶段目标写要做到的事，不写"习题做对 80% 以上"这类总分过关线，程序会拒绝。
- **阶段对应目标条目：** 每个阶段记下它支撑目标里的哪几条"能做"（条目键），老师在 `save_roadmap` 或 `save_stage_design` 里写，目标里没有的键被退回并列出现有的键。简报写出每个阶段支撑哪几条，以及还没有阶段对应的条目。
- **调整路线：**
  - `save_roadmap` 只写计划中的普通阶段；已经开始或完成的阶段、排定的补课阶段保持原样排在前面，老师又写了它们的标题时退回。
  - 第一个阶段的设计书确认之前，老师保存即生效。之后的调整要写理由，先存为"待确认的路线调整"：进度页的路线上方列出改前、改后和理由，你点"按新路线"才生效，"保持原来的"放弃；待确认时"下一步"先请你看它。
  - 不能悄悄缩小范围：原来有阶段对应的目标条目，改完必须仍有对应；要去掉某一条，先和你修订目标。
  - 老师调整顺序时没写某个阶段支撑哪几条，沿用同名阶段原来的；没有同名的，沿用它替换的那个阶段的。计划中的阶段还没有文件，调整后按新序号和标题命名。

## 阶段设计

顺序是逆向设计：
1. **先定阶段验收：** 学完能做到什么，加上阶段测试蓝图（考哪些知识点、题型、条件、新题比例）。蓝图只写考什么、怎么考，不写具体题目、题号和答案，也不写总分过关线；设计书写给你看，不出现内部编号。
2. **再定内容：** 本阶段的核心知识点（`nodes`，阶段测试按它们组卷，前测也探它们）；已经有独立证据的压缩成回顾；之前暴露的薄弱点重点展开——以前复盘带过来的风险和待验证知识点列在老师的简报里，设计书要写明怎么处理（放进哪个课时复习、前测探一下）；穿插前面阶段的复习。
3. **听取你的要求：** 比如"按我导入的那本教材的顺序和讲法来""多给例题""先做个小项目"。
4. **产出一页设计书**（`stages/<阶段>/design.md`）：目标、知识点、课时安排、测试蓝图、要用的资料。题目在这时就为测试预留好（见 [assess](../assess/design.md)）。你确认后，自动生成本阶段的讲义。

## 阶段复盘

- **程序先摆事实：** 阶段进入复盘中后，老师的简报按核心知识点列出：测试结果（过了、没过、待验证）和题号；掌握状态、理由和疑点；本阶段设计确认以来得到过几次帮助、侧边会话里问过几次、记下的误解；后面有几个知识点以它为先修；完整任务题和前面阶段的题的结果，以前带过来的知识点这次对不对。
- **怎么算：** 一个知识点的新题都对算过了；都没对（部分对也算没对）算没过；有对有错或没答到新题算待验证。完整任务题做错或部分对也算没过（完整任务是往前走的关口）。结果读阶段报告，作答按 learner 的[有效证据](../learner/design.md#有效证据)算：有帮助做对的、题目后来核对出有错的，都算待验证，复盘事实写明原因。有题等复核、有没处理的申诉、有题在核查中时，先处理完才能保存复盘。
- **默认建议：** 有知识点没过或完整任务题没过时，默认先补课（只有完整任务题没过时，补它涉及的知识点）；否则进入下一阶段。补课阶段里同一个知识点又没过时没有默认建议。通过标准不是一个固定的数字：关键的先修需要更多独立证据，事实里标出每个知识点后面有多少知识点以它为先修。
- **老师写复盘：** 先在对话里和你过一遍结果和依据，就没过的地方问一句当时怎么想的（不填表），再用 `save_stage_review` 保存到 `stages/<阶段>/review.md`：开头是程序写的结果表，后面是老师写给你的（做得好的、要修的、为什么这样建议）。建议和默认不同（或没有默认）时要写理由；建议补课时写补课阶段的标题和目标。
- **你决定：** 复盘卡片列出哪些过了、没过、待验证，老师的建议和理由，可以展开全文。建议补课时主按钮是"先补课"，也可以"不补课，进入下一阶段"（二次确认写明哪些知识点会记为风险）；建议往前走时主按钮是"进入下一阶段"，有没过或待验证的也可以"我想先补课"。决定后阶段标为已完成，复盘末尾记下你的决定。
- **带进下一阶段：** 往前走时，没过的记为风险，待验证的记为待验证；完整任务题没过时，待验证的也记为风险。你选补课时，补课阶段负责没过的，待验证的仍带进下一阶段。下一阶段设计时简报列出它们，阶段测试里前面阶段的题先出它们。后面某次复盘里它作为核心知识点过了，或之后你独立做对、状态变成已独立完成，就不再列出。

## 补课

- **补课是一个阶段：** 你选"先补课"后，在刚复盘的阶段后面插入补课阶段，后面的阶段顺延一个序号，路线文件同步。它走普通阶段的流程：设计书 → 你确认 → 讲义 → 课时 → 重测 → 复盘；时间线和路线里标"补课"（标题开头的"补课："由程序去掉）。路线调整不会改排定的补课阶段。
- **范围窄、不做前测：** 核心知识点就是要补的那几个，一般一两个课时，按它们所在的小节排；刚做完阶段测试，直接开始。
- **设计：** 在开场会话里设计，简报列出要补的知识点、上一阶段的完整任务题过没过、上一阶段复盘里写给你的那部分，要求写清每个知识点错在哪、这次换什么讲法，不重讲整节，重测要的题在你确认设计书前备好。
- **讲义换讲法：** 补课阶段的讲义版式不变，列提纲时只为复盘里没过的地方规划；每节的资料仍是那一小节的，加上上一阶段的复盘，只讲没过的地方——先点明错在哪、为什么容易错，再换一种讲法（拆开步骤、对照常见错误），已经会的一句带过（见 [textbook](../textbook/design.md)）。
- **重测：** 只考补课的知识点，用没见过的测试预留题，不出前面阶段的题。上一阶段完整任务题没过时还要一道没见过的完整任务题；只补某个知识点时不要求（再加综合题只会让重测变长）。
- **第二次没过：** 程序不给默认建议，复盘事实列出它的先修知识点和掌握状态（第二次没过更可能是先修缺口或题目问题，补同一种课多半无效）。老师看先修是不是缺、题目有没有问题，和你商量：补先修、调整路线、修订目标，或带着风险往前走（先做一两道短题验证也可以），保存复盘时写理由。

## 结课

- 所有阶段（含补课）完成后，"下一步"是"发布结课检验"。老师用 `start_test` 发布（种类 `final`），程序组卷：目标的每条"能做"至少一道没见过的测试预留题，考支撑这一条的阶段的核心知识点，完整任务题优先，已选的题覆盖了就不再加；再加至多两道以前带过来、还没独立做对的知识点；完整任务题排最后。没有对应阶段或没有新题的条目测不到，发布时告诉老师；备题不够时简报提示。
- 结果按目标条目：一条的题都对算做到，有错（部分对也算）算没做到；以前带过来的知识点单独列出对错。
- **课程报告：** 结课检验判完分、复核和申诉处理完之后，简报按每条"能做"列出事实，每条的结果是四种之一：做到了（题都对，相关知识点都已独立完成）、做到了，还缺证据（题都对，但有的有帮助，或有知识点还没独立做对过）、还没做到、没测到。老师用 `save_course_report` 写报告：`report.md` 开头是"能做 | 结果 | 依据 | 还缺"表，正文写给你学会了什么（说依据）、还缺什么证据、要注意什么、以后怎么复查。保存后课程标为已结课，进度页顶部显示课程报告，"下一步"显示已结课。
- 想接着学，请老师加新的阶段，课程回到进行中；报告卡片改为"上次结课时"。结课检验记下发布时的阶段，所以加了阶段后旧的不再算数，学完新阶段要重新做、再写报告。学到的知识点留在全局知识模型里，已结课的课程照常有复查建议。

## 数据与接口

- **服务** `learnCurriculum`：阶段（`stages`、`stage`、`currentStage`、`setStatus`、`setStageSession`）、路线（`saveRoadmap`、`revision`、`decideRevision`）、设计书（`saveDesign`、`confirmDesign`）、课时（`lessons`、`lesson`、`setLessonStatus`）、任务（`publishTask`、`completeTask`、`tasks`）、复盘（`saveReview`、`decideReview`、`carried`）、报告（`saveReport`、`report`）。复盘和报告的事实由 curriculum 的工具插件读 assess、learner、knowledge、goal 后算出，服务本身不注入这几个单元。
- **表：** `curriculum_stages`、`curriculum_lessons`、`curriculum_tasks`、`curriculum_revisions`（一门课最多一份待确认的路线调整）。**文件：** `roadmap.md`、`stages/<阶段>/design.md`、`review.md`、`report.md`。
- **页面接口** `/api/learning/curriculum.<方法>`：`overview`、`design`、`confirmDesign`、`completeTask`、`review`、`decideReview`、`decideRevision`、`report`。
- **事件：** 发 `learning/stage-changed`、`roadmap-revised`、`task-published`、`task-done`；听 `learning/test-finished`（完成测试任务、阶段进入复盘中）、`textbook-ready`（第一课时就绪，阶段变为待学习）、`task-published`（发布阶段测试后阶段进入测试中）。
- **老师工具：** `save_roadmap`、`save_stage_design`、`publish_task`、`save_stage_review`、`save_course_report`。

## 关键决定

- **讲义按阶段生成，每个阶段都有阶段测试，由复盘决定下一阶段怎么写；一个阶段内按小节推进，每学完一小节做小测和汇报**（10-03，你）。
- **每个阶段先定测试蓝图，再写讲义**（10-03，报告）。
- **阶段测试没通过时，默认先补课；不同步课表**（10-03，你）。
- **测试蓝图只写考什么、怎么考，不写具体题目**（10-04，Claude 验收：设计书列出了小测题目，生成的内容因此泄题）。
- **整份讲义发布后阶段才开始，生成期间先读草稿**（11-01，讲义改成一章一份；10-04 起原是第一个课时就绪就开始）：速览、易混点和题型要整章写完才有。
- **复盘由程序汇总事实、老师建议、你决定；有对有错、证据不够的带进下一阶段，坚持往前走的记为风险；补课是插在后面的阶段，只补没过的知识点；路线开始后的调整要你确认，不能让目标条目失去对应阶段；不写总分过关线**（10-09，Claude 按调研的推荐项）。放弃了：把补课课时加回原阶段（原阶段的测试和复盘会被重新打开）；补课不占序号（每处显示序号都要另算）；有对有错也补课（时间成本高，研究支持只补缺口）；路线调整一律直接生效（学习流程里路线属于大改动）。
- **结课检验是单独的一种测试，不拿模拟考代替**（10-09，Claude）：模拟考按考试的题型组卷，不保证每条"能做"都有题；有考试的课程仍可以另做模拟考。每条有一道题就算测到，只靠一道题不够说明的，用掌握状态补充为"还缺证据"。

## 已知限制与以后再做

- 路线不给每个阶段排时间区间，planner 只按已学完阶段的用时估整体能不能赶上。
- 有考试的课程，考完后要不要记真实成绩、怎么用，还没定；课程报告只依据结课检验和掌握状态。
- 复盘事实里还没有批注（在讲义上写了哪些批注、哪些是疑问）。

# 试用清单

写给你看的：要你试用的地方按学习的顺序分组写在这里。觉得哪里不对、看不懂、点了没反应，直接告诉我。

## 知微安装包（11-05）

从 [最新 release](https://github.com/sagemoyi/learning-agent/releases/latest) 下载 `Microsight-Setup-<版本>.exe` 运行。还没签名，Windows 会提示"未知发布者"：点"更多信息"再点"仍要运行"。

- 安装：能选安装位置，桌面和开始菜单有"知微"，图标是学士帽。
- 第一次打开：问学习库放哪里；建议先选一个新的空文件夹，不要选现在 3180 用的学习库。
- 打开后是工作台；去设置页填模型密钥，用合成资料建一门课、和主老师说几句。
- 关掉窗口后任务管理器里不该留着 `node.exe`；再打开直接进工作台，不再问学习库。
- v0.1.1 安装包 246 MB，安装约 2 分钟。
- 自动更新：已经装了 v0.1.0 的话，打开知微一会儿后应该提示 0.1.1 已下载、问要不要重启；重启后学习库旁边的 `知微备份` 里多一份备份。

## 首次启动引导和更新进度（11-06）

装 v0.1.2（或等 v0.1.1 自动更新上来）后试：

- 没填过密钥时，打开知微直接是窗口里的引导，不再弹系统对话框：先看学习库位置，"换个位置"选一个新文件夹后，知微会重新连接，引导里显示新位置。
- 第二步填 DeepSeek 密钥、点保存，再点"测试连接"，通过后才能下一步；第三步 MinerU 可以跳过。点"开始学习"后进主界面。
- 中途点"稍后再说"，底部状态栏有"还没连接模型，去连接"，点它回到引导。
- 设置 › 关于 里有知微的版本和"检查更新"；有新版本时状态栏显示下载进度，下载失败会显示"更新下载失败，重试"。

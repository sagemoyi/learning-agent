# 教材（textbook）

> 代码：[`packages/textbook`](../../packages/textbook) · 接口：[契约](../stage0/contracts.md) §3.2（教材文件长什么样）、§4.5、§5.1 和 §11 · 验证：[验证记录](../stage0/compatibility.md)"骨架联调""协同修整" · 调研：[做深调研](research.md)（含 Claude 的复核）

教材负责为每个阶段写一份为你定制的教材：按课时生成，由带固定 ID 的段落块组成，每块都有资料出处。

## 现状

- **做深（10-09 起）：** 调研经 Claude 复核后分三批做，设计和验收标准见下文三节：
  - **A 生成与恢复：已技术验收，待你试用**（见[验证记录](../stage0/compatibility.md#textbook-a生成与恢复10-09claude)）；
  - B 逐句核对、C 详略与局部修订：还没做。
- **骨架：**
  - 按课时生成，一个课时一个文件。资料超过约 6000 字时，按小标题分成几部分写（两部分同时写），再拼成一节；某部分被截断就对半拆开重写（最多拆两层）；最后单独生成"读完就答"。
  - 写教材时，模型只拿到"教学部分"：设计书去掉测试、蓝图和习题相关的小节；资料只有正文、公式、图表和例题，没有习题和答案。
  - 出处只认这次给出的片段，其余一律标"待核实"。"读完就答"下面的提问、紧挨着公式的一句引导语（如"按下式计算："）不陈述事实，不要求出处。
  - 块索引记下块 ID、出处、是否待核实、挂到哪些知识节点（规则见"生成与恢复"）。块索引先保存，再经 knowledge 的来源登记服务校验和记录连线；旧连线保留，目标消失时详情提示不可用。
  - 教材页：
    - 窄栏阅读，出处缩成 `p.12` 这样的小标签，点开就是资料原文；
    - 选中段落后可以"就这段提问"；"读完了"直接完成阅读任务；
    - 上一节/下一节；"重新生成本节"原地二次确认；生成中显示进度。
  - 生成完成或失败都交回主老师。同一课时连续两次失败，就停下来交还给你，不让主老师反复重试。
- **补课课时（curriculum B，已技术验收，待你试用）：** 补课阶段的课时一次写完：除了这一小节的资料和补课设计书，还给模型上一阶段的复盘，要求只讲复盘里没过的地方、换一种讲法、用资料里的例题拆步讲，不重写整节（见 [curriculum](../curriculum/design.md)"补课单元"）。
- **还没做：** 批注（归 [annotation](../annotation/design.md)）。
- **待你试用：** 用整本化工原理教材生成 1.2 节的效果。

## 阶段教材

- **一个阶段一份完整教材。** 不一次性写完整门课，也不学一点写一点。
- **为你定制：** 已经会的内容跳过或压缩，薄弱的内容展开。如果你指定了某本教材做骨架，就遵循它的结构。
- **由带固定 ID 的段落块组成：**
  - 每个块挂到对应的知识节点上，并标注出处（来自哪份资料的第几页）。
  - 批注锚定在块 ID 上，所以教材修订后批注不会丢。
- **不采信模型自身的知识：** 每个块都必须有资料出处。
  - 找不到出处的内容，先联网找权威资料补上（见 [library](../library/design.md)"联网找权威资料"）。
  - 仍然找不到，就不写进教材；或者标为"待核实"，并提示你。
  - 生成完成后，逐条回查：引用的原文是否真的支持这句话；公式、数值、定义这类关键事实，还要有两个独立来源支持（同一所学校、或转载自同一份课件的算一个来源）。
- **例题和小问题：** 例题优先使用资料或权威来源里的题目，只能照资料原样写，不改编、不自编。教材里还会嵌入少量"读完就答"的小问题，要求凭记忆作答，这是报告里证据最充分的学习手段之一。
- **不出现习题、小测题和测试安排。** 这些归 [assess](../assess/design.md)，教材里出现就等于泄题。

## 文件形式

教材是 Markdown 文件，存放在课程文件夹里，你也可以直接打开看（Obsidian 也能正常显示）：
- 一个小节一个文件：`stages/<序号-标题>/textbook/<小节>.md`。
- 每个段落块末尾带 `^块ID`（Obsidian 写法）。
- 出处写成 `[《书名》p.页码](cite:片段ID)` 这样的链接，不出现其他内部编号。
- 块挂到哪些节点、每句的核对结果记在数据库里，不写进文件。

## 生成与恢复（A）

**生成单位**沿用"按小标题分部分"：每部分约 6000 字资料，一次调用写完，就是调研说的"教学单元"。不为每个段落单独调用模型。

**生成记录存进数据库**，不只放在内存里：
- 记录内容：排队、进行中、成功、失败，失败原因，连续失败次数，已经写完的部分。
- 程序重启后：排队和被中断的课时自动接着生成；已经写完的部分不再调用模型；连续失败次数还在，"连续两次失败交还你"的规则不会因为重启失效。
- 某一部分失败后重试，已写完的部分照样复用。
- 部分的复用条件：这一部分的资料、设计书、目标、复盘和写作模型都没变。改了设计书再生成，就全部重写。

**发布不覆盖别人的修改：**
- 开始生成时记下教材文件的内容指纹；发布时文件已经变了（你在应用外编辑过，或者别处写过），就不覆盖，这次生成记为失败并说明原因。
- 写盘、标记完成、交回主老师按这个顺序做。写盘后程序中断，重启时认出这一版已经发布（文件里记着这次生成的编号），只补标记，不重新生成，也不重复交回。

**块 ID：** 重新生成时，文字和旧版完全相同的段落沿用原来的块 ID。

**知识关联只在本课的候选知识点里找：**
- 候选知识点 = 阶段的核心知识点，加上出处落在本课资料里的知识点（knowledge 记着每个知识点出自哪些资料片段）。
- 段落点名了某个候选知识点（标题或别名），或者引用了它的出处片段，就挂上。
- 同名的知识点一个都不挂，等你分清。

**覆盖检查：** 出处落在本课资料里、正文却一段都没挂上的知识点，列在生成结果里，交回主老师时一并说明（"这些知识点正文没有讲到：……"）。

**独立公式也要有出处：** 公式块沿用紧跟其后的解释段的出处。解释段没有出处时，公式后补一句"上式没有找到出处"并标待核实。

**补课课时**仍一次写完，带上一阶段的复盘。

**A 的验收标准：**
1. 生成到一半重启：已写完的部分不再调用模型，课时接着生成到完成；排队的课时也接着生成。
2. 连续失败一次后重启，再失败一次就交还你。
3. 生成期间改了教材文件：不覆盖，失败原因写明。
4. 写盘后、标记完成前中断：重启后不重新生成，只交回一次。
5. 重新生成时，文字没变的段落块 ID 不变。
6. 同名知识点不挂；不在候选里的知识点即使被点名也不挂；引用了知识点出处片段的段落挂上。
7. 没讲到的知识点出现在状态和交回里。
8. 公式块带上解释段的出处；没有解释段出处的公式被标待核实。
9. 补课课时和最小学习流程（`tests/flow.test.ts`）照常通过。

## 逐句核对（B）

生成完、发布前，逐句核对出处。为了控制调用次数，按批做，不逐句调用模型。

**切句和成批：**
- 程序把每个段落按句号、分号等切成句子并编号；独立公式算一句。不让模型拆陈述，这样拆分本身不会漏句。
- "读完就答"的提问和公式引导语不核对。
- 几个相邻段落连同它们引用的片段凑成一批（约 8000 字），一批调用一次核对模型。

**每句的判断：**
- 核对模型对每句给出：支持、部分支持、矛盾、找不到依据，并摘出支持它的原文。
- 程序再验三件事：
  - 摘出的原文确实在那个片段里；
  - 句中的数值都出现在所引原文里；
  - 每句都有结果，模型漏掉的句子记"没核对"。

  任何一件不过，这句就不算支持。
- 没有引用出处的句子也一起核对。在这批片段里找到支持时，把出处补进段落。

**关键事实**指公式、带单位的数值和定义（"称为""是指""定义为"这类句子）。由程序按规则认定，模型只能多认定，不能少认定。

**两个独立来源：**
- 关键事实被第一个来源支持后，用资料库的混合检索在本课的其他资料里找候选，排除同一来源组，再成批核对一次。
- 来源组：
  - 网上资料按注册域名分组；
  - 上传的资料每份算一组；同一份资料的重新解析算同一组；同名不同版次的书算同一组。
  - 不同的上传资料默认算独立。程序看不出一份课件是不是抄自某本教材，这是已知限制。
- 第二来源支持时，把它的出处补进段落。
- **原例题照录：** 引用例题片段的句子只核对"是否照录"（支持，且数值都在原文里），不要求第二来源。题目给的条件是题目本身，不是需要交叉核对的事实。

**联网补充：**
- 只有一个来源的关键事实、找不到依据的句子，按重要程度取前 3 个，变成联网搜索的问题。
- 只自动加入二级以上的网页资料（PDF 要解析，太慢；三级要等你确认），加入后再核对一次。
- 联网失败、没找到，都不影响教材发布，只在结果里说明。

**呈现：**
- 矛盾、找不到依据、没核对的句子，所在段落标"待核实"，记下具体原因（如"原文写的是……""数值 998.2 在所引原文里找不到"）。
- 关键事实只有一个来源的段落不标待核实，只在阅读页显示"单一来源"。待核实表示可能有错，单一来源只表示还没找到第二个来源，两者分开。
- 核对模型出错、格式不对或被截断：重试一次，仍不行就照常发布，状态写"出处未核对"，不算核实。
- 核对结果绑定段落的内容指纹。段落之后被改过，旧结果就不算数，显示"改过，未重新核对"。

**核对模型**是设置页里单独的角色"核对教材"，没设置时用默认模型。

**B 的验收标准**（用合成资料和假模型测程序规则；用真实模型在合成课程上走一遍）：
1. 每句都有核对结果，模型漏掉的句子记"没核对"。
2. 摘出的原文不在所称片段里、句中数值不在原文里，都不算支持。
3. 关键事实只有同一来源组的多个片段支持（同一本书的两页、同一网站的两个页面），不算两个来源。
4. 第二来源从本课其他资料里找到并支持时，出处补进段落；找不到时显示"单一来源"，不标待核实。
5. 引用例题片段的句子不要求第二来源，但数字改了就不算支持。
6. 联网补充最多 3 个问题，只自动加入二级以上的网页；联网失败时教材照常发布。
7. 核对模型出错时教材照常发布，状态是"出处未核对"。
8. 段落在应用外改过，旧核对结果不再算数。

## 详略与局部修订（C）

**按掌握证据定详略：**
- 写作模型拿到本课候选知识点的掌握状态和依据，并按状态决定怎么写：
  - 独立完成、已巩固：压缩，但保留定义、符号和适用条件；
  - 没做到、证据冲突、反复提问：展开，拆步骤，对照常见错误；
  - 有帮助才完成：正常讲，提醒自己独立做一遍；
  - 没测过：正常讲。
- 不按"学习风格"分人。阅读、聊天不当作已会。
- 压缩不能删掉知识点，A 的覆盖检查照常进行。

**局部修订：**
- 主老师用工具 `revise_textbook` 改指定的几段，附一句要求（如"这段讲得太跳，拆开步骤"）；模型只拿到这几段、前后各一段和它们引用的片段。
- 修订规则：
  - 没指定的段落文字和 ID 都不变；
  - 改写的段落保留原 ID；多出来的段落用新 ID；删掉的段落记下去向，原文在变更记录里查得到。
- 改完只核对改过的段落，同样走 B 的规则。
- B 核对出"矛盾"的段落，发布前自动局部修订一次，仍矛盾就标待核实。

**阅读提示：**
- 待核实段落显示具体原因；"单一来源"段落显示一个淡色标记。
- 点开能看支持这句话的原文。
- 正文不出现内部编号和模型评分。

**C 的验收标准：**
1. 同一份合成资料，掌握状态不同时，写作模型收到的详略要求不同；覆盖检查和出处规则不变。
2. 局部修订只改指定段落：其他段落文字和 ID 不变，改写的段落保留 ID，改过的段落重新核对。
3. 矛盾段落自动修订一次；仍矛盾时标待核实。
4. 删掉的块 ID 记下去向。
5. 阅读页的提示在 1440、1024、760 宽度和深浅两色下截图核对。

## 关键决定

- **教材一个小节一个文件；块 ID 用 `^ID`，出处用 `cite:` 链接**（10-03，契约决定 4，你确认）：和课时一一对应，Obsidian 里也能正常显示。
- **写教材只给模型"教学部分"**（10-04，Claude 验收）：把整份设计书交给模型、出处接受资料库里的任何片段时，教材会泄露小测题和习题答案，还会改写习题。
- **教材按长度分部分写再拼成一节；同一课时连续两次生成失败就交还给你**（10-04，第一次试用：1.2 节一次写完约 9500 字、124 个片段，加上模型的思考超出了单次输出）。
- **写教材的输出额度留 16000**（10-04）：`deepseek-flash` 的思考也算在额度里，额度太小会表现为"空回复"或"截断"。写教材的模型是设置页里的"写教材"角色。
- **做深的取舍**（10-09，Claude 复核调研后定，你授权）：
  - 程序切句、按批核对，不让模型拆陈述，也不逐句调用；
  - 关键事实由程序按规则认定；
  - 不同的上传资料默认算独立来源；原例题只查照录；
  - 单一来源和待核实分开显示；
  - 知识关联和覆盖检查用 knowledge 已有的出处连线；
  - 不做取消、不登记 DSH jobs、不建资料派生关系模型。

  放弃了调研里的"来源未知不算独立"：上传资料只记文件名，按它双来源规则永远不成立。

完整的决定和来源见[决策记录](../decisions.md)。

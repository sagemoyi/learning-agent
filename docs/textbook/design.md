# 教材（textbook）

> 代码：[`packages/textbook`](../../packages/textbook) · 接口：[契约](../stage0/contracts.md) §3.2（教材文件长什么样）、§4.5、§5.1 和 §11（"教材 D"） · 验证：[验证记录](../stage0/compatibility.md)"textbook A""textbook C""textbook D" · 调研：[做深调研](research.md)（含 Claude 的复核）

教材负责为每个阶段写一份为你定制的教材：按课时生成，一节 = 模型写的讲解 + 程序原样放进来的资料原文，由带固定 ID 的段落块组成，讲到的每一处都能点开原文。

- **生成与恢复（A）、详略与局部修订（C）：已技术验收**，按 D 的写法调整后测试照常通过（[A](../stage0/compatibility.md#textbook-a生成与恢复10-09claude)、[C](../stage0/compatibility.md#textbook-c详略与局部修订10-10claude)）。B 的逐句核对和"两个独立来源"已被 D 取代，代码已删除。
- **骨架：**
  - 写教材的模型拿到"教学部分"：设计书去掉测试、蓝图和习题相关的小节；资料只有正文、公式、图表和例题，没有习题和答案。只有列要点的那次调用看得到本章习题的题干。
  - 块索引记下块 ID、出处、是不是资料原文、是否待核实、挂到哪些知识节点（规则见"生成与恢复"）。块索引先保存，再经 knowledge 的来源登记服务校验和记录连线；旧连线保留，目标消失时详情提示不可用。
  - 课程里的"本课资料"按块索引的出处列出每份资料被哪几节引用（`textbook.sourceUses`，10-16）；片段属于哪份资料问资料库，重新解析前的旧片段算到最新版本上。
  - 教材页：窄栏阅读；出处缩成 `p.12` 这样的小标签，悬停看原文那一段，点开打开资料原文；上一节/下一节；"重新生成"原地二次确认；"读完了"直接完成阅读任务。
  - 生成完成或失败都交回主老师。同一课时连续两次失败，就停下来交还给你，不让主老师反复重试。
- **补课课时（curriculum B，已技术验收，待你试用）：** 补课阶段的课时只为上一阶段复盘里没过的地方列要点（1 到 3 个），换一种讲法、用资料里的例题拆步讲，不重写整节（见 [curriculum](../curriculum/design.md)"补课单元"）。

## 阶段教材

- **一个阶段一份完整教材。** 不一次性写完整门课，也不学一点写一点。
- **为你定制：** 讲解用适合你水平的话讲重点，已经会的内容压缩，薄弱的内容展开。如果你指定了某本教材做骨架，就遵循它的结构。
- **由带固定 ID 的段落块组成：**
  - 每个块挂到对应的知识节点上，并标注出处（来自哪份资料的第几页，或网页的网址）。
  - 批注记下选中的原句和块 ID，块 ID 说明去哪个段落找；教材修订后原句还在的批注自动跟着走，对不上的等你确认（见 [annotation](../annotation/design.md)）。
- **不采信模型自身的知识：** 讲事实的段落都带出处，发布前对照资料核对；公式、原图、表格、例题这些需要精确的地方直接放资料原文。资料里没讲、做习题却要用的内容，先在本课其他资料里找，再联网找权威网页；都找不到就写明"资料里没有讲到"，不让模型自己补。
- **例题：** 只用资料里的原题，题目和原书解答原样放进来，讲解只讲思路和容易错的地方，不改编、不自编。教材里还会嵌入少量"读完就答"的小问题，要求凭记忆作答，这是报告里证据最充分的学习手段之一。
- **不出现习题、小测题和测试安排。** 这些归 [assess](../assess/design.md)，教材里出现就等于泄题。列要点时看习题的题干，只是为了知道做题要会什么。

## 讲解与原文

**一节教材 = 讲解 + 原文：**
- **讲解**由模型写：按你的水平讲清这一点要解决什么、为什么、怎么用、容易错在哪，不照抄资料原句，篇幅大致和这一点的资料原文相当。讲事实的段落带出处标签。
- **原文**由程序放进来，模型不重写：公式、原书插图、表格、例题题目和原书解答、需要原话的定义。模型只写一行嵌入标记 `![[片段ID]]`（连续几段写 `![[第一段..最后一段]]`），程序换成资料原文，文件里是 Obsidian 的引用框：
  ```
  > [!quote] 原文 · [《化工原理》p.8](cite:ck_…)
  > $$p_{\mathrm g}=p-p_0 \tag{1-2}$$

  ^ab12cd
  ```
  - 例题分成"原题"和"原书解答"两个框，解答默认收起（`> [!quote]-`）；插图是"原图"框，教材页里直接显示从原书页面裁下的图。
  - 嵌入不成立的不放：不在本节资料（或为这一点找来的补充资料）里的片段、跨小标题或超过 12 段的范围、只有正文段落的嵌入（讲解里讲过的就不再放原文，出处标签能看原文）。去掉了几处写进核对说明。

**生成步骤：**
1. **列要点（一次调用）：** 模型看到本节资料的提纲（编号的片段，每段只列开头）、学习目标、设计书的教学部分、你的掌握情况，以及本章习题的题干（不给答案），按资料顺序把本节分成 3 到 8 个要点（资料很短时 1 到 2 个），每个要点是资料里连续的一段；同时写出"做这些题要会的"，并标出资料里没讲的。
   - 程序整理要点范围：补上漏掉的片段、消除重叠；例题和它后面的解答步骤不会被分到两个要点里；超过 8 个时合并最小的相邻两个；一个要点的资料超过 12000 字就拆开。
   - "要会的"里和题干有一长串相同文字的条目丢掉，写作模型只看到"要会的"，看不到题干。
   - 列要点失败时，按小标题分要点（每部分约 6000 字资料），照常往下写，核对说明里写明原因。
2. **补资料里没讲的（每节最多 3 项）：** 先在本课的其他资料里找（按意思检索加关键词检索）；没有，且设置页"联网补充讲解"开着时，联网找一个一级或二级的网页，**只读，不加入资料库**，讲解里出处写网址，网站名、网址不写进正文；都找不到，在那个要点末尾写明"资料里没有讲到：……"，交回主老师时一并说明。超过 3 项的直接写明没讲到。
3. **按要点写（两个同时写）：** 每个要点只给它那段资料、补充资料和网页摘录。只有一个要点时，"读完就答"由写作模型一起写；多个要点时最后单独写。某个要点的回复被截断，就把它的资料对半拆开重写，后半段接着写、不重复标题。写好的要点先作为草稿显示在教材页上。
4. **核对（三个要点同时核对）：**
   - 原文块是原样复制的，不核对；"读完就答"不核对。
   - 讲解段落：程序先查数值在资料里找得到、没有抄题干（连续 14 个字相同）；资料里没有原样出现的公式交给模型判断能否由资料直接得出。模型再判断每段有没有和资料矛盾、有没有资料外的事实（教学性的过渡、提问、学习建议、解题思路不算事实），并指出内容出自哪几段。没写出处的段落按模型指出的片段补上出处标签。
   - 本节资料不超过 3 万字时，每个要点对照整节资料核对（后面的要点可以用前面讲过的）；更长时只对照这个要点的资料和它引用的片段。
   - 和资料矛盾的段落发布前自动改一次（沿用 C 的局部修订），再核对；仍有问题的段落在块索引里标"待核实"。**正文里不插入"待核实"字样。**
   - 核对调用失败时照常发布，状态写"讲解没有核对完"。
5. **发布：** 与 A 相同（不覆盖别人的修改、块 ID 沿用、重启后接着写、已写好的要点不再调用模型）。

**教材页：**
- 点段落不弹出任何东西。**选中文字后**，选区上方出现浮条：提问 / 批注 / 出处与核对。"出处与核对"显示这一段引用的原文、网页摘录和核对结果；原文块显示"资料原文，原样引用，不用核对"。浮条和卡片不超出正文栏。（10-15 讨论时说放在右侧栏，做的时候改为浮条下方的卡片：离选中的文字近，按你说的"选中字以后出现浮窗"。点出处标签打开原文现在仍是分屏，外壳这一批改为在右侧栏打开。）
- 页头的"N 段待核实"可以点，点了在正文里标出这些段落；"讲解没有核对完""N 段改过未重新核对""N 项资料里没讲"悬停有说明。
- 生成中：转动的图标、步骤（整理要点 → 编写讲解 → 对照资料核对 → 发布）、已用时间、每个要点写没写完；写好的要点先显示为草稿。

**模型和服务：** 写作和列要点用"写教材"角色，核对用"核对教材"角色，没设置时用默认模型。输出额度：写作、列要点 16000，核对 8000（回复截断时核对段落对半拆开）。模型中转断线、超时、服务端错误、限流或空回复时，`complete()` 自动重试两次（隔 2 秒、6 秒）。

**D 的验收标准：**
1. 要点按资料顺序覆盖本节全部教学资料，例题和解答在同一个要点里，同一小标题不重复。
2. 嵌入的原文和资料片段逐字相同；不在本节资料（或补充资料）里的片段、跨小标题或超过 12 段的范围、只有正文的嵌入不放，并记下原因。
3. 原文块不标待核实；讲解段落里资料没有的数值、和资料矛盾或资料外的说法被标出，矛盾的段落自动改一次；正文里没有"待核实"字样。
4. 列要点的模型看得到题干、看不到答案；写作模型看不到题干；讲解里出现题干原句会被标出。
5. 资料里没讲的"要会的"：本课其他资料找到就用；联网找到的网页不进资料库，教材里是网址；都没有就写明。
6. 列要点失败、核对失败都不影响发布；某个要点写失败就整节失败，重试时已写好的要点不再调用模型。
7. 局部修订不能改原文块；最小学习流程照常通过。
8. 教材页：选中文字才出浮条；出处标签悬停有原文预览；插图直接显示；生成进度会动。在 1440、1024、760 宽度和深浅两色下截图核对。
9. 用真实模型在合成课程上走一遍：讲解不照抄、原文逐字、有补资料的情况。

## 文件形式

教材是 Markdown 文件，存放在课程文件夹里，你也可以直接打开看（Obsidian 也能正常显示引用框和图注）：
- 一个小节一个文件：`stages/<序号-标题>/textbook/<小节>.md`。
- 每个段落块末尾带 `^块ID`（Obsidian 写法）；原文框的块 ID 单独一行写在框后面。
- 出处写成 `[《书名》p.页码](cite:片段ID)`，网页写成 `[网页标题](网址)`，不出现其他内部编号。原图写成 `![图注](cite:片段ID)`。
- 块挂到哪些节点、每段的核对结果记在数据库里，不写进文件。

## 生成与恢复（A）

**生成单位是要点：** 一个要点一次调用写完（资料长时对半拆开），不为每个段落单独调用模型。

**生成记录存进数据库**，不只放在内存里：
- 记录内容：排队、进行中、成功、失败，失败原因，连续失败次数，当前步骤和开始时间，要点列表，已经得到的模型回复（列要点、每个要点、核对），草稿，补来的网页和资料里没讲的内容。
- 程序重启后：排队和被中断的课时自动接着生成，已用时间接着算；已经得到的回复不再调用模型；连续失败次数还在，"连续两次失败交还你"的规则不会因为重启失效。
- 某个要点失败后重试，已写完的要点照样复用。
- 回复的复用条件：这次调用的提示和模型都没变（资料、设计书、目标、复盘、掌握情况都在提示里）。改了设计书再生成，就全部重写。

**发布不覆盖别人的修改：**
- 开始生成时记下教材文件的内容指纹；发布时文件已经变了（你在应用外编辑过，或者别处写过），就不覆盖，这次生成记为失败并说明原因。
- 写盘、标记完成、交回主老师按这个顺序做。写盘后程序中断，重启时认出这一版已经发布（文件里记着这次生成的编号），只补标记，不重新生成，也不重复交回。

**块 ID：** 重新生成时，文字和旧版完全相同的段落沿用原来的块 ID。

**讲解里单独成段的公式**（不是原文框）沿用紧跟其后的解释段的出处。

**知识关联只在本课的候选知识点里找：**
- 候选知识点 = 阶段的核心知识点，加上出处落在本课资料里的知识点（knowledge 记着每个知识点出自哪些资料片段）。
- 段落点名了某个候选知识点（标题或别名），或者引用了它的出处片段，就挂上。"读完就答"的提问不讲解任何知识点，不挂。
- 同名的知识点一个都不挂，等你分清。

**覆盖检查：** 出处落在本课资料里、正文却一段都没挂上的知识点，列在生成结果里，交回主老师时一并说明（"这些知识点正文没有讲到：……"）。

**A 的验收标准：**
1. 生成到一半重启：已写完的要点不再调用模型，课时接着生成到完成；排队的课时也接着生成。
2. 连续失败一次后重启，再失败一次就交还你。
3. 生成期间改了教材文件：不覆盖，失败原因写明。
4. 写盘后、标记完成前中断：重启后不重新生成，只交回一次。
5. 重新生成时，文字没变的段落块 ID 不变。
6. 同名知识点不挂；不在候选里的知识点即使被点名也不挂；引用了知识点出处片段的段落挂上。
7. 没讲到的知识点出现在状态和交回里。
8. 补课课时和最小学习流程（`tests/flow.test.ts`）照常通过。

## 详略与局部修订（C）

**按掌握证据定详略：**
- 写作和列要点的模型拿到本课候选知识点（A 的"候选知识点"，最多 30 个）各自的掌握状态和依据，每个一行，并按状态决定怎么写：
  - 独立完成、已巩固：压缩，但保留定义、符号和适用条件，不展开推导和例题；
  - 没做到、证据冲突、反复提问：展开，拆步骤，对照常见错误，用资料里的例题一步一步讲；
  - 有帮助才完成：正常讲，提醒自己独立做一遍；
  - 没测过：正常讲。
- 状态取学习者模型的结论（learner），这门课自己的作答优先于跨课程的总状态。答对了却在侧边会话或批注里反复问到，按"展开"写。
- 不按"学习风格"分人。阅读、聊天不当作已会（这是 learner 的规则）。
- 掌握情况只用来定详略，正文里不复述。压缩不能删掉知识点，A 的覆盖检查照常进行。

**局部修订：**
- 主老师用工具 `revise_textbook` 改一节里的 1 到 8 段讲解，附一句要求（如"这段讲得太跳，拆开步骤"）。你在教材页或侧边会话里说某段不清楚、有错时，由主老师来改；要重写整节用"重新生成"。主老师用 `read_lesson_textbook` 读教材时，末尾列出待核实的段落。
- 修订模型只拿到这几段、前后各一段（只用来衔接，不输出），以及它们引用的片段和资料里前后各两个片段；改写可以引用、嵌入这些片段。
- 修订规则（由程序保证，不靠模型自觉）：
  - 原文块不能改（资料原文就是原文）；
  - 模型只按段落编号交回改好的段落，程序把它们放回原位，没指定的段落文字和 ID 都不变；
  - 改写的段落保留原 ID，多出来的段落用新 ID，删掉的段落记下去向（`textbook_revisions`）；原文在变更记录里查得到；
  - 教材正在生成时不能改；改的期间文件被别处改过，就不覆盖。
- 改完只核对改过的段落，同样走 D 的核对；其他段落的核对结果保留。核对结果绑定段落的内容指纹，段落之后被改过，旧结果就不算数，教材页显示"N 段改过未重新核对"。

**C 的验收标准：**
1. 同一份合成资料，掌握状态不同时，写作模型收到的详略要求不同；覆盖检查和出处规则不变。
2. 局部修订只改指定段落：其他段落文字和 ID 不变，改写的段落保留 ID，改过的段落重新核对；原文块不能改。
3. 矛盾段落自动修订一次；仍有问题时标待核实。
4. 删掉的块 ID 记下去向。

## 关键决定

- **教材一个小节一个文件；块 ID 用 `^ID`，出处用 `cite:` 链接**（10-03，契约决定 4，你确认）：和课时一一对应，Obsidian 里也能正常显示。
- **写教材只给模型"教学部分"**（10-04，Claude 验收）：把整份设计书交给模型、出处接受资料库里的任何片段时，教材会泄露小测题和习题答案，还会改写习题。10-15 起列要点的那次调用看本章习题的题干（不看答案），写作模型仍然看不到题目。
- **写教材的输出额度留 16000**（10-04）：`deepseek-flash` 的思考也算在额度里，额度太小会表现为"空回复"或"截断"。列要点也是 16000（10-16 联调时有一次列要点失败、退回按小标题分，原因当时没记下；额度放宽到和写作一样，失败原因写进核对说明）。
- **生成记录存数据库，发布不覆盖，块 ID 沿用，知识关联只看本课候选**（10-09，Claude 复核调研后定，你授权）：不做取消、不登记 DSH jobs、不建资料派生关系模型。
- **按掌握状态定详略，局部修订只给主老师工具**（10-10，Claude 按调研推荐定）：只把"矛盾"段落自动修订一次；教材页暂不加"改这段"按钮。
- **讲解与原文**（10-15，你定方向，Claude 设计）：10-12 试用时教材几乎照抄资料，公式下面全是"待核实"，长小节在例题中间被切开出现两个 1.2.3，插图要点开原文才能看，习题要用的"扩大室"没讲。前三个问题出在逐句核对：每句都要原文支持、关键事实要两个独立来源，模型换个说法就不过，只好照抄。改为模型讲、程序放原文、按要点核对，正文不插"待核实"。放弃了逐句核对和两个独立来源；代价是讲解段落的核对比逐句粗，靠"原文就在旁边、出处悬停可看"弥补。
- **习题定范围，网页只读不入库**（10-15，你"可以"；"找的来源……可以不要加到资料库里？直接给网址就行"）：列要点时看题干写出"要会的"，资料里没讲的才去找；网上找到的网页不加入资料库，免得资料库里堆满一次性的网页。
- **联调后补的规则**（10-16，Claude 在合成课程上用 DeepSeek 联调后定）：讲解段落第一次按要点自己的资料核对时，6 段承接前文的讲解被误判为"资料里找不到"，改为短小节每个要点对照整节资料核对；写作模型把正文段落讲一遍又整段嵌入原文，改为正文段落不能整段嵌入；核对放宽到教学性的过渡和提醒不算事实；核对三个要点同时做（一节 6 个要点、两个同时核对要约 5 分钟）。

完整的决定和来源见[决策记录](../decisions.md)。

## 待定问题

- 核对模型对中文化工公式、表格的判断准确率没有实测数据，D 用合成正反例和一次 DeepSeek 联调检查；真实效果等你试用。
- 一节教材生成要 5 到 8 分钟（6 个要点：列要点约 1 分钟、写约 2 分钟、核对 3 到 5 分钟）。写好的要点先显示，核对期间可以先读；还要不要更快，等你试用后看感受。
- 网页标题缺失时资料库用域名当书名（如"《jxpt.whut.edu.cn》"），写作模型这时会把出处标签写成"网页"。要不要统一改用资料库给的出处文字，等试用时看。
- 教材页要不要直接给每段一个"改这段"按钮（现在要经主老师），等外壳和批注一起定。

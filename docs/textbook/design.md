# 教材（textbook）

> 代码：[`packages/textbook`](../../packages/textbook) · 接口：[契约](../stage0/contracts.md) §3.2（教材文件长什么样）、§4.5、§5.1 和 §11 · 验证：[验证记录](../stage0/compatibility.md)"骨架联调""协同修整"

教材负责为每个阶段写一份为你定制的教材：按课时生成，由带固定 ID 的段落块组成，每块都有资料出处。

## 现状

- **骨架：**
  - 按课时生成，一个课时一个文件。资料超过约 6000 字时，按小标题分成几部分写（两部分同时写），再拼成一节；某部分被截断就对半拆开重写（最多拆两层）；最后单独生成"读完就答"。
  - 写教材时，模型只拿到"教学部分"：设计书去掉测试、蓝图和习题相关的小节；资料只有正文、公式、图表和例题，没有习题和答案。
  - 出处只认这次给出的片段，其余一律标"待核实"。"读完就答"下面的提问、紧挨着公式的一句引导语（如"按下式计算："）不陈述事实，不要求出处。
  - 块索引：块 ID、出处、是否待核实、挂到哪些知识节点（只按本课唯一标题匹配，同名歧义不自动挂接）。块索引先保存，再经 knowledge 的来源登记服务校验和记录连线；旧连线保留，目标消失时详情提示不可用。明确身份关联随教材做深补齐。
  - 教材页：窄栏阅读，出处缩成 `p.12` 这样的小标签，点开就是资料原文；选中段落后可以"就这段提问"；"读完了"直接完成阅读任务；上一节/下一节；"重新生成本节"原地二次确认；生成中显示进度。
  - 生成完成或失败都交回主老师。同一课时连续两次失败，就停下来交还给你，不让主老师反复重试。失败次数只记在内存里，重启后重置。
- **还没做：** 逐块写、生成后逐条回查"引用的原文是否真的支持这句话"，关键事实（公式、数值、定义）还要有两个独立来源支持（10-07 定，机构按资料库记下的注册域名判断）；找不到出处时自动联网补充（联网找资料本身已在资料库做好，主老师可以手动调用）；按你已会和薄弱的地方定制内容；批注（归 [annotation](../annotation/design.md)）。
- **待你试用：** 用整本化工原理教材生成 1.2 节的效果。

## 阶段教材

- **一个阶段一份完整教材。** 不一次性写完整门课，也不学一点写一点。
- **为你定制：** 已经会的内容跳过或压缩，薄弱的内容展开。如果你指定了某本教材做骨架，就遵循它的结构。
- **由带固定 ID 的段落块组成：**
  - 每个块挂到对应的知识节点上，并标注出处（来自哪份资料的第几页）。
  - 批注锚定在块 ID 上，所以教材修订后批注不会丢。
- **不采信模型自身的知识：** 每个块都必须有资料出处。
  - 找不到出处的内容，先联网找权威资料补上（见 [library](../library/design.md)"联网找权威资料"）。
  - 仍然找不到，就不写进教材；或者标为"待核实"，并提示你。
  - 生成完成后，逐条回查：引用的原文是否真的支持这句话；公式、数值、定义这类关键事实，还要有两个独立来源支持（同一所学校、或转载自同一份课件的算一个来源）。
- **例题和小问题：** 例题优先使用资料或权威来源里的题目，只能照资料原样写，不改编、不自编。教材里还会嵌入少量"读完就答"的小问题，要求凭记忆作答，这是报告里证据最充分的学习手段之一。
- **不出现习题、小测题和测试安排。** 这些归 [assess](../assess/design.md)，教材里出现就等于泄题。

## 文件形式

教材是 Markdown 文件，存放在课程文件夹里，你也可以直接打开看（Obsidian 也能正常显示）：
- 一个小节一个文件：`stages/<序号-标题>/textbook/<小节>.md`。
- 每个段落块末尾带 `^块ID`（Obsidian 写法）。
- 出处写成 `[《书名》p.页码](cite:片段ID)` 这样的链接，不出现其他内部编号。
- 块挂到哪些节点记在数据库里，不写进文件。

## 关键决定

- **教材一个小节一个文件；块 ID 用 `^ID`，出处用 `cite:` 链接**（10-03，契约决定 4，你确认）：和课时一一对应，Obsidian 里也能正常显示。
- **写教材只给模型"教学部分"**（10-04，Claude 验收）：把整份设计书交给模型、出处接受资料库里的任何片段时，教材会泄露小测题和习题答案，还会改写习题。
- **教材按长度分部分写再拼成一节；同一课时连续两次生成失败就交还给你**（10-04，第一次试用：1.2 节一次写完约 9500 字、124 个片段，加上模型的思考超出了单次输出）。
- **写教材的输出额度留 16000**（10-04）：`deepseek-flash` 的思考也算在额度里，额度太小会表现为"空回复"或"截断"。写教材的模型是设置页里的"写教材"角色。

完整的决定和来源见[决策记录](../decisions.md)。

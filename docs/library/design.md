# 资料库（library）

> 代码：[`packages/library`](../../packages/library) · 调研：[research.md](research.md) · 契约：[contracts.md](../contracts.md)

## 概要

资料库把你的教材和其他资料变成可以引用的片段：解析、切块、检索、出处定位，以及联网找权威资料。目标是 NotebookLM 的核心体验：回答和教材只依据资料，每句话都能点开，跳到原文的那一页、那一段。一份资料只存一份，课程记下用到哪几份、各当什么。网上资料的权威级别只按网站规则定，不让模型打分；解析完成不等于内容已经核实。

## 仓库和本课资料

**一份资料只存一份，课程只是用到它。** 资料存在资料库里，课程记下用到哪几份、各当什么（骨架教材、参考资料、往年试题）。从课程里移出不删资料，已有的出处照常能打开。

**主界面的"资料库"是仓库**（图标栏点了直接打开）：
- 导入 PDF、导入任务、全库检索、高级导入；
- 资料分"上传的资料"和"网上找到的资料"两组，每份标出用在哪几门课、当什么；资料多时可以按标题筛选；
- 重新解析后，用到旧版本的每门课都改用新版本，角色不变；
- 没有课程里的操作（设角色、联网找资料、待确认的网上资料）。

**课程里的"本课资料"在侧栏**（图标栏点了展开侧栏，再点收起）：
- 按骨架教材、参考资料、往年试题、网上资料分组；老师找到、等你确认的网上资料单列在最上面，可以直接"确认加入"或"不要"。
- 每份资料下面一行写被哪几个课时的讲义引用了（如"1.2、1.3 引用"）；网上资料写网站和级别。
- 有章节的资料可以展开目录（章 → 节 → 小节），每项带书上页码；骨架教材默认展开到章，只有一项的那一层也默认展开。点资料打开原书第一页，点章节打开那一页，都在当前标签（Ctrl+点击、中键另开标签）。正在看的那份资料高亮。
- 右键一份资料：改当什么、移出本课、在新标签打开。
- 顶部"从资料库加入"和"联网找"两个按钮，点了在侧栏里展开、再点收起。从资料库加入列出还没加入本课的资料，可以筛选，点一份选当什么加入，最后一项"导入新的 PDF"打开本课资料页的导入；加入后主老师会收到通知。联网找的结果只显示标题、网站和级别，点"+"加入本课；线索收在下面，只能在浏览器里打开。
- 最下面"本课资料全页"打开整页。

**本课资料页**（侧栏底部的"本课资料全页"、Ctrl K）：页首的主按钮是"从资料库加入"（导入新的 PDF 也在里面）；下面依次是待确认的网上资料、本课的导入任务、检索本课资料、按角色分组的资料卡（引用它的课时可以点开，菜单里改角色、移出本课、重新解析）、联网找资料。

**被哪几个课时引用：** 段落索引归讲义单元（textbook），由它按课时统计引用了哪份资料（`textbook.sourceUses`）；资料库只回答每个片段属于哪份资料，重新解析前的旧片段算到最新版本上（`chunkSources`）。

## 导入、解析和切块

每个环节都是可替换的零件，换零件不影响其他单元。

- **导入：** PDF 在资料库页面选择或拖入（不超过 200 MB）；网上的网页和 PDF 由老师或你加入。导入任务由 `library` 保存，DSH 的后台任务只负责运行，任务能取消、重试，程序重启后能恢复，解析器丢了任务时重新提交原件。同一内容不重复导入；完成并验证后才发布给老师，再交回主老师。任务记下远端任务交给了哪个解析服务（种类和地址，不含密钥）：查询、取消和重启后恢复都去那个服务，设置换了也一样，重试才按现在的设置提交；服务没确认取消时，导入记录写明它可能还在解析、计费。每次运行（开始、重试、重启后恢复）最长 6 小时，到时停下并请服务取消，原件和完成的部分保留。导入记录显示提交了几次、共多少页（重试和补跑都算）。
- **解析：** MinerU 4，按设置项 `parser` 选择。`cloud`（默认）上传到 MinerU 云端：省事、快，但文件要上传；每份最多 200 页，长书一次上传、按页段提交、按原页码合并；某个页段失败就按更小的页段补跑，多次失败保留已完成的部分并写明缺哪几页，只有覆盖全部页的结果才发布。`local` 用本机 MinerU（`pnpm mineru:start`，地址是设置项 `localParserUrl`）：隐私好，但整本书要近一小时。文字版和扫描版都能处理，扫描件走中文 OCR，公式转成 LaTeX，每块带页码和位置。结果包会跳转到对象存储：最多 5 跳、不绕回、共用一个截止时间，密钥只发给解析服务自己的网站，307/308 才保持原来的请求方法和内容。
- **切块：** 按教材结构切分（章、节、例题、习题、附录表），保留页码和块的定位；跨页的题干和答案归为一组（靠规则推断，需要对照原文）。网页按小标题分节，短段落合并、长段落在句末拆开，都算"第 1 页"、按顺序编号。
- **重新解析** 生成新的快照：原来的资料、片段 ID 和原件都还能打开，用到旧版本的每门课改用新版本。
- **书上页码：** 资料记下 PDF 页码和书上页码的固定差（`pageOffset`），出处显示书上的页码；在阅读器里输入当前页对应的书页即可校正。

## 检索

- **关键词：** SQLite 全文索引，中文用三字切分，不足三个字的词用子串匹配。
- **语义：** Voyage AI 的 `voyage-4`（1024 维），要单独配置（DeepSeek 官方没有向量接口）。向量存在 `library` 自己的表里，不同模型的向量分开存、不混查，换模型时自动重建；资料导入完成和程序启动时补建缺的向量。一次建一份资料、每批 256 个片段，资料卡显示这次发了几批；关掉语义检索、删掉或换了密钥、换了模型时，在途的那一批立即中止，后面的不再发，晚到的结果不存，重新开启后从没建完的片段接着建。一份资料一次最长建 1 小时。
- **融合和重排：** 两路结果按名次融合（RRF），前 24 条用 `rerank-2.5` 重排；最高相关度低于 0.5 判为"资料里没有"，低于 0.3 的片段不返回。语义检索关掉（设置项 `semanticSearch`）、缺密钥或服务出错时退回关键词检索，并说明原因。
- 老师的 `search_library` 和资料库页的检索框用同一套。

## 原文阅读和出处

- PDF 按页显示，可以翻页、缩放、旋转、跳到章节（原处翻页）；可以带页码打开。点出处在右侧栏打开原文，翻到对应页并高亮区域；缺坐标时只定位到页。标签标题是资料名；同一份 PDF 在几个标签和右侧栏里只加载一次，最后一处关掉半分钟后释放。
- 在课程里阅读时，点页面上的一段（按解析出的片段坐标，选最小的那块），旁边显示它的识别文字，可以选中一句提问或批注（批注由 [annotation](../annotation/design.md) 画在 `learning.source-notes` 插槽里）。
- 网页显示保存下来的正文，引用的那一段标出来，附原网址和保存日期。
- **附图：** `learning.figure` 按片段 ID 把一张图从原 PDF 页面上裁出来，只画图本身的区域（同一页上可能印着习题答案）；没有坐标时写"见原书第几页"。测试页、讲义页都用它。

## 联网找权威资料

你的要求：一定要联网补充，只信权威资料，不信模型自己生成的内容。质量主要取决于"搜什么、信谁"，所以做成一条管线：

1. 先查资料库（你的教材、课件），对这门课这是最权威的。
2. 不够用时（检索结果是"资料里没有"，或要找课本以外的资料）搜索：每个问题按可信网站定向搜一次、不限网站搜一次，排在前面的搜索服务出错就换下一家。
3. 按网站规则定级，去重；同一机构最多留两条，转载站、百科、问答只当线索，盗版站直接排除。
4. 二级以上抓全文入库；三级先等你确认；线索不能加入。入库的资料带原网址、保存日期和权威级别，题目只引用资料库里的资料。

**谁来用：**
- **老师：** `search_web` 返回候选（标题、网站、级别、是不是 PDF、摘要）和单列的线索；`add_web_sources` 加入时附一句"为什么需要它"，三级资料你确认时能看到。搜索结果本身不能当出处；加入时按网站规则重新定级，不信老师给的级别。
- **你：** 联网找资料能自己搜、加入本课（你自己加的三级资料不用再确认）。老师提出的三级资料出现在"待你确认的网上资料"里，确认后才下载。线索可以点开看，觉得可信就"信任这个网站"。你加入或确认后、网上的 PDF 解析完后，主老师都会收到通知。
- **写讲义：** 资料没讲、习题却要用的内容，讲义找一个二级以上的网页只读正文（`readWeb`），不加入资料库，讲义里写网址（见 [textbook](../textbook/design.md)）。

**网站级别**（内置规则；你在设置页设的优先，子域名一起生效）：

| 级别 | 网站 |
|---|---|
| 一级 | 你自己设的（例如你们学校的网站） |
| 二级 | 国内高校（`edu.cn`）、政府和国家标准（`gov.cn`）、国内科研机构（`ac.cn`）、国家级课程平台（中国大学 MOOC、国家智慧教育平台、学堂在线）、教材出版社（高教社、化工社）、ISO |
| 三级 | 国外高校（`.edu`、`ac.uk` 等）、国外开放课程（NPTEL、LibreTexts）、学术出版（DOI、ScienceDirect、Springer、Wiley、ACS、AIChE、PubMed Central、CORE、知网、万方等） |
| 只当线索 | 百科、文库和转载站（360doc、原创力文档、道客巴巴、中国高校课件下载中心等）、问答和题库、博客媒体视频、论文转载和预印本（ResearchGate、arXiv），以及不在清单里的网站 |
| 排除 | 盗版资料站（libgen、Z-Library、Anna's Archive、sci-hub 等） |

**抓取：**
- **网页** 在这台电脑上下载，用 Mozilla Readability 取正文（老式高校网站上比 Defuddle 准），转成 Markdown 存下来。下载失败或网页没有正文（要在浏览器里运行才显示）时，用 Exa 保存的副本，资料卡和阅读页上写明。
- **PDF** 下载后走和上传一样的导入和解析，出处能定位到页和区域；下载不了就不收（Exa 给的 PDF 文字会把公式弄乱）。
- **安全：** 网址来自搜索结果，所以只连公网地址：每次 DNS 结果都检查，连接用检查过的地址，每次跳转重新检查；文件最大 100 MB，30 秒超时。每一跳还按网站规则重新定级：跳到只当线索或排除的网站就不跟（也不拿 Exa 的副本），按整条跳转链里最低的级别收，老师加的从二级跳到三级要你确认；出处写内容真正来自的网址，同时记下请求的网址。读网页（`readWeb`）也一样。假 IP 代理把所有域名解析到 `198.18.0.0/15`，这个网段放行，否则代理后面什么都下载不了。
- **版权：** 网页和 PDF 存在本机，只供你个人学习（《著作权法》第二十四条的合理使用）；资料卡写明网站和原网址，不外传。

**模型的知识** 可以用来想该搜什么、挑哪几份，不能当出处。

## 在线服务

- 你填了哪家的密钥就用哪家；配了多家时按实测效果排序，排在前面的失败或超时就换下一家，结果里写明换过。
- 解析：MinerU（云端、本机）。语义检索：Voyage AI。搜索：Exa、博查、Tavily，首选服务是设置项 `searchProvider`（默认 Exa），其余按 Exa → 博查 → Tavily 接替。
- 实测：Exa 定向到高校网站后权威来源最多，中英文都是；博查国内直连、很快，但不限网站时多是文库和题库，限定网站只认注册域名（`edu.cn` 这种后缀不生效）；Tavily 偏百科和企业网站。
- **发出去的内容：** 云端解析把 PDF 原件上传到 MinerU；语义检索把资料片段和检索问题发给 Voyage AI；联网搜索只发要找的主题，网上的 PDF 上传到 MinerU。你的教材和学习记录不会发给搜索服务。设置页"数据与隐私"写明每个服务收到什么，以及关掉后正在跑的任务会怎样。

## 数据与接口

- **服务** `learnLibrary`：导入任务（列表、重试、取消、重新解析、校正页码）、资料和课程资料、检索（`retrieve` 返回命中、模式、"资料里没有"和说明；`search` 是同步的全文检索）、语义索引状态、读片段和小节、整份资料的片段、目录、片段属于哪份资料、联网搜索、加入网上资料、读网页。
- **表：** `library_sources`、`library_chunks`、`library_course_sources`、`library_imports`、`library_fingerprints`、`library_vectors`、`library_web`（网址 → 资料或导入任务，同一网址不重复抓）、`library_web_pending`、`library_site_rules`。
- **页面接口** `/api/learning/library.<方法>`：`sources`（不带课程是全库、每份带用到它的课程；带课程只返回本课的资料，PDF 带目录）、`document`、`chunk`、`pageChunks`、`search`、`import`、`imports`、`retry`、`cancel`、`reparse`、`pageOffset`、`attach`、`detach`、`reindex`、`services`、`testService`、`webSearch`、`addWeb`、`webPending`、`confirmWeb`、`dismissWeb`、`siteRules`、`setSiteRule`；二进制的 `upload`（流式，200 MB 以内）、`original`（支持 Range）、`pdfAsset`。
- **事件：** `learning/source-imported`（完成后才发）、`source-updated`、`import-changed`、`web-changed`；页面上加入或确认资料、后台导入结束时发 `learning/handoff`。
- **老师工具**（`@learning-agent/library/tools`）：`search_library`、`read_section`（侧边会话也能用）、`search_web`、`add_web_sources`（只有主老师）。
- **设置项：** `parser`、`localParserUrl`、`semanticSearch`、`searchProvider`；密钥 `MINERU_API_KEY`、`VOYAGEAI_API_KEY`、`EXA_API_KEY`、`BOCHA_API_KEY`、`TAVILY_API_KEY`。设置区块登记在设置页"资料服务"。

## 关键决定

- **自建资料库，不用 Open Notebook 这类现成产品**（10-03，你提要求，Claude 给方案）：我们要页码级出处、从教材抽题、片段挂到知识节点、权威分级，现成产品都没有；Open Notebook 需要 Docker、Python 和 SurrealDB，引用功能它自己也承认还比较基础。真正的难点是把扫描版教材读准，专门的文档解析器更强，而且可以直接接入。
- **文字版和扫描版都支持；本机解析还是云服务由你选**（10-03，你）。
- **各类服务尽量全部兼容，配了多家按实测效果排序，失败自动换下一家**（10-03，你；排序和切换规则由 Claude 补充）。
- **导入任务由 `library` 保存，DSH 的后台任务只负责运行**（10-04）：DSH 的任务 ID 不能用来恢复；重新解析生成新快照，旧引用保留；MinerU 的归一化坐标换算成 PDF 点。
- **解析和语义检索默认用在线服务**（10-04，你："先不弄本地了吧，直接用在线api吧"）：本机解析整本书近一小时太慢；本机解析保留为可选。
- **混合检索的默认参数**（10-04，Claude 按 38 条合成查询的基准定）：只用关键词时，换一种说法的问题 15 条只找回 1 条；混合检索加重排后，有答案的问题第一名全部正确，有无答案的判断全对。向量相似度判断不了"资料里没有"，重排的相关度可以。
- **云端分段失败只补缺页**（10-04，你反馈后段失败）：完成的页段单独保存，缺页的结果不发布。
- **网上资料二级以上直接可用，三级在老师加时等你确认，线索不入库**（10-07，你选"二级以上自动可用"）：放弃了"每份都等你确认"。
- **中文搜索加博查，默认顺序 Exa → 博查 → Tavily**（10-07，你"加博查"；顺序由 Claude 按实测定）。
- **权威按网站规则定，不让模型打分**（10-07，Claude 按调研）：大模型给网站可信度打分和专家只有中等一致；不认识的网站默认只当线索，你可以升级。
- **老师用我们自己的联网工具，不挂 DSH 的 `web_search`**（10-07，Claude）：网上结果要先定级、入库才能引用，DSH 的工具会让老师直接引用搜索结果。
- **讲义不要求关键事实有两个独立来源**（10-15，随讲义改为"讲解与原文"）：判断两份资料是否同一来源的"来源组"因此没人用，10-17 删掉；以后需要时从 git 找回。
- **主界面的资料库是仓库，课程里的"本课资料"放侧栏**（10-12 你的试用反馈"总资料库和课程资料库界面完全一样"，10-15 定方向，10-16 Claude 按调研细化）：一份资料只存一份，课程记角色；"从资料库加入"代替课程里的导入表单。放弃了每门课各存一份（NotebookLM 的做法，同一本书要重复上传、重复解析）。
- **重新解析后，用到旧版本的每门课都改用新版本**（10-16，Claude）：在仓库里发起的重新解析不属于任何课程，只换发起的那门课就没有课会换上。
- **章节目录用解析出的标题，不用 PDF 书签**（10-16，Claude 按调研）：扫描版教材基本没有书签。
- **任务认准自己的服务；关掉立即停**（11-03，Claude，审查 SEC-03、SEC-07）：你关掉开关就是别再发了，所以不等当前这本传完；任务记下服务就能放开切换，不用在任务跑完前禁止切换。
- **按跳转链里最弱的网站定级**（11-03，Claude，审查 SEC-02）：内容来自最后那个网站，可信网站的跳转不能给它加级。不完全拒绝跳转：正规网站和 MinerU 的结果都用跳转。
- **任务的费用先只记、不拦**（11-03，Claude，审查 M06）：没有真实数据定上限；截止时间按大书解析几十分钟、建索引几分钟留足余量。

## 已知限制与以后再做

- 解析会把个别公式符号认错，复杂题号的分组靠规则推断；原文对照和核对提示都有，但"解析完成"不等于"内容已核实"。
- 这台电脑打不开的网页（证书问题、拒绝访问）用 Exa 保存的副本。
- MinerU 取消任务后还计不计费，官方文档没写；服务没确认取消时导入记录如实写"可能还在计费"。
- 用"假 IP"模式的代理工具（Clash 等）时，程序看不到代理最后连到哪个地址，防止访问内网的检查只能挡住明写的内网地址。
- 以后再做：网上的 PPT、Word 等格式；PDF 以外格式的原文阅读；不规则的页码对应（罗马数字前言、插页）；中文和英文搜索分开排序、同时用多家；检索的上下文扩展（命中一段后取相邻段落或整节，受上下文预算限制）；确认目标时由老师提出本课的来源清单。
- 等你试用后看要不要：课程里勾选哪些资料参与回答（NotebookLM 的做法）、删除资料（要先说明影响哪些出处）、侧栏目录跟着正在读的章节高亮、章节很多时在目录里搜索。
- 讲义和题目里的插图打开的 PDF 不释放，没用阅读器的借用机制，见 [页面状态提案](../shell/proposals/2026-11-02-page-state.md)。

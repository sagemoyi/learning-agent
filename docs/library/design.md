# 资料库（library）

> 代码：[`packages/library`](../../packages/library) · 调研：[research.md](research.md) · 接口：[契约](../stage0/contracts.md) §5.1 和 §11"资料库 A/B""资料库 C" · 验证：[验证记录](../stage0/compatibility.md)里的"资料库"各节

资料库负责把你的教材和其他资料变成可以引用的片段：解析、切块、检索、出处定位，以及联网找权威资料。目标是做到 NotebookLM 的核心体验：回答和教材只依据资料，每一句话都能点开，跳到原文的那一页、那一段。

## 现状

- **已验收：**
  - **PDF 导入与出处定位（批次 A）：** 从页面选择或拖入 PDF，后台解析；任务能取消、重试，程序重启后能恢复；同一内容不会重复导入；原件和完整解析结果都保存；用 PDF.js 阅读原文，点出处翻到对应页并高亮区域，缩放、旋转后仍对齐；能校正书上页码和 PDF 页码的固定偏移；重新解析生成新快照，旧的出处仍然有效。
  - **在线解析：** 默认用 MinerU 云端，长书自动分段提交，失败的页段拆小重试、只补缺页。
  - **混合检索（批次 B）：** 关键词 + 语义检索，再用重排模型打相关度；资料里没有答案时明确说"资料里没有"。老师的 `search_library` 工具和资料库页面的检索框都用这一套。
  - **设置：** 设置页"资料服务"里能切换解析方式、填写密钥、开关语义检索、测试连接。
  - 日常库里你的化工原理教材已整本解析（488 页），语义索引已建好。
- **已实现，待你试用：联网找权威资料（批次 C）。**
  - **老师：** 资料库不够时用 `search_web` 联网搜，再用 `add_web_sources` 把合适的加进资料库。
  - **你：** 在资料库页的"联网找资料"里也能自己搜、自己加。
  - **定级和入库：** 二级以上直接可用，三级等你确认，只当线索的只给链接。网页存成正文，PDF 和上传的一样走 MinerU 解析。
  - **设置：** 设置页能换首选搜索服务、填三家的密钥、设网站级别。
  - **已验证：** 3182 上用真实搜索服务和真实模型走通过。
- **附图（assess A，已技术验收，待你试用）：** 插槽 `learning.figure` 按片段 ID 把一张图从原 PDF 页面上裁出来显示，只画图本身的区域（同一页上印着习题答案）；没有坐标时写"见原书第几页"。测试页用它显示习题的附图。
- **待你试用：** 整本教材的出处定位，以及用它生成教材的效果；联网找资料。
- **10-12 试用后的改版（方向已定，还没做）：** 主界面的资料仓库和课程侧栏里的"本课资料"分开，见下文同名一节。
- **还没做：**
  - 网上的 PPT、Word 等格式（现在只收网页和 PDF）。
  - 确认目标时由老师提出本课的来源清单：现在用内置的网站规则加你在设置页设的网站级别（见 [goal](../goal/design.md)）。
  - 检索结果的上下文扩展（命中一段后取相邻段落或整节）、引用证据接口。
  - PDF 以外格式的原文阅读；不规则的页码对应（罗马数字前言、插页）。
  - 中文和英文搜索分开排序（实测 Exa 两种都最好，现在共用一个顺序）。
- **已知限制：**
  - 解析会把个别公式符号认错，复杂题号的分组靠规则推断。原文对照和核对提示都有，但"解析完成"不等于"内容已核实"。
  - 这台电脑打不开的网页（证书问题、拒绝访问）用 Exa 保存的副本，资料卡和阅读页上会写明。
  - 用"假 IP"模式的代理工具（Clash 等）时，程序看不到代理最后连到哪个地址，防止访问内网的检查只能挡住明写的内网地址（见下文"抓取"）。

## 为什么不用 Open Notebook 和同类现成产品

- **我们要的比 NotebookLM 多：** 页码级出处、从教材里抽题、把资料片段挂到知识节点、权威分级。现成产品都没有这些功能，即使接进来，也得在外面再包一层。
- **Open Notebook 和我们是两套系统：** 它需要 Docker + Python + SurrealDB，有自己的界面和数据库；而且它自己承认引用功能还比较基础。
- **真正的难点是把扫描版教材读准：** 公式、表格、图都要识别正确。这一块，专门的文档解析器比任何 NotebookLM 替代品都强，而且可以直接接入。

## 怎么运作

全部放在 `library` 里，每个环节都是可替换的零件，换零件不影响其他单元。

| 环节 | 做法 | 可替换为 |
|---|---|---|
| 导入 | PDF 在资料库页面选择或拖入；网上找到的网页和 PDF 由老师或你加入（见下文）。设计上还要支持讲义、视频等。导入任务由 `library` 保存，DSH 的后台任务负责运行；完成后才算可用，再交回主老师 | — |
| 解析 | MinerU（4.0，协议是在 Apache 2.0 基础上附加条件），按设置项 `parser` 选择：`cloud`（默认）上传到 MinerU 云端，省事、快，但文件要上传；每份最多 200 页，长书按页段提交、按原页码合并。`local` 用本机 MinerU（`pnpm mineru:start`），隐私好，但整本书要近一小时。文字版和扫描版都能处理，扫描件走中文 OCR；每块带"第几页、在哪个位置"，公式转成 LaTeX | PaddleOCR-VL、DeepSeek-OCR-2 等 |
| 切块 | 按教材结构切分（章、节、例题、习题、附录表），保留页码和块的定位；跨页的题干和答案归为一组。网页按小标题分节，短段落合并、长段落在句末拆开，都算"第 1 页"，按顺序编号 | — |
| 检索 | 关键词：SQLite 全文索引（中文用三字切分，不足三个字的词用子串匹配）。语义：Voyage AI 的 `voyage-4`（1024 维），需要单独配置，因为 DeepSeek 官方没有向量接口；向量存在 `library` 自己的表里，不同模型的向量分开存、不混用，换模型时自动重建索引。两路结果按名次融合（RRF），前 24 条用 `rerank-2.5` 重排；最高相关度低于 0.5 判为"资料里没有"，低于 0.3 的片段不返回。语义检索关闭、缺密钥或服务出错时退回关键词检索，并说明原因 | 其他向量和重排服务（见"服务兼容"） |
| 回答和写作 | 只依据检索到的片段生成，强制附带引用；生成后逐条回查"引用的原文是否真的支持这句话"（逐条回查还没做，归 [textbook](../textbook/design.md)） | 长上下文模型可以直接读整节 |
| 阅读 | PDF 按页显示；点出处在旁边打开原文，翻到对应页并高亮区域；缺坐标信息时只定位到页。在课程里阅读时，点页面上的一段（按解析出的片段坐标，选最小的那块）在旁边显示它的识别文字，可以选中一句提问或批注（批注由 [annotation](../annotation/design.md) 画在 `learning.source-notes` 插槽里）。网页显示保存下来的正文，引用的那一段标出来，附原网址和保存日期 | — |

**发往在线服务的内容：**
- 云端解析会把 PDF 原件上传到 MinerU；语义检索会把资料片段和检索问题发给 Voyage AI。这是你选择的方式，页面上有提示。用真实教材验收在线服务前，先问你。
- 联网搜索只把要找的主题发给搜索服务；网上找到的 PDF 会上传到 MinerU 解析。你的教材和学习记录不会发出去。

精确的接口、数据表和事件见契约 §11"资料库 A 做深补充""资料库 B 与在线服务""资料库 C：联网找权威资料"。

## 联网找权威资料

**你的要求：** 一定要联网补充，只信权威资料，不信模型自己生成的内容。

**做法：** 只接搜索接口不够，质量主要取决于"搜什么、信谁"，所以做成一条管线：

```
① 先查资料库（你的教材、课件）：对这门课来说这是最权威的
   ↓ 不够用时（检索结果标"资料里没有"，或要找课本以外的资料）
② 搜索：每个问题按可信网站定向搜一次、不限网站搜一次，排在前面的搜索服务出错就换下一家
   ↓
③ 按网站规则定级（不让模型打分），去重；同一机构最多留两条，转载站、百科、问答只当线索，盗版站直接排除
   ↓
④ 加入：二级以上抓全文入库；三级先等你确认；线索不能加入
   ↓
⑤ 存入资料库（带原网址、保存日期和权威级别）→ 之后题目只引用资料库里的资料（教材补讲时可以只读网页、写网址，见下文"写教材"）
```

**谁来用：**
- **老师：** `search_web` 返回候选（标题、网站、级别、是不是 PDF、摘要）和单列的线索；`add_web_sources` 加入时附一句"为什么需要它"，三级资料你确认时能看到。搜索结果本身不能当出处，工具说明里写明了，加入时也按网站规则重新定级，不信老师给的级别。
- **你：** 资料库页的"联网找资料"能自己搜、点"加入本课"（你自己加的三级资料不用再确认）。老师提出的三级资料出现在"待你确认的网上资料"里，确认后才下载。线索可以点开看，觉得可信就"信任这个网站"。
- **交回主老师：** 你在页面上加入或确认网上资料后，主老师会收到进度通知；网上的 PDF 解析完也会通知。
- **写教材：** 本节资料没讲、习题却要用的内容，教材找一个二级以上的网页（`searchWeb` 后用 `readWeb` 只读正文），**不加入资料库**，教材里写网址（见 [textbook](../textbook/design.md)"讲解与原文"）。

**网站级别（内置规则；你在设置页设的优先，子域名一起生效）：**

| 级别 | 网站 |
|---|---|
| 一级 | 你自己设的（例如你们学校的网站） |
| 二级 | 国内高校（`edu.cn`）、政府和国家标准（`gov.cn`）、国内科研机构（`ac.cn`）、国家级课程平台（中国大学 MOOC、国家智慧教育平台、学堂在线）、教材出版社（高教社、化工社）、ISO |
| 三级 | 国外高校（`.edu`、`ac.uk` 等）、国外开放课程（NPTEL、LibreTexts）、学术出版（DOI、ScienceDirect、Springer、Wiley、ACS、AIChE、PubMed Central、CORE、知网、万方等） |
| 只当线索 | 百科、文库和转载站（360doc、原创力文档、道客巴巴、中国高校课件下载中心等）、问答和题库、博客媒体视频、论文转载和预印本（ResearchGate、arXiv），以及不在清单里的网站 |
| 排除 | 盗版资料站（libgen、Z-Library、Anna's Archive、sci-hub 等） |

**抓取：**
- **网页：** 在这台电脑上下载，用 Mozilla Readability 取正文（老式高校网站上比 Defuddle 准），转成 Markdown 存下来。下载失败或网页没有正文（要在浏览器里运行才显示）时，用 Exa 保存的副本，并标明。
- **PDF：** 下载后走和上传一样的导入和 MinerU 解析，出处能定位到页和区域。下载不了就不收，因为 Exa 给的 PDF 文字会把公式弄乱。
- **安全：** 网址来自搜索结果，所以只连公网地址：每次 DNS 结果都检查，连接用检查过的地址，每次跳转重新检查；文件最大 100 MB，30 秒超时。假 IP 代理把所有域名都解析到 `198.18.0.0/15`，这个网段放行，否则代理后面什么都下载不了。
- **版权：** 网页和 PDF 存在本机，只供你个人学习（《著作权法》第二十四条的合理使用）；资料卡写明网站和原网址，不外传。

**模型知识的定位：** 可以用来想出该搜什么、挑哪几份，但不能当出处。

### 判断独立来源

资料库记下每份资料属于哪个来源组（`sourceGroup`），供需要时判断两份资料是不是同一个来源：
- 每份网上资料按网址的注册域名算机构（如 `kmust.edu.cn`），同一所学校的几份课件算一个来源；
- 上传的资料按书名算，去掉版次和标点：同一份资料的重新解析、同名不同版次的书算一个来源；不同的上传资料算不同来源。

教材不再要求关键事实有两个独立来源（见 [textbook](../textbook/design.md)"讲解与原文"）。

## 10-12 试用后的改版（方向已定，还没做）

你 10-12 试用时说：总资料库和课程资料库界面完全一样，在课程里操作资料库很不直观（原文见 [throughts.md](../throughts.md) 10-12）。10-15 定下的方向如下，排在外壳之后（要用到外壳的侧栏，见 [shell](../shell/design.md)"10-12 试用后的改版"）。做之前先调研、写验收标准；方向要改，先和你商量。

- **主界面的"资料库"是资料仓库：** 导入、解析状态、重新解析、全库搜索，并标出每份资料被哪些课程用到。
- **课程里的"本课资料"放在侧栏：**
  - 按骨架教材、参考资料、网上资料、待确认的网上资料分组；
  - 骨架教材可以展开章节目录，点一个章节，在主区打开原书那一页；
  - 用"从资料库加入"挑已有的资料，代替课程里现在的导入表单；
  - 联网找资料也放在这里；
  - 每份资料标出被哪几节教材引用了。

## 服务兼容

适用于搜索服务、向量模型和解析服务：

- **尽量兼容所有主流服务。** 你在设置里填了哪家的密钥，就用哪家。
- **多家都配了时，按效果排序使用：** 默认顺序来自我们的实测结果，你也可以手动调整。
- **排在前面的失败或超时时，自动换下一家。**
- **中文和英文分开排序：** 中文搜索和英文搜索各有一份排序，可以同时使用多家。

**现在接了什么：**
- 解析：MinerU（云端和本机）。
- 语义检索：Voyage AI。
- 搜索：Exa、博查、Tavily。设置页选首选服务（默认 Exa），其余按实测顺序 Exa → 博查 → Tavily 接替；出错或没有密钥时换下一家，结果里写明换过。
- 中英文分开排序和同时用多家还没做。

实测结论：
- Exa 定向到高校网站后权威来源最多，中英文都是。
- 博查国内直连、很快，但不限网站时多是文库和题库；限定网站只认注册域名，`edu.cn` 这种后缀不生效。
- Tavily 偏百科和企业网站。

详见[验证记录](../stage0/compatibility.md)。

## 关键决定

- **自建资料库，不用 Open Notebook**（10-03，你提要求，Claude 给方案）：解析器可替换（默认 MinerU），检索和引用由我们自己实现。理由见上文。
- **文字版和扫描版教材都支持**（10-03，你）。
- **在本机解析还是用云服务，由你选择**（10-03，你）：对应设置项 `parser`。
- **各类服务尽量全部兼容，配了多家时按实测效果排序，失败自动换下一家**（10-03，你；排序和切换规则由 Claude 补充）。
- **联网补充做成"来源清单 + 多搜索源 + 权威评级 + 交叉核对"的管线**（10-03，你；管线由 Claude 补充）。
- **分三批交付，先做 A（PDF 导入与出处定位）**（10-04，你选择"先完成 PDF 导入与出处定位"）：B 检索和引用、C 联网补充排在后面，没有取消。
- **导入任务由 `library` 保存，DSH 的后台任务只负责运行**（10-04）：DSH 的任务 ID 不能用来恢复；重解析生成新快照，旧引用保留；MinerU 的归一化坐标换算成 PDF 点，缺几何信息时只定位到页。
- **解析和语义检索改用在线服务**（10-04，你："先不弄本地了吧，直接用在线api吧"）：本机解析整本书近一小时，太慢；本机 GPU 加速先不做，本机解析保留为可选。
- **混合检索的默认参数**（10-04，Claude 按 38 条合成查询的基准定）：只用关键词时，换一种说法的问题 15 条只找回 1 条；混合检索加重排后，有答案的问题第一名全部正确，有无答案的判断全对。向量相似度判断不了"资料里没有"，重排的相关度可以。
- **云端分段失败只补缺页**（10-04，你反馈后段失败；Claude 实现，Codex 复核）：完成的页段单独保存；多次失败时保留已完成部分，说明是哪几页，缺页的结果不发布。
- **网上资料二级以上直接可用**（10-07，你选"二级以上自动可用"）：三级（你没有指定）由 Claude 定为老师加时等你确认；线索不入库。放弃了"每份都等你确认"。
- **中文搜索加博查，默认顺序 Exa → 博查 → Tavily**（10-07，你"加博查"；顺序由 Claude 按实测定）。

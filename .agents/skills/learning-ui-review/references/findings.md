# 复核中确认过的问题

每条写：现象 → 改法 → 以后怎么避免。只收被采纳、以后还会遇到的问题，新的一条加在最后。

1. **浏览器原生控件**：资料库的"选择文件"按钮粗糙，和整体不搭。
   - 改法：改成共享的 `FileDrop`，底层用隐藏的 file input。
   - 以后：所有控件都用共享设计控件（10-04 用户要求）。
2. **emoji 图标**：
   - 改法：换成 Lucide 线条图标（`strokeWidth` 1.75），侧栏是"图标 + 两到四个字"。
   - 以后：不用 emoji（10-04 试用反馈）。
3. **选中的选项卡片一悬停就变回灰色**：悬停样式的优先级盖过了选中样式。
   - 改法：给"选中 + 悬停"单独写一条规则，保持选中色。
   - 以后：状态样式（选中、禁用）优先于交互样式（悬停、按下）。
4. **阅读器工具栏在分屏里散成三行**：
   - 改法：上一页/下一页改成方形图标按钮，夹住页码；缩放和旋转并成一组；章节跳转单独一行。
   - 以后：窄栏里的控件按功能分组，整组换行。
5. **"重新生成本节"做成了折叠区**，看起来像一段可展开的说明。
   - 改法：换成 `ConfirmButton` 原地确认。
   - 以后：确认就用确认，不借用折叠区或弹窗。
6. **资料库的检索框没有小标题**，和旁边有标题的"导入任务""资料"不对称。
   - 改法：补上"检索"小标题。
   - 以后：平行的区块要有平行的结构。
7. **760 宽同时开着分屏和侧边提问时，正文被挤得很窄**。
   - 改法：窄窗口下左侧栏收成图标栏，侧边提问浮在页面上。
   - 以后：窄窗口先收起次要面板，保住正文的宽度。
8. **同一列表里，有的卡片有"更多"菜单、有的没有**，"阅读原文"按钮因此上下对不齐。
   - 改法：没有菜单的卡片用 `la-icon-slot` 占住菜单按钮的位置。
   - 以后：列表行的操作区按固定的位置排列，缺了的按钮也要留出位置。
9. **教材的小标题紧贴着上一段**，比段落之间的距离还小。原因是每段都包在可选中的块里，块会清掉第一个子元素的上边距。
   - 改法：教材模式里，不在开头的块中的小标题，补回上边距。
   - 以后：小标题和下文的距离要小于和上文的距离；加了包裹层时，检查边距是不是被清掉了。
10. **字号有 15 种（含半像素），字重有 600、650、700 三档粗体**。
    - 改法：统一成 9 档 `--la-fs-*` 变量，字重只用 400、500、600。
    - 以后：不写死字号，不另加字重档位。
11. **搜索框带小标题时，旁边的按钮比输入框高出一截**（知识模型的"资料依据""复用已有身份"）。
    - 改法：搜索行不用带标签的 `Field`，输入框和按钮放进 `la-row nowrap`，输入框外包一层 `flex: 1`，靠区块标题和占位文字说明用途。
    - 以后：一行里只有输入框和按钮时，两者按中线对齐；需要标签的表单项，同一行的按钮也要对齐到输入框。
12. **列表还没有内容时，就画出一条边框线**：空的 `la-rows` 也有边框。
    - 改法：有内容时才渲染 `la-rows`；搜过但没有结果时，给一句提示。
    - 以后：带边框的容器，没有内容就不渲染。
13. **图谱画布不能直接用颜色变量**：WebGL 和 Canvas 只认具体的颜色值。
    - 改法：运行时从 `--la-*` 变量读出颜色，监听 `<html>` 的 `data-la-theme`，切换深浅色时重读；课程着色另加 `--la-cat-1` 到 `--la-cat-6`。
    - 以后：画布、图表里的颜色同样来自设计变量，两种主题都要截图。
14. **两个同名的对象并排时，说明文字分不清是哪一个**（合并建议的"合并后"、变更记录里改连前后的关系）。
    - 改法：同名时在名称后面带上能区分的归属（课程名），或标出角色（"被合并的节点"）。
    - 以后：比较、合并、复制这类同时出现两个同名对象的地方，每处提到名称都要能分清是哪一个。
15. **教材段落下的每条批注都是一张带原句、全文和一排按钮的卡片**，读教材时正文被切得很碎，原句还在卡片里重复一遍。
    - 改法：原句直接标在正文里（CSS Custom Highlight，不改动渲染好的 HTML）；段落下一行一条，点开才有全文和操作。
    - 以后：附在正文里的东西（批注、提示、核对结果）默认收成一行，正文优先；同一句话不要在正文和附加内容里各出现一次。
16. **插槽里的组件按相邻元素找宿主的段落，找不到**：DSH 渲染插槽时在组件外面包了一层 `div`。
    - 改法：沿父元素向上，在每一层的前面找。
    - 以后：插槽组件不假设自己在宿主 DOM 里的位置；要用宿主的元素时，向上找或由宿主通过属性传进来。
17. **窄栏里的提示卡片把操作按钮放在右侧**（侧边提问里的修改建议）：右侧栏只有三百多像素，两个按钮占掉一半，正文被挤成很窄的一列。
    - 改法：按钮放在正文下面一行；`Callout` 的 `actions` 只用在宽的主区。
    - 以后：右侧栏、阅读器旁栏这类窄栏里，卡片的操作放在内容下面；读取失败也要在原处说明原因，不能什么都不显示。
18. **跟着选区出现的浮条在窄屏上一半被左边栏盖住，还折成两行**（教材选中文字后的浮条）：浮条按选区右端定位、宽度随可用空间收缩，选区靠左时可用宽度很小。
    - 改法：浮条 `width: max-content`；渲染后量出宽度，限制在正文栏内；选区上方被标签栏挡住时改放到选区下方。
    - 以后：贴着选区或某个字出现的浮层，宽度不随定位收缩；位置在渲染后按实际尺寸校正，三种宽度下都把选区放在栏的最左、最右和最上面各试一次。
19. **固定宽度的卡片加了内边距后比设计的宽**（出处与核对卡片、出处悬停预览）。
    - 改法：带内边距和边框的浮层用 `box-sizing: border-box`，宽度写成 `min(固定值, 可用宽度)`。
    - 以后：新写的浮层先检查 `box-sizing`，再在 760 宽度下看它会不会出界。
20. **每点一个页面就多一个标签，切回来又回到顶部**（你 10-12 的试用反馈）：外壳"没开过就新建标签"，dockview 默认把切走的标签卸载。
    - 改法：默认在当前标签打开，每个标签有后退和前进；后台标签和当前页前后几页不卸载；更早的页面记下滚动位置，内容加载出来后再滚过去。
    - 以后：页面里换内容（上一节、下一节、换一份资料）走 `openPage`，不要在页面内部用状态切换，否则后退回不去、标签标题也不变。页面离开时（换页或关掉）不能丢掉用户刚输入、还没保存的内容。
21. **右键菜单一出现就关掉**（右键一个没激活的标签）：菜单在任何滚动事件时关闭，而激活标签时页面恢复滚动位置也会触发滚动事件。
    - 改法：只在滚轮、点别处、Esc、窗口大小变化时关闭。
    - 以后：浮层不要监听全局的 `scroll` 来关闭自己，用 `wheel` 这类用户动作。
22. **侧栏浮在页面上时，按 Esc 关菜单把侧栏也收起了**（本课资料侧栏的右键菜单）：外壳在 `window` 上监听 Esc 收起浮着的侧栏，菜单在自己的元素上处理 Esc，一次按键两边都处理了。
    - 改法：菜单处理 Esc 时 `preventDefault`，外壳看到 `defaultPrevented` 就不收侧栏。
    - 以后：一次 Esc 只关最上面的一层；新写的浮层处理 Esc 时都 `preventDefault`，外层的 Esc 处理先看 `defaultPrevented`。
23. **资料阅读器的"跳到章节"另开一页，还把章节标题当成"引用的原文"显示**。
    - 改法：同一份资料里跳章节就在原处翻页。
    - 以后：同一份内容里的位置（翻页、跳到章节、滚到某段）原处改，不进历史；换成另一份内容（另一节教材、另一份资料）才走 `openPage`（见第 20 条）。
24. **图谱设置面板点了"恢复默认"后按 Esc 关不掉**：Esc 挂在面板自己的元素上，点完的按钮随即变灰，焦点落到了页面上，按键不再经过面板。
    - 改法：面板打开时在 `document` 上监听 Esc 和点外面（点开关按钮本身除外），关闭时移除。
    - 以后：浮层的 Esc 和点外面关闭挂在 `document` 上，处理了就 `preventDefault`（见第 22 条）；按钮按完会变灰、消失的，不能指望焦点还在浮层里。
25. **画布放进侧栏后，图被挤到一角，节点只有一两个像素**（知识模型的侧栏局部图）：页面大画布上合适的留白（给名称和缩放按钮留 150 像素）和节点大小，搬到 240 像素宽的画布上就不对了。
    - 改法：留白按画布尺寸算；小画布放大节点，只给要看的几个节点写名称，放不下的名称以"…"收尾。
    - 以后：同一个画图组件用在大小差很多的地方时，三种宽度的截图里要各看一张小画布的。
26. **左上角切换课程的菜单只露出一条，点不到**（你 10-16 的反馈）：图标栏为了能上下滚动设了 `overflow`，菜单是绝对定位的弹层，被裁在 48 像素宽的栏里。验收脚本的 `locator.click()` 会先把裁剪的容器滚过去再点，所以一直通过。
    - 改法：图标栏不裁剪，只让中间的图标列表滚动，两个菜单放在列表外面。
    - 以后：会弹出菜单、下拉框的控件不要放进设了 `overflow` 的窄容器；验收弹层时用 `document.elementFromPoint` 看每一项的中心是不是它自己，或用 `page.mouse.click` 按坐标点，不要只靠 `locator.click()`。

# 复核中确认过的问题

每条写：现象 → 改法 → 以后怎么避免。只收被采纳、以后还会遇到的问题，新的一条加在最后。

1. **浏览器原生控件**：资料库的"选择文件"按钮粗糙，和整体不搭。
   - 改法：改成共享的 `FileDrop`，底层用隐藏的 file input。
   - 以后：所有控件都用共享设计控件（10-04 用户要求）。
2. **emoji 图标**：
   - 改法：换成 Lucide 线条图标（`strokeWidth` 1.75），侧栏是"图标 + 两到四个字"。
   - 以后：不用 emoji（10-04 试用反馈）。
3. **选中的选项卡片一悬停就变回灰色**：悬停样式的优先级盖过了选中样式。
   - 改法：给"选中 + 悬停"单独写一条规则，保持选中色。
   - 以后：状态样式（选中、禁用）优先于交互样式（悬停、按下）。
4. **阅读器工具栏在分屏里散成三行**：
   - 改法：上一页/下一页改成方形图标按钮，夹住页码；缩放和旋转并成一组；章节跳转单独一行。
   - 以后：窄栏里的控件按功能分组，整组换行。
5. **"重新生成本节"做成了折叠区**，看起来像一段可展开的说明。
   - 改法：换成 `ConfirmButton` 原地确认。
   - 以后：确认就用确认，不借用折叠区或弹窗。
6. **资料库的检索框没有小标题**，和旁边有标题的"导入任务""资料"不对称。
   - 改法：补上"检索"小标题。
   - 以后：平行的区块要有平行的结构。
7. **760 宽同时开着分屏和侧边提问时，正文被挤得很窄**。
   - 改法：窄窗口下左侧栏收成图标栏，侧边提问浮在页面上。
   - 以后：窄窗口先收起次要面板，保住正文的宽度。
8. **同一列表里，有的卡片有"更多"菜单、有的没有**，"阅读原文"按钮因此上下对不齐。
   - 改法：没有菜单的卡片用 `la-icon-slot` 占住菜单按钮的位置。
   - 以后：列表行的操作区按固定的位置排列，缺了的按钮也要留出位置。
9. **教材的小标题紧贴着上一段**，比段落之间的距离还小。原因是每段都包在可选中的块里，块会清掉第一个子元素的上边距。
   - 改法：教材模式里，不在开头的块中的小标题，补回上边距。
   - 以后：小标题和下文的距离要小于和上文的距离；加了包裹层时，检查边距是不是被清掉了。
10. **字号有 15 种（含半像素），字重有 600、650、700 三档粗体**。
    - 改法：统一成 9 档 `--la-fs-*` 变量，字重只用 400、500、600。
    - 以后：不写死字号，不另加字重档位。
11. **搜索框带小标题时，旁边的按钮比输入框高出一截**（知识模型的"资料依据""复用已有身份"）。
    - 改法：搜索行不用带标签的 `Field`，输入框和按钮放进 `la-row nowrap`，输入框外包一层 `flex: 1`，靠区块标题和占位文字说明用途。
    - 以后：一行里只有输入框和按钮时，两者按中线对齐；需要标签的表单项，同一行的按钮也要对齐到输入框。
12. **列表还没有内容时，就画出一条边框线**：空的 `la-rows` 也有边框。
    - 改法：有内容时才渲染 `la-rows`；搜过但没有结果时，给一句提示。
    - 以后：带边框的容器，没有内容就不渲染。
13. **图谱画布不能直接用颜色变量**：WebGL 和 Canvas 只认具体的颜色值。
    - 改法：运行时从 `--la-*` 变量读出颜色，监听 `<html>` 的 `data-la-theme`，切换深浅色时重读；课程着色另加 `--la-cat-1` 到 `--la-cat-6`。
    - 以后：画布、图表里的颜色同样来自设计变量，两种主题都要截图。
